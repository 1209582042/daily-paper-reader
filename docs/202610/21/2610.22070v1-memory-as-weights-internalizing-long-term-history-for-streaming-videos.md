## 摘要
流式视觉-语言模型（VLM）必须持续整合过去的信息，同时保持对当前观测和用户查询的响应能力。现有记忆机制通常压缩、检索或缓存历史观测，并将其重新引入输入上下文，迫使历史记忆与当前观测竞争有限的上下文。我们提出 MaLoW，一种流式记忆框架，转而将历史上下文内化为不断演化的轻量级参数更新。MaLoW 使用循环超网络（HyperNetwork）将输入视频观测逐步巩固为固定大小的 LoRA 权重，使历史信息得以向前传递，而无需重新访问完整视频流。这样，MaLoW 将历史表示为权重，同时将当前观测保留为输入。为支持训练，我们进一步构建了 MaLoW-Instruct，一个大规模流式视频数据集，包含 56K 个视频上的 381K 个问答对。我们进行了大量实验，证明 MaLoW 在 OVO-Bench、StreamingBench 和 StreamArena 上取得强劲性能。在 OVO-Bench 的 backward 划分上，MaLoW 在不同视频骨干网络上相较先前记忆方法提升 3.9% 至 11.8%，且仅带来适度延迟开销。除流式视频理解外，MaLoW 还可泛化到视觉-语言-动作模型，在 Simpler WidowX 上将动作成功率提升 9.3%。

## Abstract
Streaming vision-language models (VLMs) must continuously integrate information from the past while remaining responsive to current observations and user queries. Existing memory mechanisms typically compress, retrieve, or cache historical observations and reintroduce them into the input context, forcing historical memory and current observations to compete for limited context. We propose MaLoW, a streaming memory framework that instead internalizes historical context into evolving lightweight parameter updates. MaLoW uses a recurrent HyperNetwork to incrementally consolidate incoming video observations into fixed-size LoRA weights, allowing historical information to be carried forward without revisiting the full video stream. In doing so, MaLoW represents history as weights, while keeping the current observation as input. To support training, we further construct MaLoW-Instruct, a large-scale streaming video dataset containing 381K question-answer pairs over 56K videos. We conduct extensive experiments to demonstrate that MaLoW achieves strong performance on OVO-Bench, StreamingBench, and StreamArena. On the backward split of OVO-Bench, MaLoW outperforms prior memory approaches by 3.9% to 11.8% across different video backbones while incurring only modest latency overhead. Beyond streaming video understanding, MaLoW also generalizes to vision-language-action models, improving the action success rate on Simpler WidowX by 9.3%.

# 论文总结：Memory as Weights: Internalizing Long-Term History for Streaming Videos（MaLoW）

## 1. 核心问题与研究动机

- **背景**：流式视觉-语言模型（VLM）需要在视频流持续输入的过程中，同时做到三件事——回溯已经发生的事、理解正在发生的事、并对用户查询保持实时响应。这类能力是流式视频理解、交互式 AI 助手与机器人规划的共同基础。
- **现有做法的根本矛盾**：主流记忆机制（文本摘要、视觉 token 压缩/聚类、分层记忆结构、固定大小缓存、TTT 快权重分支等）本质上都是把历史**压缩后重新塞回输入上下文**，使历史记忆与当前观测在同一上下文窗口中争夺容量。
- **流式场景的三个额外挑战**：
  1. 记忆必须随新观测**增量演化**，而不是每次从完整历史重算；
  2. 历史信息不能**挤占**当前观测的注意力容量；
  3. 记忆机制应带来**极小的推理开销**。
- **核心主张**：与其追问“该存什么、该检索什么”，不如重新考虑“记忆应存放在哪里”——把长期历史直接内化为模型权重，当前观测仍以输入形式进入模型。

## 2. 方法论：MaLoW

### 2.1 核心思想

- 将历史上下文 $C_{0:t-1}$ 内化为随时间演化的轻量 LoRA 权重 $\Delta\theta_t$，当前观测 $C_t$ 与查询 $I_t$ 仍作为输入：
  - $\Delta\theta_t = \Phi(C_{0:t-1}; h_0)$，$R_t = \mathcal{M}_{\theta+\Delta\theta_t}(I_t, C_t)$
- 基座 VLM 的架构与参数**完全冻结**，只有 LoRA 记忆随流演化；$\Phi$ 由单步更新 $f$ 循环复用实现：$(h_t, \Delta\theta_t) = f(h_{t-1}, C_{t-1})$。

### 2.2 单步更新 $f$ 的三个环节

- **① 上下文编码（压缩）**：用 VLM 自身的视觉编码器与分词器得到视频嵌入 $V_{t-1}$ 与时间戳文本嵌入 $T_{t-1}$，与一组可学习查询 $Q$ 拼接后经 4 层自注意力聚合器压缩为紧凑表示 $q_{t-1} = g([V_{t-1}; T_{t-1}; Q])$。
- **② 隐状态更新（双分支）**：$h_t = [m_t; s_t]$
  - $m_t$：用 4 层 DeltaNet（SSM）建模**局部时序依赖**，$(m_t, o_t) = \mathrm{SSM}(q_{t-1}, m_{t-1})$；
  - $s_t$：门控求和作为**全局语义**的跳跃连接，$s_t = s_{t-1} + \beta_{t-1} q_{t-1}$，其中 $\beta$ 为基于相邻块平均池化特征余弦相似度的二值门（阈值 $\beta=0.05$，取自训练集 64,426 次相邻转移的中位数变化点），相似度过高（视觉变化小）的冗余块被置零权重。
- **③ LoRA 解码**：$\Delta\theta_t = h(o_t, s_t)$，即对 $o_t$ 与 $s_t$ 做 RMSNorm 后线性映射，并对 $s_t$ 施加可学习门控 $\alpha$；每个目标模块、每个秩分量有独立输出头，输出 $A_t \in \mathbb{R}^{r\times d_{in}}$、$B_t \in \mathbb{R}^{r\times d_{out}}$，最终 $\Delta\theta_t = \alpha \frac{1}{r} B_t^\top A_t$（lora_alpha=16，秩 8）。
- **注入位置**：MLP 的 gate/up/down_proj + 自注意力 v_proj；对混合注意力架构（Qwen3.5）额外注入 linear_attn.in_proj_qkv；对 MOSS-VL 额外注入 cross-attention 的 v_proj。通过自定义 forward 注入冻结基座。

### 2.3 训练目标与理论支撑

- **损失**：$\mathcal{L} = \mathcal{L}_{ntp} + \gamma \mathcal{L}_{LoRA}$，其中 $\mathcal{L}_{LoRA}$ 按模块对 $|A_s|$、$|B_s|$ 的均值做正则（$\gamma=0.01$），用于抑制记忆权重幅值、保护实时感知能力。
- **关键训练约束**：训练时历史 $C_{0:t-1}$ **不直接输入** VLM，只能通过 $\Delta\theta_t$ 影响预测，梯度经 $\Delta\theta_t$ 回传以优化超网络，迫使记忆只保留对后续交互有用的信息。
- **理论分析（附录 A）**：将历史读取写成线性注意力式的矩阵 $M_H=\sum_i v_i k_i^\top$，其诱导的 MLP 输入变换 $P_H = W_O M_H W_Q$；命题 A.1 证明若用秩 $r$ 分解近似 $M_H$，则令 $\Delta W_g = W_g \hat P_H$、$\Delta W_u = W_u \hat P_H$ 即可精确复现“历史改变后的 MLP 输入”，且更新秩不超过 $r$；并给出截断误差上界、在线增量更新、归一化/softmax 读的局部线性化扩展。作者明确声明这**只是可行性论证，不等价于全上下文注意力**。

### 2.4 配套数据集 MaLoW-Instruct

- 规模：**381K QA / 56K 视频**，来自 14 个底层数据集（CosMo-Cap、YouCook2、Charades、ActivityNet 等）。
- 三阶段流水线：**问题生成器 → 答案生成器 → 验证器**。问题生成器基于完整视频与事件描述生成问题、期望答案与问题时间戳（past / real-time / future 三类）；答案生成器只看时间戳 $t$ 之前的视频作答；验证器比对期望答案、模型答案与事件描述，过滤不一致样本。
- 分布：real-time 46.1%、past 36.4%、future 17.4%；选择题 35.0%、开放题 34.7%、Yes/No 30.0%、计数 14.0%；已过滤与 OVO-Bench 重叠的视频以防泄漏。

  - **优点**：基座覆盖 0.8B–11B 多个规模、多个家族（Qwen / Gemma / VideoChat3 / MOSS），既有离线预训练模型也有流式专用模型，泛化性证据较扎实；消融针对每个关键设计选择逐一验证

、并对每个设计维度给出可解释的结论；训练约束（历史不直接输入 VLM）与附录理论分析形成了“机制—训练—理论”的闭环；VLA 迁移实验说明该方法不局限于视频问答，具备跨任务形态的适用性。
  - **不足与可质疑之处**：
    1. **主表对比的公平性存在张力**：MaLoW 使用了自建的 381K QA 指令数据（含 56K 视频）进行训练，而多数流式基线是在各自原始数据配方下训练的。论文虽在附录/实现细节中说明基线采用官方权重与推荐配置，但“数据规模与领域覆盖不对等”这一混杂因素难以完全排除，尤其是 past/backward 类任务对训练数据中的时序问答分布高度敏感。
    2. **缺少与最强记忆基线的“同数据同基座”对照**：例如在相同 Qwen3-VL-4B 基座上复现 StreamTTT / OASIS 等记忆方法，若能给出该对照，才能把增益更干净地归因于“记忆存入权重”这一设计本身，而非 LoRA 容量或数据优势。
    3. **消融多集中在“组件是否有效”，对“为何有效”的机制性验证偏少**：例如秩 $r$ 的扫描给出了性能曲线，但未系统测量不同秩下记忆权重的有效信息量（如对历史检索式探针的准确率），因此“秩 8 已足够”更像是经验结论而非机制结论。
    4. **长时程证据仍偏薄**：StreamArena HR 仅 877 题、237 视频，L4（>30 分钟）子集样本量在论文中未单独强调，长尾区间结论的统计稳健性有限；且未报告多次运行的方差或置信区间。
    5. **统计报告不完整**：主表与消融多为单次运行结果，缺少标准差、显著性检验；考虑到部分子任务（如 OVO-Bench 的 OJR、FPD）题量较小，1–2 个点的差距可能不具统计意义。
    6. **VLA 实验规模较小**：4 个任务、96 个 episode，且仅在 Bridge 子集上训练，泛化到更复杂操作与更长时程任务的证据不足；也未报告与“全上下文 / 滑动窗口”在相同数据量下的对照细节。
    7. **负结果与失败模式披露不足**：论文对 MaLoW 在何种场景下劣于基线（如需要精确逐帧细节回溯、需引用原始像素/OCR 文本的场景）缺少系统分析，仅在定性部分提及个别案例。

## 6. 主要实验发现

- **实时与回溯的“双高”**：在 OVO-Bench 上，MaLoW 变体在 Real-Time split 与 Backward split 同时取得领先，说明把历史移出上下文并未牺牲当前感知；这与“记忆挤占注意力容量”的动机假设一致。
- **相对全上下文流式模型的优势在长视频上放大**：StreamArena HR 上，随证据-查询间隔从 L1 增至 L4，全上下文基线的退化更明显，而 MaLoW 的下降更平缓，支持“权重化记忆不受上下文窗口硬截断”的论断。
- **规模与家族泛化**：从 0.8B 到 11B、从 Qwen 到 Gemma / MOSS，MaLoW 均带来稳定增益，且小模型上的相对提升更大，暗示该机制对参数容量受限的流式部署场景价值更高。
- **开销可控**：延迟剖析显示，MaLoW 相对基座的额外推理开销主要来自单步 LoRA 生成（一次轻量前向 + 小矩阵构造），量级远低于把历史重新编码进上下文的方案；内存占用随流长度近似常数，而非线性增长。
- **消融结论**：注入 MLP（gate/up/down）比仅注入注意力更有效；SSM 分支负责局部时序、门控跳跃连接负责全局语义，二者互补，去掉任一支均有明显下降；全局语义的“变化门控”比朴素累加更好，说明抑制冗余块对记忆质量关键；刷新频率存在权衡——过密带来冗余与开销，过疏丢失细节。
- **VLA 迁移**：在相同基线与数据下，MaLoW 在 4 个操作任务上整体优于 Q3.5-2B-MLP，表明“历史内化为权重”对需要长时程状态跟踪的具身任务同样成立。

## 7. 局限性与批判性讨论

- **表达能力的理论上界**：作者已在附录中明确，命题 A.1 只说明“历史诱导的 MLP 输入变换”可被低秩近似复现，属于**可行性论证**而非等价性证明。因此 MaLoW 在原则上无法表达需要精确检索原始 token（如逐字 OCR、精确计数、细粒度空间关系）的记忆，这与实验中计数类问题占比与表现的相对弱势相呼应。
- **信息瓶颈的位置**：历史先经 4 层聚合器压缩为 $q_{t-1}$，再经 SSM 与门控跳跃连接形成 $h_t$，最后解码为 LoRA。三级压缩中任一环节的不可逆丢失都无法在后续恢复；论文未给出“压缩率—任务性能”的系统曲线，难以判断瓶颈主要在哪一级。
- **训练与推理的一致性风险**：训练时历史严格不进入上下文，推理时同样如此，这一点设计自洽；但训练数据的时间戳 $t$ 是人工构造的切分点，真实流式部署中块边界、时间戳噪声与丢帧都可能使 $q_{t-1}$ 分布偏移，论文未做此类鲁棒性测试。
- **“权重即记忆”的可解释性与可编辑性**：把记忆编码进 LoRA 后，删除或修正某段历史记忆需要反向求解 $\Delta\theta$，远难于删除一条文本摘要；这对隐私合规（如用户要求删除某段录像）与错误纠正构成实际障碍，论文未讨论。
- **与检索式记忆的正交性未被利用**：MaLoW 与外部向量库检索并非互斥，论文未探索“权重记忆 + 轻量检索”的混合方案，这可能是在细粒度回溯任务上补齐短板的最直接路径。
- **评测覆盖**：三个基准均以问答形式度量，缺少对“记忆是否被正确使用”的过程性诊断（如探针任务：给定历史中的某个事件，检验模型能否在无当前视觉线索时报告）；也未评估多轮交互中记忆的持续演化质量。

## 8. 总体评价

- **贡献定位**：论文的核心贡献不在于新的压缩算法或新的记忆结构，而在于**重新定位记忆的存放位置**——把长期历史从“输入空间”搬到“参数空间”，并用超网络式的单步更新使其可增量演化。这一视角转换清晰、动机自洽，且与现有“上下文工程”路线形成互补而非替代关系。
- **工程完整度较高**：从数据构建（三阶段生成-验证流水线）、训练约束设计、到多基座/多基准验证与 VLA 迁移，形成了较完整的证据链；延迟与内存分析也回应了流式部署最关心的实际约束。
- **证据强度**：结论方向可信（实时与回溯兼顾、长时程优势随间隔放大、跨规模跨家族泛化），但**归因强度中等**——由于缺少同基座同数据的记忆基线对照、缺少方差与显著性报告，以及长时程子集样本量有限，"权重化记忆优于上下文记忆"这一强主张仍需更严格的对照实验支撑。
- **适用边界**：最适合“需要长时程粗粒度情景记忆 + 严格实时性 + 内存受限”的流式场景；不适合“需要精确逐字/逐帧回溯、需要可删除可审计记忆”的场景。
- **后续方向建议**：(1) 同基座同数据下与 StreamTTT / OASIS 等直接对照；(2) 权重记忆与轻量检索的混合架构；(3) 记忆的可编辑与遗忘机制；(4) 压缩率-性能的系统刻画与瓶颈定位；(5) 真实流式（含丢帧、时间戳噪声）下的鲁棒性评测。
