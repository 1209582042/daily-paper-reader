## 摘要
主动流式视频问答要求模型持续监测输入流，并自主决定何时发言、说什么以及是否输出响应。现有流式系统面临一个根本困难：保留长视觉历史代价高昂，而丢弃它们又可能导致漏检事件和重复响应。我们提出 ProV-Mem，一个围绕冻结 VLM 主干构建的免训练主动记忆框架。ProV-Mem 将主动决策分解为三个轻量级记忆层：时间触发记忆控制何时查询主干，并从长时间静默中恢复；指令记忆通过固定的提示先验引导说什么，以生成简洁且视觉有据的内容；情节记忆通过过滤近重复响应来决定是否输出。在理想化的条件充分性假设下，我们推导出一个逐阶段近似界，将分解过程与全状态联合策略联系起来。我们进一步引入代价感知曲线下面积（CAUC），它通过显式折扣冗余、过于频繁和不必要长的输出，扩展了 PAUC。在 ProactiveVideoQA 的四个场景上的实验表明，ProV-Mem 在所有场景中取得最佳 CAUC，并在 WEB、EGO 和 TV 上取得最佳 PAUC，同时保持较低的每响应推理延迟。

## Abstract
Proactive streaming video question answering requires a model to continuously monitor an incoming stream and autonomously decide when to speak, what to say, and whether to emit a response. Existing streaming systems face a fundamental difficulty: retaining long visual histories is costly, whereas discarding them can lead to missed events and repeated responses. We propose \textbf{ProV-Mem}, a training-free proactive memory framework built around a frozen VLM backbone. ProV-Mem decomposes the proactive decision into three lightweight memory tiers: a temporal-trigger memory controls when to query the backbone and recovers from prolonged silence, an instructional memory guides what to say through a fixed prompting prior for concise and visually grounded generation, and an episodic memory determines whether to emit by filtering near-duplicate responses. Under an idealized conditional-sufficiency assumption, we derive a stagewise approximation bound relating the decomposed process to a full-state joint policy. We further introduce Cost-Aware Area Under the Curve (\textbf{CAUC}), which extends PAUC by explicitly discounting redundant, overly frequent, and unnecessarily long emissions. Experiments on the four scenarios of ProactiveVideoQA show that ProV-Mem achieves the best CAUC across all scenarios and the best PAUC on WEB, EGO, and TV, while maintaining low per-response inference latency.

## 1. 核心问题与研究动机

- **范式转变**：视频-语言模型正从"回顾式"（看完整个视频再回答）转向实时流式应用（直播审核、具身智能体），但传统流式 benchmark 仍是"问题驱动"的被动交互，每一轮都需要显式用户查询。
- **Proactive-VQA 的新要求**：智能体需在**无显式提示**下持续监测无界视频流，并自主决定三件事——**何时说**（timing）、**说什么**（content）、**是否输出**（necessity），且动作不可撤销、受严格实时约束。
- **双重困境之一：被动记忆**。为保吞吐，现有系统丢弃原始帧，导致缺乏显式时序视觉历史；训练型触发头基线因此出现严重的**模板化重复与覆盖缺口**（漏检目标窗口）。轻量特征缓存/hidden state 只是"被动"存储，不参与决策治理，一旦退化则三重控制同时崩塌。
- **双重困境之二：有漏洞的指标**。主指标 PAUC 按真值窗口对每次发射的质量积分，允许"过度触发"的退化策略通过**累积窗口时长**而非提升信息密度来虚高分数，形成结构性 reward hacking。
- **核心主张**：从"被动缓存"转向"**主动记忆**"——每个记忆层不只存上下文，而是**主动治理流式决策的一个独立轴**。作者据此提出免训练的 ProV-Mem，并配套提出代价感知指标 CAUC 以堵住评估漏洞。

## 2. 方法论

### 2.1 问题形式化
- 流：$V=(x_1,\dots,x_T)$，查询 $q$ 在 $t=0$ 给出，真值窗口 $\{(s_j,e_j,r_j^*)\}$ **仅用于事后评估**。
- 每步观测因果前缀 $X_{\le t}$ 与已发射历史 $H_{<t}$，输出不可撤销动作 $a_t\in\Sigma^*\cup\{\varnothing\}$；全因果状态 $S_{\le t}=(X_{\le t},q,H_{<t})$。

### 2.2 决策分解与理论保证
- **隐决策链分解**（非最终动作分布分解）：
  $$P^{\text{dec}}_\delta(f_t,\hat r_t,e_t\mid S_{\le t})=P_{\text{trig}}(f_t\mid M_{\text{trig},t})\cdot P_{\text{gen}}(\hat r_t\mid f_t,M_{\text{inst}},z_t)\cdot P_{\text{emit}}(e_t\mid f_t,\hat r_t,M_{\text{ep},t})$$
  最终 $a_t=\hat r_t$ 当且仅当 $f_t=e_t=1$，否则 $a_t=\varnothing$。
- **假设 1（条件充分性）**：三个局部表示分别保留触发、生成、发射三个阶段的条件分布——作为理想化参照条件。
- **引理 1（逐阶段近似界）**：在共同状态反事实评估下，
  $$U(\delta^*_{\text{joint}})-U(\delta^*_{\text{dec}})\le 2cT(\epsilon_{\text{trig}}+\epsilon_{\text{gen}}+\epsilon_{\text{emit}})$$
  证明思路：每步效用有界 $c$ + 最终动作分歧必源于至少一个阶段分歧（并集界）+ 对时间求和。表面-语义碰撞率 $\rho$ 作为可解释诊断量单列，不计入界内。

### 2.3 三层非参数记忆（常数规模、免训练、冻结骨干）
- **时间触发记忆** $M_{\text{trig},t}=(p_t,c_{\text{sil},t})$：$p_t$ 为模触发步长 $K$ 的节奏相位，$c_{\text{sil}}$ 为连续未发射的常规触发机会计数。
  确定性门控：$f_t=\mathbb{1}[p_t=0\ \vee\ c_{\text{sil},t}\ge\kappa]$——每 $K$ 个采样帧查询一次，静默达 $\kappa$ 次则强制恢复查询 $P^{\text{force}}_{\text{sys}}$。
- **指令记忆** $M_{\text{inst}}$：固定提示先验，约束"单句、≤15 词、只描述当前窗口可见动作、禁开场白/推测、统一规范词汇、无事件则输出 *No Reply*"，以降低 $\epsilon_{\text{gen}}$ 与 $\rho$ 并配合下游词汇过滤。
- **情节记忆** $M_{\text{ep},t}=(\bar r_{\text{last},t},\tau^{\text{emit}}_{\text{last},t})$：存最近发射响应的前 $L$ 字符与时间戳；前缀级归一化 LCS 相似度
  $$s=2\,\mathrm{LCS}(\bar{\hat r}_t,\bar r_{\text{last},t})/(|\bar{\hat r}_t|+|\bar r_{\text{last},t}|)$$
  发射门：$e_t=\mathbb{1}[f_t=1\wedge(s<\eta\ \vee\ \tau_t-\tau^{\text{emit}}_{\text{last}}>\tau_{\text{sup}})]$，即词面相近者须经冷却期后才能重发。
- **层间反馈环**：发射→更新情节状态并清零静默计数；常规触发未发射→静默计数递增；触发恢复→重置计数。所有状态定长/有界，故为轻量 wrapper。

### 2.4 CAUC 指标
- 代价调整质量：$\tilde q_t=\big[q_t(1-\alpha P_{\text{red},t}-\beta P_{\text{freq},t}-\gamma P_{\text{len},t})\big]_+$
  - 冗余惩罚 $P_{\text{red}}$：与**完整发射历史**的最大前缀 LCS 相似度（比在线门控更严格，用全历史）；
  - 频率惩罚 $P_{\text{freq}}=\exp(-\Delta\tau_t/\tau_{\text{cooldown}})$；
  - 长度惩罚 $P_{\text{len}}=\max(0,|a_t|_{\text{tok}}-L_{\text{ref}})/L_{\text{ref}}$。
- 复用 PAUC 的时间积分流程与时效-正确性权衡参数 $\omega$，仅替换 $q_t\to\tilde q_t$，分数缩放至 $[0,100]$。
