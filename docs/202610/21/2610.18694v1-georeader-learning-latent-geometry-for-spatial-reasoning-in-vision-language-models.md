## 摘要
视觉语言模型（VLM）难以处理那些在RGB观测中仍然隐含的度量关系和多视角关系。几何基础模型能够从RGB中恢复这种结构，但现有方法要么将估计出的特征与视觉token融合，并仅通过问答任务学习如何使用这些特征，要么将VLM的潜在表示与几何特征对齐。然而，捕获几何并不保证其被使用：将某个已发布特征对齐模型中对齐后的潜在表示置零，其准确率保持不变。我们提出GeoReader，一个为能够读取几何表示的VLM学习几何表示的框架。首先，我们训练轻量级几何读取器以生成连续的输入token，并用由冻结VLM解码出的几何描述对其进行监督，从而使读取器以目标模型本就能读取的形式表达几何。随后，我们冻结读取器以保持这一接口，同时在空间问答任务上微调VLM，并以问题为条件进行几何注入。几何描述仅作为训练目标：在推理时，VLM直接根据连续的几何token作答，而无需生成几何思维链。在从RGB图像预测几何的情况下，我们的方法在Qwen3-VL-4B上于MindCube-Tiny达到94.3，并在使用多源问答混合数据时，于Qwen3.5-9B上在六个额外空间基准上平均达到72.5。这些结果表明，有用的几何表示应是接收模型能够使用的表示，而不仅仅是能够从中重建出几何的表示。

## Abstract
Vision-language models (VLMs) struggle with metric and multi-view relationships that remain implicit in RGB observations. Geometry foundation models recover this structure from RGB, but existing methods either fuse the estimated features with visual tokens and learn to use them from question answering alone, or align VLM latents with geometry features. Capturing geometry, however, does not ensure its use: zeroing the aligned latents of a released feature-alignment model leaves its accuracy unchanged. We introduce GeoReader, a framework that learns geometric representations for the VLM that reads them. First, we train lightweight Geometric Readers to produce continuous input tokens, supervising them with geometry descriptions decoded by a frozen VLM, so that the Readers express geometry in a form the target model can already read. We then freeze the Readers to preserve this interface while fine-tuning the VLM on spatial QA, with geometry injection conditioned on the question. Geometry descriptions serve only as training targets: at inference, the VLM answers directly from the continuous geometric tokens without generating a geometry chain of thought. With geometry predicted from RGB images, our approach reaches 94.3 on MindCube-Tiny with Qwen3-VL-4B and, with a multi-source QA mixture, an average of 72.5 across six additional spatial benchmarks with Qwen3.5-9B. These results suggest that a useful geometric representation is one the receiving model can use, not merely one from which geometry can be reconstructed.

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）在通用多模态理解上进步显著，但在**度量几何**（距离、尺寸、深度）与**多视角关系**（相机运动、视角变换）上仍明显不足，而这恰恰是具身智能在 3D 世界中行动的基础能力。这类信息在 RGB 观测中是**隐含**的，需要从 2D 推断 3D 结构。
- **已有两条技术路线及其缺陷**：
  - **(a) 仅靠 QA 的几何融合**：把几何基础模型（VGGT、DUSt3R、Depth Anything 3 等）提取的特征与视觉 token 拼接，只靠下游问答损失让 VLM"自己学会用"。问题在于：答案监督并不告诉模型几何特征究竟编码了什么，模型可能学不会解释它。
  - **(b) 特征对齐**：把 VLM 生成的潜在表示与几何特征做对齐（如 3DThinker 用 L2 损失对齐 VGGT 特征）。问题在于：对齐的是"与外部目标的相似度"，而非"接收模型能否读懂"。
- **关键实证反例（论文的核心洞察）**：把已发布 3DThinker 检查点的对齐潜变量**置零**，MindCube-Tiny 准确率几乎不变（62.7% → 62.9%）；跨问题**交换**潜变量也只降到 61.5%。注意力分析显示其答案 token 对几何潜变量的注意力份额仅 0.2%–0.4%。这说明 **"捕获几何"不等于"使用几何"**。
- **论文主张**：有用的几何表示应当是**接收模型（receiving VLM）能够直接读取并据以作答**的表示，而不仅是"能从中重建出几何"的表示。为此需要先把几何转成 VLM 能用语言能力理解的形式，再让它学会在下游任务中使用。

## 2. 方法论

### 2.1 核心思想
采用**两阶段解耦**：Stage 1 只解决"几何如何变成 VLM 可读的输入"（学接口）；Stage 2 只解决"VLM 如何针对当前问题使用这些输入"（学应用）。几何描述只作为 Stage 1 的**训练目标**，推理时不生成任何几何思维链。

### 2.2 几何 token 编码（Geometric Reader）
- 每个视角 $i$、每种几何信号 $m$（相机位姿、深度图）配一个轻量 Reader $E^m$，输出**每视角一个**连续嵌入 $Z^m_i \in \mathbb{R}^{1\times d}$。
- 流程：先把原始信号转成与 RGB 合并 token 同网格的**逐 patch 描述子** $U^m_i$（相机 20 维：图像坐标、世界射线、参考系射线、平面位移、朝向、内参、视角序号、参考标志、时间位置；深度 5 维：坐标、视角序号、$\log(1+z)$、有效像素比例）→ LN+MLP 得 memory $M^m_i$ → 一个**跨视角共享的可学习 query** $r^m$ 经 2 个 Transformer 解码块（cross-attn + self-attn + FFN）读出 → 线性投影。
- 关键设计：Reader **只看几何、不看 RGB**，且**不做跨视角注意力**（视角作为独立 batch 项），跨视角关系已编码在"参考系相对"的描述子里；不同信号用独立权重的 Reader，保留各自结构。

### 2.3 Stage 1：冻结 VLM 的可读性训练
- 给定图像 $I$、几何 token $Z^m$ 和固定指令，让**参数冻结**的 VLM 以 teacher forcing 预测该信号的几何描述 $y^m$（如"相比图 1，图 2 的观察者向右移 0.4 米、后退 0.1 米、左转约 23 度"；"吉他（左）在 1.7 米处"）。
- 损失仅在**几何内容位置** $T^m$ 上计算（距离、方向、角度等），模板词被排除：
  $$\mathcal{L}^m_{\text{read}} = -\frac{1}{|T^m|}\sum_{t\in T^m}\log p_\theta(y^m_t \mid I, Z^m, y^m_{<t}),\quad \theta\ \text{冻结}$$
- 梯度穿过冻结 VLM 只更新 Reader，从而迫使 Reader 用"目标模型已有的语言能力"来表达几何。
- **Pair 监督**（相对 group 监督的关键改进）：对每个"参考–目标"视角对 $(1, i)$ 单独前向，只输入这两视角的几何，让描述只能由这两个 token 解释，消除"哪个 token 承载关系"的歧义（消融：77.8% → 89.2%）。

### 2.4 Stage 2：问题条件化的几何注入
- **冻结 Reader**：QA 监督并不要求 Reader 保持 Stage 1 学到的几何关系，若继续更新会破坏接口（消融：微调 76.4% vs 冻结 89.2%）。
- **两遍前向**：
  - **Read pass**：只输入 RGB + 问题，取最后一层最后一个有效问题 token 的隐状态 $h_q$（已聚合全部视觉与问题上下文，梯度截断）。
  - **Answer pass**：在问题之后插入几何 token，序列为 $[X_1..X_V, Q, \{\tilde Z^m\}, a]$。
- **几何注入器**：对每个信号，用零初始化的 tokenwise 仿射适配器 $P^m$ 拟合冻结 Reader 输出，再用由 $h_q$ 经 LayerNorm+MLP+sigmoid 得到的**路由门** $g_m$ 调制，并加上槽位嵌入 $B^m$：
  $$\tilde Z^m = B^m + g_m P^m(Z^m),\qquad g_m = \sigma(R^m(h_q))$$
  信号缺失时 $g_m=0$，仅保留槽位嵌入，输入布局不变。
- **训练/推理**：只对答案做 next-token 交叉熵，微调语言模型与注入器，冻结 Reader 与视觉编码器；推理时 answer pass 复用 read pass 的 KV cache，只额外计算几何 token 与答案。
- **几何来源**：主实验用 Depth Anything 3（DA3NESTED-GIANT-LARGE-1.1）从 RGB 预测相机位姿与深度；消融用 MindCube 标注认知地图导出的几何（仅取 2D 网格位置与离散朝向，不用物体标注、推理链或答案）。

## 4. 资源与算力

- **明确给出的**：
  - Stage 1：**4 张 GPU**，10 个 epoch，每 GPU batch size 1，无梯度累积，学习率 $10^{-4}$，VLM 冻结。
  - Stage 2（主模型）：**4 张 GPU**，2 个 epoch（约 135K 数据），每 GPU batch 1、梯度累积 2（等效 batch 8），学习率 $2\times10^{-5}$，100 warm-up，线性衰减，weight decay 0.01，bf16 + AdamW。
  - MindCube 消融：**单张 GPU**，10 个 epoch（100,000 优化步），batch 1。
  - 延迟测量在 **NVIDIA H200** 上进行（batch size 1，5 个预热样本后对 1,050 题取平均）。
- **未明确说明的**：**GPU 具体型号与总卡时/总 GPU-hours 未交代**（H200 仅用于推理延迟基准）；不同 backbone（3B 到 9B）的总训练成本、单次完整训练墙钟时间也未报告。这是一处可复现性上的信息缺口。
