## 摘要
空间智能要求智能体主动获取视觉证据，并将观测整合为对三维世界的一致表征。然而，空间问答难以为模型能否通过自主探索构建准确的度量地图提供充分证据。我们提出 SpatialScout，一个用于评估视觉语言模型（VLM）智能体在主动物体级 3D 建图任务上表现的基准。SpatialScout 包含 80 个多样化室内场景，涵盖 3,140 个目标物体。给定物体清单、RGB 观测、相机标定和相机位姿，智能体控制相机探索每个场景，并在共享坐标系中估计物体中心。该任务要求在有限交互预算下协调视角选择、跨视角关联、几何估计和地图修正。评估通过物体尺度重叠分数联合衡量定位精度和目标覆盖率，并对缺失预测进行惩罚。针对前沿 VLM 的实验揭示了显著局限：评估中最强的模型 Claude Opus 5.5 取得 41.71% 的平均重叠分数，其中 47.23% 的目标超过交并比（IoU）阈值 0.5，仅 3.25% 超过 0.9。这些结果表明，在恢复粗略物体布局与构建完整、精确的度量地图之间仍存在显著差距。SpatialScout 为开发通过主动感知构建可靠 3D 空间表征的智能体提供了定量测试平台。代码见 https://github.com/JesseZZZZZ/SpatialScout。

## Abstract
Spatial intelligence requires agents to actively acquire visual evidence and integrate observations into a coherent representation of the three-dimensional world. Yet spatial question answering offers limited evidence of whether models can construct accurate metric maps through autonomous exploration. We introduce SpatialScout, a benchmark for evaluating vision-language model (VLM) agents on active object-level 3D mapping. SpatialScout comprises 80 diverse indoor scenes containing 3,140 target objects. Given an object inventory, RGB observations, camera calibration, and camera poses, agents control a camera to explore each scene and estimate object centers in a shared coordinate frame. The task requires coordinating viewpoint selection, cross-view association, geometric estimation, and map revision under bounded interaction budgets. Evaluation jointly measures localization accuracy and target coverage through object-scale overlap scores that penalize missing predictions. Experiments with frontier VLMs reveal substantial limitations: the strongest evaluated model, Claude Opus 5.5, achieves a mean overlap score of 41.71%, with 47.23% of targets exceeding an intersection-over-union (IoU) threshold of 0.5 and only 3.25% exceeding 0.9. These results reveal a substantial gap between recovering coarse object layouts and constructing complete, precise metric maps. SpatialScout provides a quantitative testbed for developing agents that build reliable 3D spatial representations through active perception. Code is available at https://github.com/JesseZZZZZ/SpatialScout.

## 1. 核心问题与研究动机

- **背景**：空间智能要求具身智能体主动观察环境、消解遮挡与视角歧义、推断物体位置与空间关系，并把多视角证据整合为一致的三维表征。
- **现有基准的局限**：当前空间智能评测多采用图像/视频问答（VSR、BLINK、VSI-Bench、OpenEQA、E3VS-Bench、ESI-Bench、S³-Bench 等）。作者指出这类评测存在三类问题：
  - 有限选项使模型可凭猜测或排除法答对；
  - 语言先验与答案分布偏置可让模型绕过真正的空间理解；
  - 问答形式无法覆盖"自主采集证据—更新空间表征—指导后续动作"的闭环。
- **已有相关工作的不足**：Theory of Space 关注离散认知地图，IR3D-Bench 关注由给定图像逆渲染，SceneActBench 关注可执行场景生成；它们都未把"在连续三维空间中主动探索并输出物体级度量地图"作为直接评测目标。
- **论文的核心问题**：VLM 智能体能否通过主动探索，把局部观测转化为**准确且完整**的度量空间表征？为此作者提出 **SpatialScout** 基准，以"主动物体级三维建图"作为评测任务。

## 2. 方法论

### 2.1 核心思想
- 将空间智能评测从"问答正确率"转为**显式三维地图构建**：智能体在有限交互预算下控制相机探索场景，最终提交每个目标物体中心在统一坐标系下的三维坐标。
- 任务形成"观测 → 推理 → 决策 → 再观测"的闭环：当前地图估计决定下一步看哪里，新视角又反过来修正地图。

### 2.2 任务定义
- **输入**：物体清单 E = {(i, c_i, g_i)}（实例 ID、类别、等价组）、RGB 观测、相机内参与位姿、目标区域半径 r = max_i ‖p_i‖₂。
- **输出**：估计地图 P̂ = {p̂_i}，每个 ID 一个中心估计；同一等价组内 ID 可互换。
- **几何真值**：目标中心定义为渲染几何的**世界轴对齐包围盒（AABB）中点**；对关节物体取各连杆几何并集。参考中心需先在世界系构造包围盒，再变换到任务系：
  - p_i = R₀ᵀ · [(b_i⁻ + b_i⁺)/2 − o₀]，其中 o₀、R₀ 为初始相机的世界位置与相机到世界旋转。
- **坐标系**：原点为初始相机位置，+x 沿初始光轴前向，+y 指向初始左侧，+z 沿初始上方；若初始相机有俯仰，任务"上轴"与世界竖直方向不一致。
- **关键难点**：三角化得到的表面点与 AABB 中心通常不是同一点，智能体必须结合物体观测到的空间范围推断中心。

### 2.3 交互接口（10 个工具，均不泄露真值）
- 查询类：`list_entities`、`get_camera_pose`、`get_camera_intrinsics`；
- 控制类：`set_camera_position`（绝对定位）、`move_camera`（相对平移 ≤1 m）、`rotate_camera`（yaw/pitch，最终 pitch 限制在 ±85°）；
- 感知类：`capture_image`（512×512 渲染，交付 JPEG 最长边 ≤384 px）；
- 几何类：`triangulate_observations`（多视角三角化）；
- 提交类：`submit_positions`（可批量提交/修订，空批量可查看当前地图）、`finish_mapping`（冻结地图并结束）。

### 2.4 三角化算法
- 给定相机原点 o_k 与单位视线方向 d_k，定义投影矩阵 A_k = I − d_k d_kᵀ；
- 最小化到各视线的垂直距离平方和：p̂_tri = argmin_p Σ_k ‖A_k(p − o_k)‖₂²；
- 正规方程闭式解：p̂_tri = (Σ_k A_k)⁻¹ (Σ_k A_k o_k)；
- **有效性检查**：至少 2 个视角、相机基线 ≥5 cm、Σ A_k 条件数 ≤10⁶、每条射线满足前向性 d_kᵀ(p̂ − o_k) > 0；
- **警告条件**：最大视角夹角 <3°、RMS 残差 >0.1 m、或估计点超出 r+0.5 m；工具返回残差与最大夹角供智能体判断。
- 作者强调：低残差只说明几何一致，**不保证对应的是同一物理特征**，也不保证该点就是物体中心。

### 2.5 预算与评分
- **预算**：每回合 B = 100 次模型调用、V = 100 张采集图像（含初始图）；一次调用可顺序执行多个工具；采集上限耗尽后仍可用剩余调用推理与提交。
- **匹配**：在等价组内做最小总欧氏距离的一对一分配（Crouse 的矩形分配算法）。
- **指标**：
  - 平均中心误差（m）、中位数、RMSE；
  - 3D IoU：将参考包围盒平移至预测中心后计算，对最短边做 ϵ = 0.01 m 下限正则化；
  - 严格阈值命中率 τ ∈ {0, 0.5, 0.9}，每个阈值单独做"先最大化命中数、再最大化总重叠"的匹配；
  - 同时报告 **all targets**（遗漏计 0）与 **submitted targets** 两个口径；
  - 聚合方式为 object-micro（按目标数加权），另有 scene-macro 版本。
- **遗漏惩罚**：L_scene = [Σ_{i=1..M} e_i + λ(N − M)] / N，默认 λ = 5 m；可分解为 L = C·ē + (1−C)·λ，从而把覆盖率与定位误差的影响分开。
- **无 RGB 基线**：原点策略（全部提交 0）场景级损失 3.113 m；均匀球采样策略 4.701 m。
