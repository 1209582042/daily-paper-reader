# ABSTRACT 

Proactive streaming video question answering requires a model to continuously monitor an incoming stream and autonomously decide when to speak, what to say, and whether to emit a response. Existing streaming systems face a fundamental difficulty: retaining long visual histories is costly, whereas discarding them can lead to missed events and repeated responses. We propose ProV-Mem , a training-free proactive memory framework built around a frozen VLM backbone. ProV-Mem decomposes the proactive decision into three lightweight memory tiers: a temporal-trigger memory controls when to query the backbone and recovers from prolonged silence, an instructional memory guides what to say through a fixed prompting prior for concise and visually grounded generation, and an episodic memory determines whether to emit by filtering near-duplicate responses. Under an idealized conditional-sufficiency assumption, we derive a stagewise approximation bound relating the decomposed process to a full-state joint policy. We further introduce Cost-Aware Area Under the Curve ( CAUC ), which extends PAUC by explicitly discounting redundant, overly frequent, and unnecessarily long emissions. Experiments on the four scenarios of ProactiveVideoQA show that ProV-Mem achieves the best CAUC across all scenarios and the best PAUC on WEB, EGO, and TV, while maintaining low per-response inference latency. 

# 1 INTRODUCTION 

Recent advances in video-language models (VLMs) (Lin et al., 2024; Maaz et al., 2024; Li et al., 2024) have driven a paradigm shift from retrospective video understanding (Xu et al., 2016; Lei et al., 2018) to real-time streaming applications, such as live moderation (Xu et al., 2026) and embodied agents (Driess et al., 2023; O’Neill et al., 2024). Unlike traditional passive streaming benchmarks where explicit user queries drive every turn, Proactive Video Question Answering (Proactive-VQA) (Wang et al., 2025a) requires an agent to continuously monitor an unbounded video stream without explicit prompts. Under strict real-time constraints, the agent must autonomously determine the timing (when to speak), content (what to say), and necessity (whether to emit) of each response, integrating trigger control directly into the task formulation. 

A dual predicament: passive memory and a leaky metric. To sustain real-time throughput on unbounded streams, existing architectures typically discard raw video frames, which deprives the model of explicit temporal visual history. This lack of historical awareness causes trained-head baselines to exhibit severe templated repetitions and coverage gaps, frequently missing critical events across target windows, as shown in Figure 1(a). Latest pipelines attempt to mitigate this by relying on lightweight feature caches or hidden states to implicitly represent past context. However, these implicit representations remain fundamentally passive: they store compressed context but play no active role in governing when, what, or whether to respond, so any degradation inevitably causes all three controls to collapse simultaneously. Crucially, this systemic failure is further masked by a structural loophole in the standard evaluation protocol. The primary metric, Proactive Area Under the

Our solution: from passive caching to proactive memory. The root cause of implicit context decay is that a passive buffer plays no structural role in decision-making, forcing a monolithic head to recover timing, content, and redundancy judgements from compressed history alone. We propose a fundamentally different paradigm: proactive memory , in which each memory tier does not merely store context but actively governs a distinct axis of the streaming decision. We instantiate this paradigm as ProV-Mem , a training-free framework comprising three constant-size, non-parametric proactive memory tiers sharing a frozen VLM backbone. A temporal-trigger memory actively controls 

when to speak via deterministic gating over a compact timestamp state, with a silence-recovery for re-engagement; an instructional memory actively shapes what to say by imposing a canonical surface-form prior that maximises visual grounding and aligns generations with downstream lexical filtering; and an episodic memory actively decides whether to emit by caching the latest response and filtering redundancy via character-level similarity. Because each tier maintains constant-size state rather than raw-frame buffers, ProV-Mem eliminates coherence degradation and reduces cross-scenario adaptation to tuning a few interpretable scalars. We further show that these three proactive memory tiers can be optimized independently, with an approximation gap characterized by three stagewise discrepancy terms. Finally, we introduce Cost-Aware Area Under the Curve (CAUC), a metric that penalises redundancy, excessive frequency, and token inefficiency to close the evaluation loophole. 

Experimental success and contributions. Experiments on the ProactiveVideoQA benchmark (Wang et al., 2025a) show that ProV-Mem consistently outperforms existing baselines. Without scenario-specific fine-tuning, the framework achieves state-of-the-art proactive performance while maintaining low response latency. In summary, our main contributions are threefold: • We propose ProV-Mem, a proactive memory framework factorising the proactive decision function into three independent memory stages to enable seamless cross-scenario adaptation. • We expose a structural reward-hacking loophole in existing evaluation metrics and propose CAUC, a rigorous cost-aware metric that penalises redundancy, chatter frequency, and token inefficiency at each emission. • We provide comprehensive empirical evidence showing that ProV-Mem achieves excellent perfor-mance on ProactiveVideoQA under both standard and cost-aware evaluation. 

# 2 RELATED WORK 

Proactive-VQA and Streaming Video-Language Models . Passive VQA s, in which the model consumes a full video before answering, has been extensively studied (Lei et al., 2020; Zhang et al., 2023). Wang et al. (2025a) depart from this paradigm by requiring frame-by-frame streaming with autonomous decisions on timing, content, and emission necessity. Broader benchmarks such as StreamingBench (Lin et al., 2026) and OVOBench (Niu et al., 2025) advance online video understanding but remain question-driven, leaving autonomous firing outside their protocol. Prompt-Based Control and Memory-Augmented Models Since CLIP (Radford et al., 2021) and Flamingo (Alayrac et al., 2022), a substantial line of work shapes frozen VLM behaviour at inference time via system prompts and in-context examples, where grounded-detail and persona prompts (You et al., 2024; Maaz et al., 2024) elicit specificity or stylistic surface form. In parallel, a memory-augmented lineage attaches explicit memory modules read at inference to modulate generation, including MemoryBank (Zhong et al., 2024) which stores summarised interactions in a vector database, and Memorizing Transformers (Wu et al., 2022) and RETRO (Borgeaud et al., 2022) which retrieve nearest-neighbour examples during generation. These two lineages are typically pursued in isolation, and the memory-augmented one is moreover parametric, requiring target-domain training and retrieval-time operations that block the streaming forward pass; the absence of a single non-parametric formulation that unifies inference-time prompting and explicit memory while staying backbone-agnostic and streaming-compatible is precisely the gap our work targets.

To evaluate the efficacy of our ProV-Mem, we compare ProV-Mem against representative baselines. As shown in Table 1, the results expose the structural limitations of parametric streaming architec-tures across three dimensions. First, online models equipped with explicit streaming supervision are consistently outperformed by static offline baselines on multiple scenarios, a failure that traces to a fundamental architectural constraint: parametric designs must compress long-horizon visual history 6Published as a conference paper at ICLR 2027 into a fixed-capacity hidden state to sustain low latency, and this compression irreversibly degrades the representational fidelity required for complex video reasoning. ProV-Mem circumvents this capacity-latency tension by externalising temporal state management into non-parametric memory tiers, leaving the representational capacity of the frozen backbone intact. Second, the cross-domain performance collapse exhibited by RL-trained trigger policies reveals a deeper generalisation defi-ciency: reinforcement learning overfits trigger thresholds to the temporal statistics of the training distribution, and any shift in event density or temporal structure between domains causes the learned trigger head to fail. Third, the systematic divergence between PAUC and CAUC across competing baselines provides evidence of metric reward-hacking: because PAUC does not penalise redundant emissions, several systems opportunistically over-trigger on detected segments to inflate their scores, while the cost-aware CAUC metric corrects this inflation and restores the true performance ordering. The fact that ProV-Mem simultaneously leads on both metrics across three of the four scenarios suggsets that its gains arise from precise content management and semantic deduplication rather than unconstrained firing frequency. The main exception is the VAD PAUC score, which suggests that anomaly detection may require stronger parametric event priors than surface-level lexical memory can provide. This result marks the current boundary of the non-parametric design and points to the temporal memory tier as the most promising direction for future extension. 4.3 ABLATION STUDY

To assess whether ProV-Mem generalizes across backbone scales, we evaluate Qwen2.5-VL at 3B, 7B, and 32B parameters with fixed memory hyperparameters. Figure 3 reveals two key findings. First, the baseline exhibits non-monotonic scaling curves on several scenarios, a symptom of its monolithic design. As backbone capacity grows, the implicit context buffer must simultaneously handle temporal reasoning and semantic generation, and these two objectives interfere under the pressure of more complex representations, causing accuracy to plateau or regress on high-density streams. ProV-Mem, by contrast, scales monotonically across all scenarios because the non-parametric memory tiers absorb all temporal state management externally, allowing the backbone to translate increased capacity purely into stronger semantic grounding without concurrently maintaining memory state. Second, the computational efficiency advantage conferred by the temporal-trigger gate compounds with scale. By suppressing redundant backbone invocations on silent or uninformative windows, ProV-Mem reduces its effective inference workload sub-linearly relative to the baseline, and this saving becomes increasingly pronounced as the per-forward-pass cost rises with parameter count. Taken together, these results demonstrate that ProV-Mem functions as a structural scaffold that converts backbone scaling into monotonic quality improvement while bounding the growth rate of computational overhead, two properties that parametric streaming designs cannot provide at the architectural level regardless of the underlying model size. 4.5 SENSITIVITY OF MEMORY HYPERPARAMETERS 

Effect of similarity threshold. The similarity threshold governs a fundamental trade-off between two error terms in the suboptimality bound. Tightening it reduces the collision rate ρ but risks suppressing semantically novel candidates and inflating ϵgen , while relaxing it admits near-duplicate emissions at the expense of cost efficiency. Figure 4 reveals that this trade-off manifests differently across domains in ways that carry theoretical weight beyond hyperparameter selection. The most diagnostic finding is on EGO, where raw PAUC also degrades when deduplication is fully disabled, demonstrating that procedural repetitions actively dilute the matching signal by occupying the candidate set’s allocation budget rather than merely inflating redundancy cost. TV provides the clearest evidence of the PAUC-CAUC asymmetry: the subtitle-anchored event structure allows repetitive fires to achieve coverage through temporal saturation rather than semantic precision, a form of metric exploitation that CAUC is specifically designed to penalise. VAD’s complete insensitivity to η suggests that its sparse event structure is governed by the temporal cooldown τevent rather than the per-window similarity threshold, making η a secondary factor in this domain. Effect of trigger stride. The trigger stride K determines how often the model refreshes its visual evidence, creating a trade-off between temporal coverage and query efficiency. As shown in Figure 5, WEB and EGO are most sensitive to larger strides: their short, dense events require frequent trigger opportunities, and less frequent updates can leave relevant visual changes unobserved until after the event has passed. TV exhibits a broader plateau because subtitle-aligned events typically persist over longer intervals, making its response quality less sensitive to modest delays in visual updates. VAD is comparatively stable over the tested range, since the scouting stage provides an additional event-level filter before full response generation. These differences show that trigger stride should match the temporal persistence of the target events. Across the four scenarios, K = 3 provides the most favorable balance between event coverage and redundant backbone queries. 4.6 CASE STUDY

This example illustrates the role of the instructional prior in shaping what to say from the active visual window. The episodic memory evaluates each candidate against the most recent emitted response before delivery, preventing the recovery mechanism from simply increasing redundant emissions. Together, these examples illustrate the complementary roles of the three tiers in controlling when to query, what to generate, and whether to emit. 

# 5 CONCLUSION 

We presented ProV-Mem, a framework for proactive video reasoning that requires no additional training and organizes decision-making through a three-stage nonparametric memory hierarchy over a frozen VLM backbone. Our contributions are threefold. First, we formulate proactive reasoning as a decomposition of triggering, candidate generation, and emission, which gives the problem a clear and modular structure. Second, we provide a formal suboptimality bound that justifies this decomposition as a principled approximation to joint decision-making over the full causal state. Third, we introduce CAUC, a cost-aware evaluation metric that penalizes redundant, overly frequent, and verbose responses. Experiments on ProactiveVideoQA show that ProV-Mem achieves excellent performance with low latency, consistently improves the utility-cost trade-off, and establishes a stronger Pareto frontier without scenario-specific fine-tuning. These results show that careful memory 9Published as a conference paper at ICLR 2027 organization and stagewise decision design are sufficient to produce effective proactive behavior even when the backbone model remains frozen.

# A RELATED WORKS 

A.1 PROACTIVE STREAMING SYSTEMS 

Passive video question answering (Video-QA) represents a mature domain within multimodal un-derstanding, characterized by retrospective reasoning over fully offline, temporally bounded video sequences (Lei et al., 2020; Zhang et al., 2023). To transition multimodal understanding into interac-tive contexts, early streaming paradigms introduced online streaming architectures. This includes benchmarks such as StreamingBench (Lin et al., 2026) and OVOBench (Niu et al., 2025), which emphasize high-frequency frame-by-frame multimodal inference. However, these systems remain fundamentally question-driven, requiring explicit external queries to trigger each model response and ignoring the problem of autonomous engagement. To formalize autonomous interaction, the paradigm of Proactive Streaming Video QA was introduced by Wang et al. (2025a), which requires an agent to process an unbounded, continuous streaming input and independently make three interconnected causal decisions at each step: when to speak (timing control), what to say (contextual generation), and whether to deliver the response (emission necessity). Research addressing this proactive control problem primarily bifurcates into two paradigms, namely parametric trained-head systems and training-free heuristic adaptations. Under the parametric paradigm, architectures such as MMDuet (Wang et al., 2025b), VideoLLM-Online (Chen et al., 2024a), and MMDuet2 with Reinforcement Learning (Wang et al., 2026) append dedicated classifier heads to the hidden states of visual backbones, supervising them using dense, frame-level alignment annotations. While displaying high temporal precision on specific, in-distribution scenarios, these models are notoriously sensitive to domain shifts and suffer from catastrophic generalization failure on unseen video densities due to over-fitting on trained temporal priors. Under the training-free paradigm, offline VLMs (Li et al., 2024) are reused through temporal chunking (Zhang et al., 2024b; Chen et al., 2025) or heuristic agent-based prompts (Han et al., 2024; Wang et al., 2024). Although these systems avoid expensive training, they lack structural mechanisms to explicitly control timing and redundancy, often falling back on brute-force, high-frequency inference that degrades real-time throughput. A parallel line of long-context streaming work addresses engineering challenges via frame-level KV cache compression (Xu et al., 2026) or attention sinks (Xiao et al., 2024; Xu et al., 2026), yet predominantly assumes passive interaction without active decision gating. A.2 MEMORY -A UGMENTED AND PROMPT -B ASED ARCHITECTURE 

Modulating frozen vision-language models at inference time via strategic prompt design is an effective, training-free engineering technique. Grounded detail and specification prompts (You et al., 2024) forced models to anchor responses in specific spatiotemporal coordinates, while persona prompts (Maaz et al., 2024) shaped the stylistic and lexical surface form of outputs. Despite their flexibility, pure prompting methods are inherently memoryless, meaning they cannot dynamically adjust the model’s internal context as the interaction history scales. Conversely, memory-augmented architectures employ external storage to modulate runtime generation. Within these memory-augmented paradigms, Retrieval-Augmented Generation (RAG) methods like RETRO (Borgeaud et al., 2022) and Memorizing Transformers (Wu et al., 2022) use dense retrieval networks to query massive external text corpora at each decoding step, which remains computationally expensive and incompatible with real-time stream causality. Database-driven agent memories, such as MemoryBank (Zhong et al., 2024) and MemGPT (Packer et al., 2023), compress multi-turn dialogues or interaction summaries into vector databases, executing retrieval queries to fetch historical contexts. However, executing dense database lookups at every frame boundary introduces substantial latency, violating the causality constraints of real-time streaming video understanding. State-driven cognitive architectures, including Generative Agents (Park et al., 2023) and cognitive agent frameworks (Sumers et al., 2023), maintain high-level textual states to plan long-term decisions, but have historically been pursued in isolation from prompt engineering. ProV-Mem addresses these limitations by introducing a unified, non-parametric formulation that co-designs inference-time prompting with explicit state tracking, delivering a lightweight, backbone-agnostic wrapper. 13 Published as a conference paper at ICLR 2027

# C EXPERIMENT 

C.1 DATASET 

To evaluate autonomous and interactive capabilities under strict temporal causality, recent benchmarks have begun to emphasize proactive streaming paradigms. A notable milestone is ProactiveVideoQA (also formalized as ProactiveStreaming) (Wang et al., 2025a), a large-scale streaming multimodal benchmark specifically designed to assess an agent’s proactive interaction capacity over unbounded visual inputs. To comprehensively evaluate proactive agents across diverse temporal densities and semantic distributions, the benchmark incorporates four distinct streaming tasks: • Streaming Video Captioning (WEB), which evaluates continuous, low-latency web video narration. • Egocentric Video Narration (EGO), which demands high-frequency first-person activity tracking characterized by dense, repetitive action substeps. • Subtitle-centric Dialogue QA (TV), which requires the temporal alignment of visual evidence with streaming conversational subtitle flows. • Video Anomaly Detection (VAD), which assesses the model’s ability to trigger timely, non-redundant alarms over highly sparse and critical hazard events. Under this protocol, models must dynamically synchronize trigger control, grounded-content genera-tion, and lexical redundancy filtering under strict online constraints, establishing a challenging and unified testbed for next-generation proactive vision-language agents. C.2 EXPERIMENTAL SETTING 

We evaluate ProV-Mem on all four scenarios of the ProactiveVideoQA dataset. We report the standard Proactive Area Under the Curve (PAUC) at trade-off weight ω = 0 .5 together with our proposed Cost-Aware Area Under the Curve (CAUC). Both metrics are computed with the official evaluation framework under the official single-question protocol, using GPT-4.1 as the semantic judge. Unless otherwise noted, all experiments use the same frozen Qwen2.5-VL-7B-Instruct backbone. The main domain-specific differences lie in trigger cadence, episodic control, and a small number of scenario-specific prompting modules. For WEB, we use a regular trigger stride of K = 3 sampled frames, a similarity threshold of η = 0 .75 , and no suppression expiry in episodic memory, that is, 

τsup = ∞. EGO uses the same trigger and similarity settings but introduces a suppression cooldown of τsup = 30 s to permit re-emission of recurring procedural steps after sufficiently long gaps. TV also uses K = 3 and η = 0 .75 , and activates a silence-recovery prompt P force sys after κ = 4 consecutive silent trigger windows. VAD adopts a two-stage pipeline with a lightweight scouting prompt Pscout 

and an event cooldown of τevent = 8 s. For CAUC, we fix the penalty weights to α = 0 .3 for redundancy, β = 0 .3 for frequency, and γ = 0 .4 for token inefficiency. We set the length reference to 16 Published as a conference paper at ICLR 2027 

Lref = 50 tokens and the cooldown to τcooldown = 5 s for all four scenarios. We set the comparison prefix length to L = 200 characters in all experiments. C.3 PER -D OMAIN IMPLEMENTATION DETAILS 

For WEB, frames are sampled at 1 fps and grouped every K = 3 frames. At each trigger window, the backbone receives the current frame batch together with the primary system prompt Psys and generates a reply of up to 128 tokens using greedy decoding. The episodic memory Mep stores a fixed length prefix extracted from the last emitted reply. A newly generated candidate is suppressed when its character level lexical similarity to the stored prefix, measured by longest common subsequence alignment, exceeds η = 0 .75 . Since τsup = ∞, the suppression state is not reset within the video. A negation filter additionally maps outputs containing phrases such as “there is no”, “cannot see”, or “not visible” to No Reply . The instructional memory Minst keeps the fixed prompt Psys throughout the video, with no per-video adaptation. For EGO, the inference pipeline is identical to WEB, including 1 fps frame sampling, K = 3 , and 

η = 0 .75 , except that a suppression cooldown of τsup = 30 s is introduced in Mep . This allows the system to emit again for the same procedural substep after a sufficiently long interval, which is necessary because egocentric cooking and assembly videos often revisit the same action after a temporal gap. For TV, the model processes the frame stream together with the most recent W = 6 unique subtitle lines, which are provided in each trigger window as a [Recent subtitles] block. The trigger cadence is fixed at K = 3 frames, and the episodic suppression threshold remains η = 0 .75 . When 

κ = 4 consecutive trigger windows pass without an emitted response, corresponding to 12 seconds under 1 fps sampling, the system invokes the recovery prompt P force sys to produce a best effort reply, after which the silence counter is reset. In addition, if no valid reply has been emitted throughout the clip, the system performs a single end of video fallback. This mechanism does not require access to gold timestamps at inference time. VAD employs a two-stage pipeline. In the scouting stage, every K = 3 frames are processed by the lightweight JSON-output prompt Pscout in a high-recall mode. The backbone returns a binary anomaly flag together with a coarse event category drawn from the UCF-Crime anomaly label space. Any window predicted as anomaly detected=true , or matched by a keyword-based fallback rule, is forwarded to the reply stage. In the reply stage, the backbone generates the final natural-language description using Psys . The episodic module then applies the same LCS-based character-level similarity gate with η = 0 .75 to suppress near-duplicate responses, while an event cooldown of τevent = 8 s prevents repeated emissions for the same anomaly. A five-frame normal baseline at the start of each video is used to calibrate the scouting stage before anomaly detection begins. C.4 SENSITIVITY TO THE TIMELINESS /C ORRECTNESS TRADE -OFF

Silence silence-recovery threshold κ on TV. The silence-recovery threshold κ specifies after how many consecutive silent regular trigger opportunities an additional recovery query is issued, preventing the model from remaining dormant on sparse streams. A small threshold such as κ = 2 

makes this recovery mechanism too aggressive: PAUC rises to 60.02, but Rep% also increases to 26.13%, because forced triggers are frequently invoked in weakly informative windows. The default setting κ = 4 yields a PAUC of 57.43 and a CAUC of 40.22. Under 1 fps sampling, this corresponds to 12 s of silence and serves as a moderate operating point that preserves a recovery path for sparse events without making forced triggering overly frequent. At the other extreme, disabling the silence-recovery entirely ( κ = ∞) gives PAUC 58.93, CAUC 41.68, and Rep% 16.70%, which indicates lower redundancy but also removes the recovery mechanism for sparse events. Overall, the sweep shows that κ mainly controls the balance between recovery coverage and redundant activation, rather than uniformly improving all metrics at once. 18
