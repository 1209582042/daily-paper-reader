## 摘要
空间理解对于具身智能体在物理世界中导航和交互至关重要。随着观测逐步到达，智能体必须以流式方式进行推理。然而，流式理解也必须是闭环的：任务相关证据可能既需要回忆过去的观测，也需要主动获取新的视角。现有流式方法主要强调处理到来的观测，而对任务驱动的主动探索研究不足。我们提出 MemAct，一个结合记忆与动作的流式空间理解框架。一个共享的视觉-语言模型会增量写入结构化历史记忆，按需检索记录和过去帧，并通过移动和转向获取额外证据。检索到的证据和动作观测会为后续决策提供信息，使智能体能够在统一的推理循环中继续探索或作答。我们开发了 MemAct 套件，这是一个跨真实与模拟环境的数据生成流水线与数据集，包含约100万个用于空间推理、记忆写入、检索和探索的训练样本。其 MemAct-bench 包含 20,000 个主要问答对，用于评估当前观测理解、历史证据使用和主动探索，另有 2,000 个独立的 Timing 问题。MemAct 将用于记忆和交互的监督微调与反事实动作优化相结合，利用累积证据增益、动作成本和最终答案质量来改进探索与停止决策。实验表明，MemAct 在 MemAct-bench 上优于现有空间理解和流式基线，并接近前沿多模态模型，同时保持流式推理效率。

## Abstract
Spatial understanding is essential for embodied agents navigating and interacting with the physical world. As observations arrive incrementally, agents must reason in a streaming manner. Yet streaming understanding must also be closed-loop: task-relevant evidence may require both recalling past observations and actively acquiring new views. Existing streaming approaches largely emphasize processing incoming observations, leaving task-driven active exploration underexplored. We introduce MemAct, a framework for streaming spatial understanding with memory and action. A shared vision--language model incrementally writes structured historical memory, retrieves records and past frames on demand, and acquires additional evidence through movement and turning. Retrieved evidence and action observations inform subsequent decisions, enabling the agent to continue exploring or answer within a unified reasoning loop. We develop the MemAct suite, a data generation pipeline and collection across real and simulated environments, with approximately 1M training examples for spatial reasoning, memory writing, retrieval, and exploration. Its MemAct-bench comprises 20,000 main QA pairs evaluating current-observation understanding, historical evidence use, and active exploration, plus 2,000 separate Timing questions. MemAct combines supervised fine-tuning for memory and interaction with counterfactual action optimization using cumulative evidence gains, action costs, and terminal answer quality to improve exploration and stopping decisions. Experiments show that MemAct outperforms existing spatial understanding and streaming baselines and approaches frontier multimodal models on MemAct-bench while retaining streaming inference efficiency.

## 1. 核心问题与研究动机

- **背景**：具身智能体在物理世界中导航与交互时，观测是**增量到达**的（未来视角不可见、已见物体可能离开上下文、关键细节可能从未出现在当前视野中），因此空间理解必须是**流式（streaming）**的。
- **核心洞察**：流式理解还必须是**闭环**的——同一个空间问题可能（a）用当前视角即可回答，（b）需要回忆历史观测，（c）必须通过移动/转向主动获取新证据。智能体需要在这三种行为间自主决策。
- **现有方法不足**：
  - 离线 Video QA：整段视频可用、批量处理，非因果。
  - 被动流式 QA（StreamingVLM、Stream3D-VLM 等）：遵循**预定相机轨迹**，只强调"处理到来的观测"，早期证据会因上下文驱逐而丢失，需要的视角可能永远不会被采集；**任务驱动的主动探索被严重忽视**。
  - 主动式具身 QA（EXPRESS-Bench、ESI-Bench、MemoryEQA、Mind Palace 等）：依赖几何地图/结构化空间记忆/独立空间规划器，且往往不是"先观测后提问"的同一模型闭环。
- **论文目标**：用**单一共享 VLM** 同时完成"增量写记忆 → 按需检索历史 → 主动采集新视角 → 作答"，推理时**不输入深度图、不输入重建的 3D 地图、不使用独立空间规划器**。
- **三大技术挑战**：(1) 在还不知道问题时就需保留潜在有用证据；(2) 判断证据是"当前可见/历史可恢复/只能靠新视角获得"，需要关于"看过什么、动作揭示了什么"的**因果监督**；(3) 某些有信息量的视角需要"无即时收益的准备性移动"，训练必须为**延迟收益**记账，并学会**何时停止探索**。

## 2. 方法论

### 2.1 总体框架
- 因果上下文 $C_t$ 存于**增量 KV cache**（沿用 compact-cache streaming，超限时优先驱逐最旧视觉 token）；**外部记忆 $M_t$** 由确定性 harness 独立保存（结构化记录 + 历史帧），从而支持超出视觉上下文的检索。
- 问题 $q_t$ 到来后，第 $k$ 轮历史 $h_k$ 含问题、可用观测、先前命令/结果与剩余预算；模型以**同一生成接口**输出 `answer` / `use_memory` / 相机动作；harness 按规则执行并回填结果，形成 $h_{k+1}=\text{Append}(h_k,u_k,z_k)$。作答即终止交互。

### 2.2 增量记忆写入与检索
- 每 **5 秒**写入一次增量 $\Delta M_t$：时间戳、帧引用、**逐帧类别计数**、可选**像平面关系**（3×3 网格上的 left/right/above/below）。空帧与末尾不完整窗口也保留。
- 更新 $M_t=\text{Update}(M_{t-5},\Delta M_t)$ 只做**结构与时间引用校验**，不做语义纠正；重复写入返回 already stored，冲突写入被拒。
- 检索请求含类别集合、可选时间范围、是否需要图像；返回匹配记录/关系/至多 2 张图；**每题最多 4 次检索调用、最多 4 张不同历史图**，记录按时间排序、每页 8 条，游标绑定原查询快照。
- 设计逻辑：结构化记录用于**定位**历史证据，检索到的历史帧用于**恢复**记录中缺失的视觉细节。

### 2.3 离散动作与多轮探索
- **5 个无参数命令**：前/左/右平移 0.5 m（保持朝向）、左/右旋转 45°（保持位置）；执行器固定幅值。
- 每题最多 **3 次**动作尝试；动作观测保留在问题上下文中但**不自动写入记忆**；探索结束后原视频流继续。

### 2.4 训练 Stage I：监督微调（SFT）
- 数据：MemAct-data（约 1M）+ VSI-590K；对 assistant token（记忆写入、检索请求、相机命令、答案）做 next-token 交叉熵，观测/提示/工具结果 **loss-masked**；序列内先平均、再跨 batch 平均；每条序列上限 180,000 token，超长直接丢弃（不截断）。
- 采用 **LoRA**（仅 query/value 投影，rank 8、scaling 16、dropout 0），视觉编码器等基座参数冻结。

### 2.5 训练 Stage II：反事实动作优化（上下文 Bandit）
- 在同一因果状态 $h$ 上，用**独立副本**并行评估 5 个相机命令 + "立即作答"，每候选 **B = 4 条**多步续 rollout（温度 1 采样后续动作、贪心生成终答），得到 $\hat Q_\mu(h,a)=\frac1B\sum_b G^{(b)}(h,a)$。
- **证据质量函数**：$E(x,q)\in[0,1]$ 由归一化可见像素比例（10% 占用即饱和）、**取景完整度**（惩罚被画面边界裁剪）、**双目标联合支撑**（取较弱目标，即 min）组成；$\Phi(h,q)=\max_{x\in O(h)}E(x,q)$。
- **单步奖励**：$r_j=\alpha[\Phi(h_{j+1},q)-\Phi(h_j,q)]_+-\lambda_{ac}(a_j)-\lambda_{inv}\mathbb{1}[\text{invalid}]$（实现取 $0.10d_k-0.03-0.20\cdot\text{invalid}$）。用"相对**历史最佳**视角的增益"而非"相对当前视角"，避免重复奖励已获证据。
- **累积回报**：$G_j=\sum_{\ell=j}^{T-1}\gamma^{\ell-j}r_\ell+\gamma^{T-j}R_{QA}$（$\gamma=1$，$R_{QA}$ 为选项正确性或数值 MRA）；无效动作不改变观测、无证据增益但消耗一次尝试。
- **策略与损失**：$\pi_\theta(a|h)$ 由候选决策 token 的条件对数概率**求和（不做长度归一化）**后归一化得到；
  $\mathcal{L}_{action}=\mathbb{E}_h[-\sum_a \pi_\theta(a|h)\hat Q_\mu(h,a)+\beta\,\mathrm{KL}(\pi_\theta\|\pi_{SFT})]$，$\beta=0.05$，$\pi_{SFT}$ 冻结，$\hat Q$ 更新时 detach。
- **混合目标**：$\mathcal{L}_{mix}=\mathbb{E}_{u\sim\rho}\mathbb{E}_{z\sim D_u}[\ell_u(z)]$，采样概率 $\rho_{action}=0.50,\rho_{QA}=0.25,\rho_{mem}=0.25$，用监督 QA 与记忆回放防止能力退化。

### 2.6 数据构建流水线（五阶段）
- 观测获取 → 元数据对齐 → 记忆与 QA 生成 → 动作渲染 → 流式装配。
- **仿真**：3D-FRONT 布局/资产（剔除穿插与错误尺度物体），网格 A* 规划 + Bézier 平滑的随机访问顺序轨迹，Cycles 渲染并随机化地板/天花纹理与 HDRI 光照。
- **真实**：ScanNet、ScanNet++、ARKitScenes，按物理时间戳对齐帧、位姿与 3D 标注；统一五类元数据（时间、相机、物体、可见性、场景几何），1 FPS 采样，米制单位。
- **动作监督**：在专用仿真渲染中固定场景/目标/问题/答案，只改变证据；端点须满足 $p_j\ge0.005$、$f_j\ge0.80$、$v^{occ}_j\ge0.70$，且 $P(x,q)\ge1.5B_t(q)$、绝对增益 $\ge0.002$；最多执行 3 步并保留**最早**满足条件的端点，允许中间步骤无即时收益；另渲染 5 个候选的**反事实分支**供 RL 使用（不受端点阈值过滤）。
- **规模**：1,000,000 个 QA turn（Current 302,661 / Memory 402,662 / Action 294,677），序列化为 342,868 条流，覆盖 11,724 个场景标识；动作示范长度 1 步 216,418、2 步 46,858、3 步 31,401。训练/测试在**场景级**不重叠。
