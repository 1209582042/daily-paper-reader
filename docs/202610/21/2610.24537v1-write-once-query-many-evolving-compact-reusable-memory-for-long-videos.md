## 摘要
长视频常常超出多模态大语言模型（MLLMs）的上下文容量，而智能体式搜索会为每次查询重复进行昂贵的视频处理和定位。可复用记忆能够摊销这一成本，但必须为构建时未知的问题保留信息。我们提出 Video-EMem，一种基于时间锚定感知观测的可演化视频记忆框架。该表示将紧凑的自由形式文本与稀疏图像相结合，以在多个时间尺度上保留语义内容和互补的视觉细节，并支持无需固定语义模式的时间导航。Writer 通过整合重叠的多尺度观测，对每个视频仅编码一次；Reader 仅从所得记忆中检索并组织证据。在底层模型冻结的情况下，我们利用不同的反馈来演化其工作流和算子：针对 Writer 使用与查询无关的源保真度和覆盖率，针对 Reader 使用证据定位与利用方面的问答失败。实验表明，这种分离有助于泛化到开发查询之外；与未演化框架相比，我们的演化策略将平均准确率提高了 7.2%。相对于原始视频，Video-EMem 平均减少约 99.86% 的存储，同时在三个长视频问答基准上，相较于直接输入 2,048 帧，使 Qwen3-VL-30B 平均提升 2.6%。在使用与最先进智能体方法相同的 o3 答案模型时，其平均准确率提高 2.5%，且每次查询延迟更低。

## Abstract
Long videos often exceed the context capacity of multimodal large language models (MLLMs), while agentic search repeats costly video processing and grounding for each query. Reusable memory can amortize this cost, but must preserve information for questions unknown during construction. We propose Video-EMem, an evolvable video memory harness built on time-anchored perceptual observations. This representation combines compact free-form text with sparse images to preserve semantic content and complementary visual details across temporal scales, supporting temporal navigation without a fixed semantic schema. A Writer encodes each video once by consolidating overlapping multiscale observations, and a Reader retrieves and organizes evidence solely from the resulting memory. With the underlying models frozen, we evolve their workflows and operators using distinct feedback: query-independent source fidelity and coverage for the Writer, and QA failures in evidence localization and utilization for the Reader. Experiments support this separation for generalization beyond development queries, with our evolution strategy improving average accuracy by 7.2% over the unevolved harness. While reducing storage by about 99.86% on average relative to raw videos, Video-EMem improves Qwen3-VL-30B by an average of 2.6% across three long-video QA benchmarks over direct input of 2,048 frames. Using the same o3 answer model as the state-of-the-art agentic method, it improves average accuracy by 2.5% with lower per-query latency.

## 1. 核心问题与整体含义

- **背景**：长视频（如小时级）远超多模态大语言模型（MLLM）的上下文容量。直接输入需要降采样帧，容易丢失细节；智能体式搜索（agentic search）虽能定位相关片段，但**每个查询都要重复处理原始视频**，计算与延迟成本高。
- **核心问题**：能否将视频**只编码一次**为紧凑、可复用的记忆，使其在构建时未知的未来问题下仍保留足够信息，并支持高效的证据检索与组织？
- **整体含义**：论文提出“**write once, query many**”范式——用一次性记忆构建摊销重复视频处理成本，同时通过可进化的 Writer/Reader 工作流，在有限存储预算下兼顾信息保真度与查询效率。这为长视频理解提供了一条区别于“更长上下文”和“逐查询智能体搜索”的第三条路径。

## 2. 方法论

### 2.1 核心思想

- 记忆不是固定语义模式的结构化数据库，而是**时间锚定的多模态观测序列**：每条观测由时间区间、紧凑自由文本和稀疏时间戳图像组成。
- 将记忆构建（Writer）与记忆访问（Reader）**分离优化**：Writer 在不知道下游问题的情况下最大化源信息保留；Reader 仅基于冻结记忆做查询条件证据检索与组织。
- 底层 MLLM 全部冻结，仅通过 LLM 驱动的“反思—变异”进化工作流中的算子，分别使用**源保真度反馈**（Writer）和**下游 QA 失败反馈**（Reader）。

### 2.2 记忆表示

- 记忆定义为按时间排序的观测序列：  
  \(M=[o_1,\dots,o_N]\)，其中 \(o_i=(\Delta_i,s_i,I_i)\)。  
  \(\Delta_i\) 为视频时间区间，\(s_i\) 为文本记录，\(I_i\) 为稀疏或空的时间戳图像集合。
- 预算约束：文本 token 总数 \(\le B_s\)，图像总数 \(\le B_v\)。默认 \(B_s=20K\) tokens、\(B_v=160\) 张 448×448 图像。
- 文本是记忆主骨架，整合多时间尺度信息；图像仅在文本不足以表达外观、空间布局、细微/瞬态细节时补充，且保留时间戳以支持定位。

### 2.3 Writer：构建查询无关记忆

**多尺度源语料**：将视频按 3 个时间尺度划分为 16/32/64 个嵌套区间，每个区间均匀采样 50 帧生成独立 caption，形成从粗到细的源语料。

**文本写作流程（自细到粗）**：

1. **Merge**：将当前尺度源 caption 与更细尺度已得观测合并。
2. **Allocate**：按内容重要性/冗余度为各观测分配 token 预算。
3. **Compress**：将合并观测压缩到分配容量。
4. **Verify**：对照源 caption 和细尺度观测，检测压缩中丢失或弱化的源支持信息。
5. **Repair**：在预算内选择性恢复遗漏信息。
6. 最粗尺度输出最终文本观测 \(\{s_i\}\)。

**视觉补充

**视觉补充（Visual Supplement）**：文本观测定型后，Writer 再判断哪些观测需要图像证据。选择标准通常包括：文本难以精确描述的外观/空间布局、瞬态动作、细粒度文字或物体细节，以及查询时可能成为区分性线索的帧。被选帧按时间戳挂接到对应观测，形成 \(I_i\)；若文本已足够，则 \(I_i=\varnothing\)。视觉预算 \(B_v\) 在全局层面分配，优先覆盖信息密度高、文本歧义大或时间上关键的区间，并避免相邻帧冗余。最终输出按时间排序、文本为主骨架、图像为稀疏补充的记忆 \(M\)。

### 2.4 Reader：冻结记忆上的查询条件证据组织

- **输入与目标**：给定查询 \(q\) 与已冻结的记忆 \(M\)，Reader 不修改记忆，只负责检索、筛选并组织与 \(q\) 相关的观测，形成紧凑证据集后交给 MLLM 回答。
- **查询解析**：先识别查询的时间意图（全局、区间定位、事件顺序、计数、因果等）与证据类型需求（文本描述、视觉细节或二者结合），据此决定检索粒度。
- **证据检索**：在时间锚定的观测序列上进行文本匹配与语义相关性排序，必要时回溯相邻观测以保持时间上下文；对候选观测再决定是否调用其挂接图像。
- **证据组织**：将选中观测按时间顺序重排、去冗余，并保留时间戳与来源区间，使回答可追溯到具体视频片段；若证据不足，可进行有限轮次的再检索或查询改写。
- **与常规 RAG 的区别**：记忆不是固定切块的向量库，而是多尺度、时间锚定、文本与稀疏视觉耦合的观测序列；Reader 的优化目标是下游 QA 成功率，而非单纯检索相似度。

### 2.5 进化工作流：用反馈分别优化 Writer 与 Reader

- **总体机制**：底层 MLLM 全部冻结，由 LLM 驱动的“反思—变异”循环提出流程算子或提示变体，执行后依据评估反馈选择保留，迭代形成更优的 Writer/Reader 工作流。
- **Writer 反馈**：以源保真度为核心，衡量压缩后记忆对原始视频信息的保留程度，例如基于记忆重建源描述、覆盖关键实体/事件/时间关系，以及检测压缩中丢失或弱化的信息；Verify/Repair 步骤即在该反馈下迭代。
- **Reader 反馈**：以下游 QA 失败案例为信号，分析失败源于检索遗漏、时间定位错误、证据组织不当还是视觉补充不足，并据此变异检索与组织策略。
- **分离优化**：Writer 在不知道下游问题的情况下追求查询无关的信息保留；Reader 在冻结记忆上追求查询条件证据利用。二者解耦，使记忆可复用，同时避免记忆构建被特定问题过拟合。

## 4. 主要结果与分析（定性）

- **效果**：论文报告该方法在多个长视频 QA 基准上取得有竞争力甚至更优的结果，尤其在需要时间定位与细节证据的题型上，优于仅降采样帧或固定分块记忆的方案。
- **效率**：由于视频只编码一次，随着同一视频上查询数增加，平均每查询成本显著下降；相比逐查询智能体搜索，减少了重复视频处理与反复调用视觉模型的开销。
- **预算权衡**：文本预算与视觉预算存在边际收益递减；多尺度写作与 Verify/Repair 有助于在有限预算下保留关键信息，视觉补充主要改善外观与细粒度识别类问题。
- **消融结论**：移除多尺度合并、验证修复或查询条件证据组织均会导致性能下降；Writer 与 Reader 分离优化被证明有利于记忆复用，而非仅针对单一查询过拟合。
- **错误分析**：剩余错误多来自源 caption 本身遗漏、极细粒度或瞬态细节在视觉预算外、复杂时间推理中的证据组织失败，以及 Reader 检索到相关但不足以回答的观测。

## 5. 主要贡献

- 提出“**write once, query many**”的长视频记忆范式，将一次性记忆构建与多次查询访问分离，摊销重复视频处理成本。
- 设计时间锚定、文本为主、稀疏视觉补充的紧凑多模态记忆表示，在有限存储预算下兼顾信息保真与可定位性。
- 提出 Writer/Reader 分离的进化工作流，分别利用源保真度反馈与下游 QA 失败反馈优化流程，而无需微调底层 MLLM。
- 通过实验展示该范式在效果、查询效率与预算可控性上的潜力，并为长视频理解提供区别于“更长上下文”和“逐查询搜索”的第三条路径。

## 6. 局限与启示

- **局限**：记忆质量受源 caption 与底层 MLLM 能力约束；进化工作流本身有构建开销；静态记忆难以在视频流式更新时即时修订；视觉预算有限可能丢失长尾细节；评估仍以 QA 为主，对开放式理解与多轮交互的覆盖有限。
- **启示**：未来可探索增量式记忆更新、查询分布感知的预算分配、更强的跨模态证据压缩，以及将记忆构建与检索策略联合进化；同时需要更细粒度的证据级评估指标，而不仅是最终答案准确率。
