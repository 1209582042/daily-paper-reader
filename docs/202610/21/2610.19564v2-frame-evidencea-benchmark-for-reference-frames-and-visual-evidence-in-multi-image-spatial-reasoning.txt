Abstract 

A spatial answer depends on the reference frame specified in language and its support-ing visual evidence. Item accuracy alone ob-scures whether correctness persists when either changes. We introduce F RAME EVIDENCE , a benchmark of 320 matched triplets and 960 Chi-nese multiple-choice questions from captured and rendered scenes. One family compares three grounded reference frames over fixed im-ages. The other pairs image deletion annotated as insufficient with answer-preserving addition. Joint metrics require correct answers across all three frames and paired evidence variants. Across 20 configurations on 288 held-out ques-tions, GPT three-shot reaches 50.00% item ac-curacy, but the best three-frame group accu-racy is 5/48 (10.42%), reached by GPT two-shot. Few-shot prompting and task-specific adaptation improve item accuracy without con-sistently improving joint correctness. Input con-trols show where images support matched suc-cess, while repeated executions reveal answer instability beneath similar scores. 

1 Introduction 

Spatial language describes an arrangement relative to a reference frame. An object on the left from a camera may be in front in another object’s frame. Models must identify the intended frame and as-sess whether partial views jointly support that de-scription. Spatial supervision has improved spa-tial question answering and regional reasoning in vision-language models (Chen et al., 2024; Cheng et al., 2024). Evaluation must therefore test both frame grounding and visual evidence use. Existing benchmarks test perceptual and three-dimensional spatial relations (Liu et al., 2023; Fu

Multi-view and video eval-uations extend this coverage to evidence distributed across observations (Yang et al., 2026; Yeh et al., 2026; Yang et al., 2025). Yet item accuracy alone cannot establish correctness across matched inputs. A preferred answer can match a direction with-out reflecting the specified frame. Matched eval-uations distinguish these behaviors by changing selected input attributes (Thrush et al., 2022; Wang et al., 2025; Kim et al., 2026). 2 Related Work 

Reference frames and frame-conditioned rea-soning. Spatial and matched-contrast bench-marks probe relational judgments (Liu et al., 2023; Fu et al., 2024; Thrush et al., 2022). COM-FORT, FoREST, and ViewSpatial-Bench examine reference-frame ambiguity (Zhang et al., 2025; Premsri and Kordjamshidi, 2025; Li et al., 2026). SCOPE, All-Angles, and CityCube address cross-view and scale variation (Kim et al., 2026; Yeh et al., 2026; Xu et al., 2026), while MirrorQA targets subject-centered left–right judgments (Liu et al., 2026). COMFORT compares explicit frames on matched synthetic scenes and measures prob-abilistic consistency. Our frame protocol evalu-ates joint correctness across three multi-view frame prompts, distinguishing a correct switch from an answer change alone. 

Multi-image reasoning and evidence interven-tions. MIRB, ReMI, MMIU, and MuirBench as-sess multi-image reasoning, while MIMIC probes controlled failure cases (Zhao et al., 2024; Kazemi et al., 2024; Meng et al., 2025; Wang et al., 2025; Das et al., 2026). MMSI-Bench, CrossView Suite, MultiView-Bench, and cross-view relation learn-ing focus on spatial integration (Yang et al., 2026; Wang et al., 2026a; Zhang et al., 2026; Jeong et al., 2026). Evidence-centered diagnostics ex-amine input dependence through rationale suffi-ciency, paired unanswerability, view selection, evi-dence sensitivity, and multi-view necessity (DeY-oung et al., 2020; Moratelli et al., 2026; Wang et al., 2025; Guo et al., 2026; Wang et al., 2026b; Bhat and Yamasaki, 2026; Yu et al., 2026). SSMNBench adds and removes views of minimal necessary sets to measure view-wise accuracy and distraction de-cay. These measures characterize supporting views and average sensitivity to evidence changes. Ta-ble 1 summarizes our requirement for paired cor-rectness before and after an intervention on the same instance. Comparing models on shared, cor-rectly answered MSSs then separates initial cover-age from subsequent intervention errors.

4 FrameEvidence Construction 

4.1 Scene Acquisition and Group Assembly 

FrameEvidence combines 126 captured-image and 194 rendered-image groups of static layouts span-ning indoor tabletop, indoor large-space and out-door public-space scenes. An object inventory iden-tifies the target, relatum and any bridge objects connecting views. Construction criteria require un-ambiguous identity matches, unchanged layouts, grounded frame anchors and evidence that must be combined across views. FQ1 reuses two to four ordered images across its three questions. FQ2 starts from two to four MSS images, then changes the set size by one. Each fam-ily contains 53 two-image, 54 three-image and 53 four-image base sets. Hard additions supply com-peting context but preserve the annotated answer. 

4.2 Annotation and Quality Control 

Controlled Chinese questions specify the queried entities and reference frame. Answer placement maps semantic answers to A–D while fixing option order within groups. 5 FrameEvidence Analysis 

Composition and balance. Table 2 shows bal-anced relation ontologies and nearly equal scene strata, with 160 questions per condition. The ten labels in Figure 2 account for 374 of 960 group-level occurrences, with 116 further types retaining source names. Test A–D counts are 75, 70, 69 and 74. Macro-averaging gives each class equal weight. 

Evidence structure and non-visual controls. 

Figure 3a shows that extreme image counts iden-tify some FQ2 conditions. On 144 held-out FQ2 items, a train-fitted count-plus-schema rule achieves 37.50% accuracy, compared with 33.33% from always selecting insufficient information. NTS and DIS reach only 6.25% and 2.08%, so this advantage rarely extends to paired variants. A clas-sifier using character-level term frequency–inverse document frequency (TF-IDF) features from ques-tions and options reaches 23.96% accuracy on all 288 test items. Identical FQ2 text forces this deter-ministic model to repeat its answer, making NTS zero. Condition cues and item accuracy alone there-fore cannot establish sensitivity to changed evi-dence. Appendix F.3 specifies the text model. 

Scene overlap and sensitivity. The release has 443 distinct images across 1,120 paths. Exact im-ages stay within one split, although views and ren-derings can share scenes across splits. An inferred scene/template ledger assigns 81 test groups to clus-ters shared with training and 15 to four clusters absent from both train and dev. On these 15 groups, Qwen LoRA lowers DIS from 4/8 to 2/8, matching the full-test direction. InternVL’s unchanged over-all NTS instead combines opposing changes across strata. The subset’s 13 rendered and two captured groups also differ in composition from the full test. Across the full test, rendered inputs yield higher DIS in 16/20 configurations and higher accuracy in 14. Appendices F.1 and G report both comparisons. 

Ordinal references after deletion. Deletion re-moves the original referent in 36/48 FQ2 groups and shifts it in six. Under current-order presenta-tion, 38 ordinals resolve to another image and four fall out of range. Table 3 separates joint successes by reference change. Both InternVL checkpoints succeed only when the referent is removed. Their NTS scores therefore combine responses to evi-dence removal and reference changes. Both primary LoRA checkpoints increase insuffi-ciency responses across all conditions in Table 8. Qwen’s insufficiency recall rises from 6.25% to 79.17%, but precision changes from 42.86% to 41.30%. The extra deletion hits therefore come with more false insufficiency responses on answer-able MSS and addition inputs. Joint scoring ex-poses this trade-off by requiring success on both sides of the intervention. Mistral shows the oppo-site imbalance, selecting insufficiency more often on MSS than on deletion. Appendix G.4 gives the full count breakdown. 

MSS coverage separates intervention outcomes. 

Shared MSS-correct groups account for four of Qwen’s five net NTS gains. InternVL gains one on these groups, offset by changed MSS coverage. All InternVL joint deletion successes involve removed anchors in Table 3. Qwen loses fourteen DIS successes through changed MSS coverage and one among shared groups. InternVL loses three through each route. Qwen’s decline thus occurs mainly before addi-tion, whereas InternVL also fails to retain ini-tially correct answers. Similar DIS declines thus have different sources. Appendix D.3 provides the paired decomposition. 

Prompt effects vary across executions. On twelve triplets excluding removed anchors, two randomized blocks yield 51.39% agreement with released labels under original wording and 52.78% under stable IDs. Yet NTS falls from 8/24 to 4/24 group–block observations, and 14–15/36 answers change at fixed wording. The small item-level gain thus does not carry over to matched deletion answers. Appendix E compares each block and condition. 88 Conclusion 

FrameEvidence tests spatial reasoning under matched changes in reference frames and visual evidence. Prompting and adaptation improve item accuracy without consistent gains in joint success, whereas images most often benefit MSS–addition pairs. Paired analyses identify incorrect frame switches, changes in initial MSS coverage and execution instability. Together, these diagnostics distinguish isolated correct answers from success across matched changes. 

Limitations 

FrameEvidence evaluates static, Chinese, four-option spatial reasoning on 96 held-out groups. Scenes can overlap across the image-separated splits, limiting conclusions about unseen-scene generalization. Metadata cues and image-ordinal changes can influence responses alongside visual evidence. Production review does not constitute independent response-level validation of labels or every-member MSS necessity. NTS therefore as-sesses agreement with the released deletion labels. Model comparisons reflect the tested decoding settings, one demonstration pool and provider-reported gateway identities. The three-seed devia-tions describe training variation. Circular uses its own within-experiment controls. The human refer-ence is one participant’s sampled summary without individual answers or a documented sample size.

The captured and rendered images were supplied by an external data provider with permission for pub-lic release. Language-model assistance supported editing, scripting and simulated review. The au-thors remain responsible for checking the evidence, citations and privacy of the released materials.

A Implementation and Scoring Details 

Evaluation inputs. Table 9 lists the evaluated checkpoints and aliases. Each public item contains ordered image references and a Chinese prompt asking for exactly one of A, B, C or D. Evaluation identifiers link predictions to a private mapping with the source sample and group, input mode, gold letter and option meanings. Group identifiers and gold metadata are not shown to models. Metrics are computed from the frozen predictions and their matching input records. All model–mode compar-isons use the full question and group counts. 

Offline scoring companion. A self-contained Python standard-library scorer reproduces the 20 primary configurations in Table 4, eight ordinary multi-seed configurations in Table 11, and seven complete Circular rows in Table 12. It uses san-itized per-item records without model calls or image access, preserving all item and group de-nominators. Primary, multi-seed and rotation runs remain separate. It also reproduces GPT’s 1,152 Circular responses and 288 same-order re-peat responses, including all 16 entries in Table 7. Running python run_reproduction.py from its 

offline_reproduction directory writes the re-computed tables and a verification report. The author-confirmed Qwen Base summary is reported separately from these recomputed results. 

Production review and release correspondence. 

The production database contains 323 PASS and three REWORK actions. Selecting the latest PASS per group covers all 320 groups and 960 questions. Distinct annotation and review account assign-ments are recorded for every group, with semantic answers visible in the review interface. These are production approvals rather than independently col-lected answer sheets. Automatic comments and checklists do not verify reviewer independence or the answerability of every single-view deletion. The task records exactly match the released anno-tations. Compared with the latest PASS snapshots, the release preserves all 960 semantic gold answers and option-meaning sets, and all 1,120 reviewed image files match. Raw fields nevertheless differ in 917 questions. Of 857 prompt changes, 856 re-place a recurring Chinese-character typo and one revises a training item’s anchor ( fce_test_00581 ). Option order changes in 540 items and answer let-ters in 416, without changing semantic gold. Two anchor fields also change. Author adjudication con-firms the scored inputs for the four flagged records. 

Input and assembly consistency. A separate audit compares literal questions, ordered source-image bytes and options across all 960 items. It finds 959 distinct input signatures. The only re-peated signature belongs to two training items with the same gold answer. No signature crosses splits or conflicts in its gold letter. All 288 test inputs are distinct. Ignoring option placement alone also yields no conflicting selected option strings. All 320 triplets pass the encoded assembly rules. FQ1 preserves ordered images, options and entity fields across its three frame variants and has at least two distinct gold meanings. FQ2 preserves ques-tion and option strings, removes or adds exactly one image, and retains the order of the remain-ing images. No item repeats identical image con-tent. Assets match production records. Geometric checks lack camera poses and object coordinates. 

Few-shot construction. The fixed pool uses training groups group_00152 for FQ1 and 

group_00388 for FQ2. FQ1 demonstrations fol-11 low camera, object and scene order. FQ2 demon-strations follow MSS, deletion and addition order. One-, two- and three-shot conditions take the corre-sponding prefixes. The manifest verifies group and exact-image separation from test, although phys-ical scenes may overlap. All shot counts use this fixed demonstration pool. 

Decoding and invalid answers. The common output parser extracts an allowed answer letter and records the raw response, parsing status and API failure separately. An invalid response is never con-verted to a guessed answer. In class-wise recall and accuracy it contributes a false negative for its gold class. Precision uses the predicted A–D counts, with zero for undefined per-class precision. Macro-F1 is the mean of the four classwise F1 scores. A separate full-response parser recovers all 5,750 valid answers among 5,760 main-table records. The ten empty API failures remain in-correct. Reconstructed answers and point estimates match the frozen results. 

Random and human reference rows. Uniform random selects one of A–D independently for each question. The reference row gives exact finite-test expectations. Accuracy and macro-recall are 25%, while macro-F1 averages the expected classwise ratios under the actual supports 75, 70, 69 and 74, yielding 24.93%. The three-answer and two-answer joint expectations are respectively (1 /4) 3

and (1 /4) 2. Separate binomial calculations and small-test enumeration verify the scorer. The human reference is an author-reported P/R/F1/Acc. summary from one participant an-swering sampled groups. The retained record con-tains aggregate scores without the sample size or item-level responses. We report these sample-level values and leave joint scores unreported. 

Held-out metadata controls. The post-hoc con-trols in Table 10 fix three categorical majority rules before computing their held-out scores. They fit only on the 288 FQ2 training questions in 96 groups. Neither the 48 development questions nor the 144 test questions select rules or features. Ties use alphabetic letter order, and unseen feature val-ues fall back to the training-global majority. No held-out feature is unseen. The fixed features are image count alone and its pairing with the insuffi-ciency option’s letter. The count-plus-schema rule answers 54/144 test questions correctly but solves only 3/48 MSS/deletion pairs and 1/48 MSS/addition pairs. Conversely, always predicting the training-majority letter solves 11/48 addition pairs because the spa-tial answer letter is shared within each pair. Joint correctness therefore reveals differences between these rules beyond item accuracy, while the image-free control shows that shared answer preferences can also yield joint success. The reproduction ma-terials include fitted rules and predictions.
