## 摘要
空间推理不仅仅需要能够使用几何工具：推理者必须判断何时直接观察已足够，以及何时需要重建、测量或改变参考系。我们提出 SpatialBrain 框架，它在保持视觉-语言主干固定不变的同时，保留关于这些决策的经验。关键区别在于关于场景的证据与关于如何利用该证据进行推理的经验。3DFusionMemory 将当前场景的观测融合为可查询的空间关系。空间技能库（Spatial Skill Library）提供可复用的工具流程，空间认知（Spatial Cognition）则将任务条件与关于何时以及如何使用记忆和技能的经验相关联。已完成的轨迹被抽象为过程记录，并在任务块之间进行整合，使后续决策能够借鉴先前的执行过程，而无需传递场景坐标或参考答案。在五个空间推理基准上，SpatialBrain 在四个基准上优于同一主干的直接回答，在第五个基准上与其持平。组件比较、经验覆盖曲线以及追踪到的资源决策刻画了该框架如何积累和使用这些资源。

## Abstract
Spatial reasoning requires more than access to geometric tools: a reasoner must decide when direct observation is sufficient and when to reconstruct, measure, or change reference frames. We present SpatialBrain, a framework that retains experience about these decisions while keeping its vision-language backbone fixed. The key distinction is between evidence about a scene and experience about how to reason with that evidence. 3DFusionMemory fuses current-scene observations into queryable spatial relations. A Spatial Skill Library provides reusable tool procedures, and Spatial Cognition associates task conditions with experience about when and how to use memory and skills. Completed trajectories are abstracted into process records and consolidated between task blocks, allowing later decisions to draw on earlier execution without transferring scene coordinates or reference answers. Across five spatial-reasoning benchmarks, SpatialBrain improves on direct answers from the same backbone on four and ties on the fifth. Component comparisons, experience-coverage curves, and traced resource decisions characterize how the framework accumulates and uses these resources.

## 一、核心问题与研究动机

- **问题定位**：空间推理不仅是“能否调用几何工具”，更关键的是**判断何时直接观察已足够、何时需要重建、测量或切换参考系**。不同问题（可见属性、物体相对方向、跨视图距离、路线追踪）所需的计算量级不同。
- **现有方法的不足**：
  - 直接回答可能忽略必须跨视图整合的信息；无差别重建则带来不必要成本与噪声证据。
  - 训练式空间表示（SpatialVLM、SpatialRGPT）与工具式方法（感知/重建/仿真 API）扩展了“可用的计算”，但**拥有资源不等于知道何时使用资源**。
  - 已有 agent 记忆方法保留反思与工作流，但常混淆“场景坐标”与“可迁移经验”——技能流程可跨场景复用，其操作过的坐标不能。
- **核心挑战**：在保留“资源使用经验”的同时，把每个答案锚定在当前场景上。论文的解法是将三者分离：
  - **场景证据**（当前场景支持什么）；
  - **可复用计算**（技能如何执行）；
  - **使用经验**（何时、如何调用前两者）。
- **整体含义**：提出“自进化（self-evolution）”概念——模型权重固定，仅外部经验状态在任务块之间更新，使后续任务的资源决策受益于先前执行，且**不迁移场景坐标或参考答案**。

## 二、方法论

### 2.1 总体状态划分

- 推理器可用状态定义为：`S_{i,t} = (G_{i,t}, H_b)`，其中 `H_b = (L_b, P_b)`。
  - `G_{i,t}`：当前场景图（任务内更新）；
  - `L_b`：技能库；`P_b`：策略经验（块级提交快照）。
- 同一块内所有任务读取同一 `H_b`，但各自维护独立场景图，因此可在块内并行执行；更新仅在块结束后发生。

### 2.2 3DFusionMemory（场景证据层）

- 表示为 `G_{i,t} = (V_{i,t}, E_{i,t}, C_{i,t}, R_{i,t})`：物体节点、空间关系、相机状态、有序路线历史。
- 节点保留检测、3D 中心、点集与范围、位姿、语义轴、支持视图；通过深度与相机位姿将观测放入统一场景坐标系。
- **置信度加权融合**：对匹配物体 `o`，用 `μ_o^+ = (W_o·μ_o + w_{o,v}·μ̃_{o,v}) / (W_o + w_{o,v})`、`W_o^+ = W_o + w_{o,v}` 更新中心与权重；权重表达相对支持度，非校准概率。
- 查询返回距离、相机系/物体系关系，并附带**置信度、支持视图、歧义标记**；路线状态支持连续平移与旋转。
- 记忆可被设为“规划器可见”或仅用于答案校验，技能与推理步骤可引用同一批已落地物体。

### 2.3 Spatial Skill Library（可复用计算层）

- 每个技能定义为四元组 `ℓ = (A_ℓ, X_ℓ, P_ℓ, Y_ℓ)`：适用条件、类型化输入、参数化工具流程、返回证据。
- 技能参数指向当前任务物体，因此**过程可跨场景复用而坐标不迁移**。
- 种子技能初始化库；完成轨迹可补充重复执行模式；控制器可“隐藏 / 作为提示暴露 / 允许执行”技能。
- 可执行配置下，兼容的原始调用可被编译为参数化流程并在有限预算内测试；技能不能提供历史答案或绕过被禁用的记忆接口。

### 2.4 Spatial Cognition（策略经验层）

- 任务签名 `σ_i` 由输入可见特征构成：参考系、关系范围、输出形式、时间结构、度量需求、视图数量；**不使用参考答案或基准类别标签**。
- 资源选择：`g_i = π(σ_i; P_b, L_b) = (r_i, m_i, K_i, ν_i)`：
  - `r_i`：直接优先 or 工具辅助；
  - `m_i`：记忆关闭 / 仅校验 / 规划器可见；
  - `K_i ⊆ L_b`：允许的技能；
  - `ν_i`：验证与修订策略。
- **这是资源选择而非答案预测**；控制器由初始规则 + 存储经验组合，不训练额外模型。

### 2.5 自进化循环

- 任务完成后轨迹 `τ_i` 被抽象为**无标签记录** `d_i = Abs(τ_i)`：任务签名、资源决策、工具序列、过程检查、失败、成本；排除答案、字面坐标、原始任务内容。
- 块结束后更新：`P_{b+1} = U_policy(P_b, D_b)`，`L_{b+1} = U_skill(L_b, D_b)`——是**状态更新而非梯度步**。
- **保守准入规则（附录 D.2）**：路由/记忆替代方案需满足最小支持数、过程违规率上界（Wilson 上界）≤ ε、且候选成本上界 `≤ (1−δ)·` 默认成本下界；每次请求至多改变一个路由或记忆因子；过程反馈是执行可靠性信号，**不是正确性奖励**。

## 六、主要结论与发现

- **主结果**：SpatialBrain 在 5 个基准中 4 个优于同主干直接回答、1 个持平（SAT 91.3 vs 91.3），平均从 **67.5 → 72.6**。
- **最大增益**在 MindCube（+20.4 个百分点，67.2→87.6）；OmniSpatial（68.3→69.1）与 SpaceDG（56.9→57.9）提升较小，说明收益**依赖任务设置**。
- **错误分析**：MindCube 总体错误 344→130（−62.2%）；按推理需求，**运动/旋转**类别改善最大；MMSI 总体错误 462→429（199 次纠正、166 次反转），相机–物体与外观类下降，多步推理反而上升；类别层面存在混合甚至回退（OmniSpatial 自我中心题、SpaceDG 距离与计数题）。
- **组件贡献**：MindCube 上 Full 87.6，去掉技能库 76.7、去掉 3DFusionMemory 75.2、去掉 SpatialCognition 78.8、直接回答 67.2；Among/Around 的组件差距大于 Rotation。
- **记忆表征**：3DFusionMemory 表达的是**互补观测支持的空间关系**；保存 3D 物体的任务比例因基准而异（MMSI 50.6%、SpaceDG 37.5%、MindCube 21.0%、OmniSpatial 29.2%、SAT 18.0%），覆盖不等于检索或几何精度。
- **经验积累**：MMSI 达 165 个任务签名、24 个种子技能；MindCube 为 12 和 10；MMSI 上任务覆盖在技能覆盖趋于平台后仍继续增长。
- **成本**：在与固定策略控制均答对的配对中，部分任务显著减少 token 与调用（如 −90.4%、−66.9%），但**并非普遍更省**（如 MMSI 416 调用数与耗时反而增加）。

## 七、优点

- **概念清晰的三分法**：场景证据 / 可复用计算 / 使用经验，明确回应了“有工具≠会用工具”的痛点。
- **无需训练的自进化**：固定权重、块间更新、无参考答案、无标签抽象，避免坐标与答案泄漏，具备可检查性与可审计性。
- **保守的资源准入机制**：用支持数、过程违规率上界、成本区间比较（而非点估计）控制策略变更，降低冒险切换风险。
- **记忆设计扎实**：置信度加权融合、支持视图与不确定性标注、路线状态支持连续变换，且记忆可按需“隐藏/仅校验/可见”。
- **实验分析细致**：除主表外，提供组件消融、双维度错误分解、覆盖曲线、暴露核验、成本与失败恢复轨迹，并**主动披露**多项混杂因素。
- **诚实的局限性陈述**：明确区分“过程反馈”与“正确性”，指出覆盖≠检索准确、曲线≠普遍提升。

## 八、不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量/时长/总成本，难以评估方法在真实部署中的开销与可扩展性。
- **比较公平性受限**：表 1 跨协议、跨主干、跨服务精度混合比较；SAT 固定选项顺序；部分基线为他人报告分数，原始预测不可独立核验。
- **消融不彻底**：移除 3DFusionMemory 连带移除记忆校验；MMSI 早期组件配置未验证为完整移除；空白答案计入错误放大了配置间差距，组件贡献**无法被干净隔离**。
- **自进化证据

- **自进化证据仍以描述性为主**：覆盖曲线、暴露计数与定性轨迹能够说明经验被积累和调用，但尚不足以证明自进化在广泛任务上带来稳定、可泛化的性能提升；缺少跨随机种子、任务顺序置换、置信区间与显著性检验，也未评估长期运行中的遗忘、负迁移或策略漂移。
- **统计严谨性不足**：主结果以平均准确率呈现，未报告方差、配对检验或效应量；经验覆盖曲线不是性能学习曲线，无法区分“经验被使用”与“经验使用后变好”。5 条独立流虽增加观察面，但仍不足以刻画任务顺序和基准构成带来的混杂。
- **经验准入偏重“过程可靠”而非“答案正确”**：保守准入使用支持数、过程违规率与成本上界，能降低冒险切换，但也可能固化“执行成功率高、成本低、答案仍错”的路由；对困难题所需的必要重建、测量或参考系切换，可能因成本约束被抑制。
- **技能库质量控制不充分**：自动补充的技能可能冗余、过拟合种子流程，或其适用条件与参数绑定在跨场景时失效；论文未系统评估新增技能的精确率、复用率、失败模式及对技能库长期膨胀的影响。
- **记忆评估仍偏覆盖统计**：保存 3D 物体的任务比例不等于检索正确率或几何精度；置信度权重被明确为非校准概率，其阈值、歧义标记与误匹配传播对下游决策的影响缺少校准分析。动态路线在遮挡、重复纹理、尺度变化和长时程漂移下的鲁棒性也未充分验证。
- **成本核算不完整**：token 与调用次数节省只在部分配对任务中显著，且未控制并发、缓存与服务波动；缺少端到端延迟、能耗、API 费用以及经验状态维护/检索本身的开销，因而难以判断真实部署中的净收益。
- **泛化与部署验证有限**：评测集中于 5 个静态图像或有限视图基准，主干固定为 GPT-5.6-sol，跨主干、跨模态、主动视角选择、真实机器人闭环与多智能体场景的可迁移性未知；多语言、标注偏差与领域偏移亦未讨论。
- **可复现性与审计边界**：表 1 混合已发表结果与自评结果，部分基线预测不可独立核验；未报告随机种子、服务版本、图像哈希与完整提示/技能库状态，复现难度较高。无标签抽象虽降低答案与坐标泄漏风险，但任务签名仍可能编码基准分布特征，错误经验也可能跨任务传播。
- **理论保证缺失**：方法未提供资源选择策略的收敛性、遗憾界或安全性形式化保证；保守准入在稀疏支持时趋于不更新，冷启动高度依赖种子技能与初始规则，改进速度与上限均缺少理论刻画。

## 九、总体评价

SpatialBrain 的主要贡献不在于“全面刷新 SOTA”，而在于把空间推理中的核心难点重新表述为**场景证据、可复用计算与使用经验的三层分离**，并给出一个无需训练、可审计、块间更新的工程框架。其最有价值之处是：让“何时直接观察、何时重建/测量/切换参考系”成为可记录、可复用且不迁移坐标的资源决策；3DFusionMemory 的置信度融合与技能参数化也较好回应了跨场景复用问题。

但论文的证据强度仍落后于概念主张：主实验增益依赖任务设置，消融无法干净隔离组件，自进化主要被“覆盖与调用”证明而非“稳定提升”证明，成本收益亦非普遍。若要将该框架推进为可靠方法，建议补充：多随机种子与任务顺序置换下的配对统计、经验学习曲线与负迁移分析、记忆检索/几何精度的独立基准、技能质量筛选与淘汰机制、将过程可靠性与答案正确性解耦的准入规则，以及跨主干和真实闭环环境中的端到端成本—性能评估。
