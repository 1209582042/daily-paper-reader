## 摘要
几何结构对于机器人操作和理解三维世界至关重要。大多数VLA模型依赖当前观测的二维表示，而几何感知方法通常需要额外的三维信息。然而，从单次观测中独立推断出的几何信息往往被丢弃，而未被累积为持续的任务表示。我们的关键见解是：动作生成需要一种紧凑、与任务相关且可持续更新的几何抽象，而非每一步都进行完整、可渲染的三维重建。我们提出GeoMem-VLA，一种VLA框架，它将显式三维监督内化为专用几何token，并将其作为时序记忆加以维护以用于动作生成，而无需将VLM原生视觉嵌入与教师特征空间直接对齐。在训练期间，一个冻结的几何基础模型通过几何流匹配目标，基于当前场景点图和未来末端执行器轨迹，对可学习的GeoPlan token进行监督。这些token与观测表示的记忆相集成；在此过程中，历史信息被检索、与当前观测自适应融合，并随着任务推进进行巩固以保留事件帧。在推理时，策略检索历史表示，并将其与当前工作表示融合以预测动作，而无需调用三维教师模型或显式重建场景。经过针对特定基准的下游适配后，GeoMem-VLA在LIBERO上达到98.9%的平均成功率，在RoboTwin的clean/randomized设置下分别达到91.10%/91.24%。在五个真实世界任务中，GeoMem-VLA达到78.0%的平均成功率。这些结果表明，将三维场景理解内化并加以记忆是机器人控制的一种有前景的方法。

## Abstract
Geometric structure is essential for robotic manipulation and understanding the 3D world. Most VLA models rely on 2D representations of current observations, while geometry-aware approaches often require additional 3D information. However, geometry inferred independently from individual observations is often discarded rather than accumulated into a persistent task representation. Our key insight is that action generation needs a compact, task-relevant geometric abstraction that can be continuously updated, rather than a complete, renderable 3D reconstruction at every step. We introduce GeoMem-VLA, a VLA framework that internalizes explicit 3D supervision into dedicated geometric tokens and maintains them as temporal memory for action generation, without directly aligning the VLM's native visual embeddings with the teacher feature space. During training, a frozen geometry foundation model supervises learnable GeoPlan tokens through a geometric flow-matching objective over the current scene point map and future end-effector tracks. These tokens are integrated with the memory of observation representations, where historical information is retrieved, adaptively fused with current observations, and consolidated to retain event frames as the task progresses. At inference, the policy retrieves historical representations and fuses them with the current working representation to predict actions, without invoking the 3D teacher or explicitly reconstructing the scene. After benchmark-specific downstream adaptation, GeoMem-VLA achieves 98.9% average success on LIBERO and 91.10% / 91.24% on RoboTwin's clean/randomized settings. Across five real-world tasks, GeoMem-VLA achieves 78.0% average success. These results suggest that internalizing and remembering 3D scene understanding is a promising approach to robot control.

## 2. 方法论

### 2.1 核心思想
- 在 VLM 输入序列中追加 **K 个可学习 GeoPlan marker token**，其最终隐藏状态经投影形成几何工作空间表示 `c_t`；
- 用**冻结的几何基础模型 VGGT** 作为教师，通过**几何流匹配**监督这些 token，使其同时编码**当前场景点图**与**未来末端执行器（EEF）轨迹**；
- 将几何 token 与观测表示一同存入**因果回合记忆库**，检索、门控融合后送入动作专家；
- **推理时移除教师与几何解码头**，仅保留潜 token 与记忆操作。

### 2.2 关键技术细节
- **GeoPlan token 提取**：`z_t = VLM([o_t; ℓ; q_{1:K}])`，取 K 个 marker 位置输出，经 LayerNorm + 线性映射得 `c_t ∈ R^{K×D_g}`。
- **监督目标构造**：
  - 场景目标：VGGT 当前视角点图池化为 `P×P` 网格，用置信度加权；
  - 运动目标：演示轨迹导出的未来笛卡尔 EEF 路径点，变换到当前点图坐标系并联合归一化；
  - 拼接为 `Y_t = [P_t; W_t] ∈ R^{(P²+n_e)×3}`。
- **辅助流匹配**：对 `Y_t` 加噪 `Y_{t,τ}=(1-τ)ε+τY_t`，模态感知 Transformer `v_φ` 以 `c_t` 为条件预测速度；损失对 Scene / EEF 两段分别加权（场景权重 0.5、EEF 权重 3.0）。
- **总损失**：`L = L_action + α·L_geo`，动作端为 GR00T 风格 flow-matching 专家损失。
- **记忆结构**：两路观测流（视觉 token + 末位 VLM 状态 token）与一路几何流，各自独立记忆库。
- **因果时序检索**：每步仅从**同回合更早条目**检索（当前条目先检索后写入，避免自检索），键上加入学习的时间戳编码。
- **记忆整合（Consolidation）**：库满时选**最相似的时间相邻对**，以元素均值替换并标为较晚时间戳——稳定阶段冗余被压缩，特征突变的事件帧更易保留，形成“事件级关键记忆”。
- **门控几何融合**：视觉 token 对几何 token 做交叉注意力，再经通道门控 `g_t = σ(W_g[h_t;e_t]+b_g)` 融合；几何通路零初始化，初期偏向视觉。
- **事件感知训练**：从同一回合采样**时间上远离**的观测并保持时间顺序，扩大检索覆盖的历史跨度。

- **超参敏感性未探讨**：几何损失权重 α、场景/EEF 损失权重（0.5 / 3.0）、marker 数量 K 等均未给出敏感性分析或选择依据，读者难以判断性能对超参的鲁棒性。
- **推理开销缺乏定量报告**：虽然强调“推理时移除教师与解码头”，但未报告 GeoPlan token、三路记忆库检索与门控融合带来的实际延迟、显存占用与吞吐变化，也未与显式 3D 重建方法做“成本—性能”对照。
- **记忆压缩不可逆**：库满时以相似相邻对的元素均值替换并标记较晚时间戳，属于有损压缩；一旦早期关键帧被合并，后续无法恢复，长回合任务中可能造成不可逆的信息损失。
- **失败模式分析不足**：真实世界任务间成功率从 0% 到 100% 跨度较大，但文中未系统归类失败原因（如遮挡恢复失败、双臂协调失败、记忆误检索等），削弱了对方法边界的理解。
- **跨具身泛化未验证**：真实实验虽用两个双臂平台，但未报告跨平台迁移或零样本泛化实验；方法对单臂、移动平台或不同动作空间的适用性仍不明确。
- **教师依赖的误差传播未量化**：点图与 EEF 监督均来自冻结 VGGT，但未分析教师置信度低或几何退化场景（如透明、反光、纹理缺失物体）下的性能下降程度。
- **与同期强基线比较有限**：仿真对比多为引用第三方数字，缺少在同一代码库、同一数据与训练预算下的受控复现，绝对领先幅度较小，结论稳健性有待加强。

## 9. 改进方向与启示

- **补齐可复现性信息**：报告 GPU 型号与数量、训练墙钟时间、总 GPU-hours、推理延迟与显存占用，使算力成本与部署可行性可被独立评估。
- **强化真实世界证据**：将每任务 rollout 提升至数十次以上，报告多随机种子/多次训练的均值与方差，并给出置信区间；对失败案例做系统性归因分析。
- **开展超参与容量敏感性研究**：对 α、场景/EEF 损失权重、K、记忆容量与合并阈值做网格或消融扫描，给出性能—成本曲线，明确默认配置的适用边界。
- **改进记忆机制**：可探索可学习的压缩/写保护策略（如按显著性保留事件帧、引入可微遗忘门），或保留被合并条目的摘要而非简单均值，以缓解不可逆信息损失。
- **建模教师不确定性**：利用 VGGT 的置信度对几何损失做加权或过滤，在低置信区域降低监督强度，减少教师误差向策略的传导。
- **与显式重建方法做公平的成本对照**：在相同硬件上比较“潜几何 + 记忆”与“每步重建/点云输入”的精度、延迟与显存，量化“内化几何”的实际收益。
- **拓展泛化评估**：增加跨具身（单臂/移动平台）、跨场景与零样本任务迁移实验，检验几何 token 与记忆机制是否学到可迁移的空间抽象。
- **理论层面启示**：本文提示“几何监督的作用不仅是提升当前帧空间精度，更在于塑造可被时序检索的任务级空间记忆”，这一视角可推广到其他需要历史空间推理的长时程 VLA 任务；同时说明“紧凑潜表征 + 事件级记忆”可能比“完整 3D 重建”更适合实时闭环控制。

## 10. 总体评价

GeoMem-VLA 的核心贡献在于将 3D 几何理解从“推理期显式重建”转变为“训练期监督下的潜 token + 回合级时序记忆”，在保持推理路径轻量的同时，把几何信息沉淀为可复用的任务表征。其方法设计（场景点图 + 未来 EEF 轨迹联合流匹配、因果检索、相似相邻合并）具有较强针对性，实验覆盖两个仿真基准、两个真实平台、组件消融与表征诊断，证据链较完整。主要短板在于算力与推理开销披露不足、真实世界 rollout 次数偏少、比较非完全受控、超参与记忆容量缺乏敏感性分析，以及教师误差传播与失败模式未被系统刻画。总体而言，这是一项问题切口清晰、工程实用性较强的工作，但其绝对性能优势与泛化边界仍需更严格的受控实验与更大规模真实评测来确认。
