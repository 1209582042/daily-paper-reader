对支撑和包含等细粒度摆放约束进行推理，对于创建逼真的3D场景至关重要。现有方法通常依赖有向包围盒（OBB）等简化物体表示，这类表示无法感知详细几何结构，因此该问题仍是一项重大挑战。为解决这一局限，我们提出GALA，一种具有显式点云感知能力的几何感知语言模型，用于可控物体摆放。我们的模型以自回归方式运行：在给定场景上下文和摆放指令的条件下，每次预测一个目标物体的6D位姿。我们采用两阶段训练策略：第一阶段通过预训练任务对齐几何与文本模态，第二阶段针对摆放任务对模型进行微调。为促进该任务研究，我们还整理了一个多源场景数据集，涵盖多样房间类型和细粒度家具布置，并将开源以惠及社区。在我们的基准上的实验表明，我们的模型显著优于不具备显式几何推理的基线方法。我们进一步开发了一个多阶段规划—摆放—验证智能体流水线，利用该模型进行文本驱动的场景生成。项目页面：https://xccelephant.github.io/paper/gala/

## Abstract
Reasoning about fine-grained placement constraints, such as support and containment, is essential for realistic 3D scene creation. It remains a significant challenge for existing methods that rely on simplified object representations like oriented bounding box (OBB), which are blind to the detailed geometry. To address this limitation, we introduce GALA, a geometry-aware language model with explicit point cloud perception for controllable object placement. Our model performs autoregressively by predicting the 6D pose of one target object at a time conditioned on the scene context and placement instruction. We utilize a two-stage training strategy: the first stage aligns geometric and textual modalities through pretraining tasks, and the second stage fine-tunes the model for placement. To facilitate this task, we also curate a multi-source scene dataset covering diverse room types and fine-grained furniture arrangements, which will be open-sourced for community benefit. Experiments on our benchmark show our model significantly outperforms baselines without explicit geometric reasoning. We further develop a multi-stage plan-place-verify agent pipeline that uses the model for text-driven scene generation. Project Page: https://xccelephant.github.io/paper/gala/
