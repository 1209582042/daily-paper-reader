# ABSTRACT 

Vision-language (VL) models are typically built by fine-tuning a language model to attend to visual features in service of a Visual Question-Answering objective. We ask whether this alignment changes how language models represent text —especially on tasks where visualization would help, like geometry questions posed in words. We distinguish weak multimodality (the model can answer questions about an input image) from strong multimodality (the model’s text representations themselves become vision-aligned, improving performance on text-only tasks with latent visual structure). To test for strong multimodality, we construct a task of shape-counting problems with paired equivalent text and image specifications. This task is trivial when the image is provided, but requires visualization when specified in text as line coordinates. We compare instruction-tuned Qwen-2.5 and Mistral models against their vision-aligned counterparts on the text variant of the task. We find that the multimodal models do no better in this setting, despite strong performance on the image version of the task. Probing experiments corroborate this: vision-aligned decoder embeddings carry no more visual structure than their text-only counterparts. Finally, we provide an optimization objective that distills in-context visual embeddings into text embeddings. This alignment induces gains on the text variant of the task without explicit task supervision, even on samples more complex than seen during alignment. This suggests that VQA-style alignment leaves available cross-modal transfer untapped. 

# 1 INTRODUCTION 

We study the paradigm of vision language alignment used in the Qwen (Bai et al., 2025b;a), LlaVA (Liu et al., 2023), and Pixtral (Agrawal et al., 2024). These models begin with a strong language decoder that is then aligned with a pretrained vision encoder on a visual question answering task. Since the visual task feedback is used to update the language backbone, we ask whether it teaches the language decoder to build meaningful visual representations of text when useful. We distinguish between weak multimodality and strong multimodality . A weakly multimodal model can operate on input from a different modality (vision) and can answer questions about that input. However, when it comes to input that is purely in text, a weakly multimodal model will behave exactly like the language-only model. By contrast, a strongly multimodal model can form representations for inputs provided in text that are vision-aligned and consequently perform better when the tasks are more naturally represented visually (for example, front-end code and edits, or solving geometry problems specified in words). Informally, strongly multimodal models treat all modalities as part of the same cognitive system rather than as separate input pipelines that share a decoder. We call this capability of a strongly multimodal model “visualization” in this work. We argue that strong multimodality is desirable because it would utilize data from a modality (say vision) to improve performance on another modality (text). To study visualization in a tractable way, we propose a synthetic task that has the following properties (i) For each instance, there is a way to equivalently specify the question in text or image; and (ii) The problem is much easier when specified visually. Our task consists of code that draws shapes and 1arXiv:2610.25470v1 [cs.AI] 18 Oct 2026 Preprint. Under review. the language model is asked questions about the resulting image (see section 3). We evaluate Qwen 2.5 models (Bai et al., 2025b) and Pixtral / Mistral Nemo 12B (Agrawal et al., 2024; Mistral AI, 2024), which provide a clean minimal pair. We isolate the contribution of vision-language training to text-only reasoning by comparing vanilla text decoders to the corresponding VL-aligned text decoders. For both the model families, we find that vision alignment provides essentially no benefit on the text task, despite the image version being significantly easier for the same models. Linear and Contrastive probes on the decoder’s hidden states confirm that the visual structure in both models’ decoder representations are equally bad. Finally, we address whether visualization – beyond what text training alone provides– can be instilled at all. We propose an alignment method based on self-distillation: the model is trained to predict, from text, the embeddings it would have obtained given the image. Applied to our synthetic data (where paired samples are available) with no explicit task supervision , this yields substantial improvements on the text version of the task across difficulty levels. This provides a proof of concept that alignment objectives aimed at strong multimodality, by targeting text representations directly, can yield gains on this task that VQA-style alignment does not. 

Contributions. Our contributions are three-fold: • A new task that can be equivalently specified visually and in text, but is much easier to solve using visual representations. This allows us to evaluate the same models on the vision-specified version of the task and the text-specified version of the task while controlling for difficulty. Additionally, it also allows us to compare vision-aligned text decoders to pure text decoders with the upper-bound context of vision informed performance. • We present behavioral and representational evidence that for two widely used VL model families (Qwen 2.5 VL, Pixtral), the vision-aligned decoder does not construct visual representations for tasks provided in text, even when such representations are useful. • To demonstrate that stronger multimodality can be instilled in multimodal models through better alignment methods, we provide a self distillation based method to vision-align a text student to learn to use visual representations for textual tasks. With this method, we provide a proof-of-concept model that operates on the text version of our task but with vision-informed representations – demonstrating improvements across the difficulties of the task. 

# 2 RELATED WORK 

2.1 NON -TEXT REPRESENTATIONS IN PURE LANGUAGE MODELS 

Sharma et al. (2024), Patel & Pavlick (2022), Abdou et al. (2021), and Ilharco et al. (2021) explore the question of whether visual grounding (similar to our notion of strong multimodality) emerges in vanilla language models. Sharma et al. (2024) operationalize this in a code generation setting – where they make the language models generate images from descriptions via code. Ilharco et al. (2021) and Abdou et al. (2021) study whether language models learn visual relationships from their text training corpus – Ilharco et al. (2021) train mappings from BERT representations of concrete words to representations from a vision model (Faster R-CNN) and find nontrivial structural alignment while Abdou et al. (2021) do this by comparing embeddings to the CIELAB colour space. Finally, Patel & Pavlick (2022) study grounded representations in language models (GPT-2 and GPT-3). Our work asks a complementary question: what does vision-language alignment provide beyond 

language-only training. Lepori et al. (2026) show that language models presented with a random walk over a latent state-space topology come to encode that topology in their hidden states (replicating Park et al. (2025)), yet largely fail to use those representations. 2.2 VISUAL REASONING 

Xu et al. (2026) and Wang et al. (2025) both study vision-language models on geometry tasks. Xu et al. (2026) investigate math problems that they can equivalently transcribe in images, text, and both together. They observe that the tested models (Qwen-3 (Bai et al., 2025a)) simply do best on the text-only variants of the problems. Wang et al. (2025) likewise report that the contribution of 2Preprint. By contrast, we study visual representations in purely textual input. Our setup shares motivation with MentisOculi (Zeller et al., 2026), which designs tasks that require visual reasoning. They demonstrate that visual reasoning in models that can interleave text and image generation is limited by error accumulation. Our work differs in task specification: nearly all of their tasks include an image in the input, and on the one exception (RushHour) the models they test do worse with visual context than without. # 3 THE SHAPE COUNTING TASK

> (b) Output image with one trapezium and one rectangle.

Figure 1: A simple example of the paired data sample: the code snippet (left) when compiled generates the image (right). The task is simply to count shapes of each kind given either the code snippet (for the text-variant of the task) or the rendered image (for the image variant). We are concerned with problems that can be completely specified in text but would benefit a lot from intermediate computations in a visual representation space. To that end, we use a synthetic data setting for the experiments in this work. We describe it here briefly and provide the full data generation process in Appendix A.1. We procedurally generate python code that when run would output a set of shapes (specifically, rectangles and trapeziums). This allows us to generate samples of varying difficulties that deterministically specify an image but do so entirely in text; for an illustrative example, see Figure 1. To generate an item, we sample the number of rectangles and trapeziums in the scene, rotate them randomly, and sample their positions in the image. We derive from the shapes a list of edges with exact coordinates that can be turned into a python program (see Figure 1a). Crucially, we shuffle the order in which edges appear in the program. This leaves the rendered image unchanged but forces the model to compose edges that may be separated by long stretches of code. 3Preprint. Under review. 

# 4 VISION -L ANGUAGE MODELS USE POOR VISUAL REPRESENTATIONS 

Scope and Models. This study examines a popular vision-language alignment paradigm, in which a pretrained language model is coupled to a vision encoder through a translation MLP block and trained under some alignment objective (usually visual question answering). To isolate the effect of alignment on the language model’s representations, we require minimal pairs of models, that is, the text decoder before visual adaptation and the updated weights after visual adaptation. These requirements leave us with the Qwen-VL family (Bai et al., 2025b;a), Mistral / Pixtral (Mistral AI, 2024; Agrawal et al., 2024) and LLaVA (Liu et al., 2023). Furthermore, we need the VLM to do better on the image variant of the task than the text variant to conduct the study. This would validate that our synthetic data is in-distribution and the vision encoder has the features required for the image variant of the task. LLaVA fails this criterion but we present its results in Section 4.1 for completeness. The analysis in this work centres around Qwen 2.5 and Pixtral models. 4.1 BEHAVIORAL EXPERIMENTS 

The task is to count the number of shapes of each type given the source code. This requires the model to group edges into shapes and identify the angles in it. However, when the rendered image is available, the distinction (between rectangles and trapeziums) is obvious using heuristics in the image. We measure the performance of the model(s) on the task based on just the image; this establishes our upper-bound baseline. We then compare text-only models to vision-aligned text models on different answer modes (No-CoT, ICL-No-CoT, and ICL-CoT). In the N O-C OT condition, the model is provided just with the description of the task, and is asked to output the answer immediately. In the ICL-N O-C OT condition, the model is provided with the task description as well as examples of the task (i.e. in-context learning, or ICL), and is asked to output the answer immediately, Finally, in the ICL-C OT condition, the model is provided with examples and is allowed to output whatever it wants before providing the answer. For the image variant of the task, the model is simply asked to look at the image and count the number of shapes of each type (for the full prompts, see Appendix A.2). For all ICL setups, we use 3 ICL examples. We calculate the accuracy of the task strictly: the model is given a point only if it gets the count of both the shapes right.

# 5 TEACHING THE MODEL TO VISUALIZE 

The problem, as identified, is that while vision-language models can pay attention to vision features to perform question-answering tasks (including the one we propose), they don’t seem to construct internal representations that capture the visual structure of the problem. To encourage cross-modality transfer, we propose a methodology based on self-distillation. The intuition is that we will make the student model (initialized as a copy of the V+L teacher model) have the same intermediate embeddings 

without the image as the teacher calculates with the image. The Qwen 2.5 VL model treats vision features the same as token embeddings during language decoding i.e. vision patch embeddings are concatenated with text context (details about the Qwen architecture are in Appendix A.3). This allows us to get meaningful transfer by literally equating the embeddings as opposed to some projection or KL-divergence loss which is typical in distillation literature. Alignment and Length Generalization We experiment with a Qwen2.5-VL-7B-Instruct model; we use a 7B model, as opposed to the 72B or 12B models used earlier, because of compute constraints. Crucially, during alignment, neither the student nor the teacher is provided with a specification of the task (an instruction to count the number of shapes) or task labels (the counts). Therefore, any transfer comes from the teacher’s task-agnostic processing of the image. These image-conditioned representations are informative about properties such as shape counts, even though the teacher is never prompted to attend to them; this is precisely the kind of general visual structure we aim to transfer. Results Figure 6 shows that just the objective of predicting image-informed embeddings from the same model can show very strong gains on the text version of the task. The distillation model usually outperforms the vanilla text decoder and the multimodal decoder. It is important to note that the task was not specified during alignment – this suggests that image encoder does process the images in a generic way that is useful for the task post-facto and hence learning to imitate that

# 6 DISCUSSION 

We test minimal pairs of language-only and vision-and-language models, on a task that can be equivalently specified in both text and image, but where the image version is substantially easier. We demonstrate that the standard vision-language alignment paradigm like in Qwen 2.5-VL and Pixtral do not make the language modeling backbone meaningfully better at text tasks that benefit from visualization. We conduct this analysis at two levels: behavioral and representational. Behaviorally, the vision-aligned text decoder and the vanilla text decoder perform comparably poorly on the text variant of our shape-counting task, lagging significantly behind the performance of the multimodal model when it is given the rendered image. Our representational probes show some evidence of visual structure emerging in the middle layers of both classes of models, but, crucially, the vision-aligned decoders’ embeddings are typically on par with or worse than those of the vanilla text models. Together, these findings suggest that for models we study the VQA-based vision-alignment paradigm does not transfer vision priors into the language decoder’s text-processing pathway: it only teaches the model to attend to visual features when they are present, and not to think visually about text. A natural objection to this conclusion is that text training alone may already saturate whatever visual structure a language model can plausibly acquire. Prior work on emergent grounding in pure language models (Abdou et al., 2021; Sharma et al., 2024; Patel & Pavlick, 2022) has shown that nontrivial perceptual structure emerges in model that have only been trained on text. We address this objection with our distillation experiment. By aligning the Qwen-2.5-VL-7B text decoder so that, given a textual input, it reconstructs the hidden states the same model would produce given the corresponding image—without any task supervision—we induce measurable improvements on the text variant of our task. These gains length-generalize beyond the shape counts seen during alignment training. We interpret these results as a proof of concept for vision alignment that bleeds into the text pathways of a language model allowing it to use vision-informed representations for text tasks that benefit. We view our work as a call to review how vision-language alignment training is usually done i.e. visual alignment of a language model is mostly seen as a way for it to process images. Our results suggest that this does not, by itself, provide strong multimodality. If our goal is to get strong multimodality then alignment strategies that make the language model better at text tasks like the self distillation we demonstrate deserve more attention 9Preprint. Under review. 

# 7 LIMITATIONS 

The results demonstrated in this work including the proposed alignment methodology has been conducted on a single synthetic setup. Future work should expand the scope to other evaluative setups where the image-based performance is significantly better than the equivalently specified text-based performance cleanly. Furthermore, the distillation results are provided as a proof of concept. We leave adapting to scale of data for production-ready models to future work.

We provide a summary description of the Qwen 2.5 VL models here to help with the intuition behind some design decisions for the distillation objective specified in Section 5. The Qwen 2.5 VL models (Bai et al., 2025b) consist of three main components (i) the vision encoder which is a ViT with some efficiency modifications (ii) an MLP-based vision-language merger component (iii) Large Language Model which starts off as the Qwen 2.5 LM. An inference forward pass goes through the following: the image is processed by the ViT and the corresponding features are passed through the MLP merger block, following this the patch vectors are simply put in the context of the language model like the embedding of any other token. The Language Model decoder attends to the image information and the text information auto-regressively. The vision encoder is pre-trained using a CLIP-style objective first. In the second-stage, all the components including the vision encoder, the MLP-merger, and the language model are kept un-frozen and trained for a visual question answering task. This is followed by a third stage to adapt the model to work with long-context videos. A.4 EXPERIMENT HYPER -PARAMETERS
