## 摘要
长时第一人称视频给多模态语言模型带来了核心挑战：视觉流必须被压缩为一种可高效检索的记忆表示，同时仍保留回答问题所需的证据。基于一个将第一人称视频转换为具有时间依据的字幕的在线文本记忆框架，本工作系统研究了检索在情景记忆视频问答中的作用。我们在 QAEgo4D-Closed 上评估不同检索单元、查询形式、上下文预算和重排序策略对多项选择问答的影响，在保持底层生成记忆固定的同时，将检索作为主要变量进行隔离分析。我们最佳配置 Parent 先匹配细粒度字幕子块，再将它们的完整父字幕提供给推理器。该方法达到 56.4% 的准确率，与强全记忆基线和检索基线相当，同时在提问时只暴露一小部分文本记忆。更重要的是，我们的分析表明，更好的时间覆盖并不必然转化为更好的答案：增加检索预算会提升时间 Hit@K 和 Recall@K，但可能因引入视觉上看似合理的干扰项和不确定的字幕证据而降低准确率。这些发现表明，检索增强的第一人称记忆不应仅针对证据召回进行优化，还应针对检索上下文的可靠性、特异性以及答案判别价值进行优化。该研究推动了更结构化的情景记忆，即从原始字幕检索迈向面向长时第一人称推理的证据感知表示。

## Abstract
Long egocentric videos pose a central challenge for multimodal language models: the visual stream must be compressed into a memory representation that can be searched efficiently while still preserving the evidence needed for question answering. Building on an online textual-memory framework in which first-person videos are converted into temporally grounded captions, this work systematically studies the role of retrieval in episodic-memory video question answering. We evaluate how different retrieval units, query formulations, context budgets, and reranking strategies affect multiple-choice answering on QAEgo4D-Closed, isolating retrieval as the main variable while keeping the underlying generated memory fixed.   Our best configuration, Parent, matches fine-grained caption subchunks, then provides their full parent captions to the reasoner. It achieves 56.4 % accuracy, matching strong full-memory and retrieval baselines while exposing only a small fraction of the textual memory at question time. More importantly, our analysis shows that better temporal coverage does not necessarily translate into better answers: increasing the retrieval budget improves temporal Hit@K and Recall@K, but can reduce accuracy by introducing visually plausible distractors and uncertain caption evidence. These findings suggest that retrieval-augmented egocentric memory should not be optimized only for evidence recall, but also for the reliability, specificity, and answer-discriminative value of the retrieved context. The study motivates more structured episodic memories that move beyond raw caption retrieval toward evidence-aware representations for long-form egocentric reasoning.

## 1. 核心问题与整体含义

- **研究背景**：长时第一视角视频（egocentric video）包含大量重复物体、相似场景、遮挡、相机运动和细微状态变化。若在提问时直接处理完整视频，计算成本高；若把视频转成文本记忆后全部送入推理器，又会超出上下文预算并引入干扰项。
- **核心问题**：在“在线文本记忆”框架中，视频已被压缩为带时间戳的字幕记忆，那么**提问时应该检索哪些记忆片段、以何种粒度提供给推理器**？论文将检索作为主要变量，系统研究检索单元、查询构造、上下文预算和重排序策略对多项选择问答的影响。
- **整体含义**：检索在情景记忆视频问答中不仅是“缩短上下文”的工具，还会改变推理器看到的证据分布。检索到更多相关时间片段不一定带来更高答案准确率，可能引入“视觉上合理但时间错误”的干扰证据。因此，检索增强的第一视角记忆应同时优化证据召回、上下文可靠性、具体性和答案判别力。

## 2. 方法论

- **总体框架**：基于已有的在线文本记忆管线，分为三阶段：
  - **Online Memory Constructor**：将第一视角视频流切分为时间有序的短视频片段，每个片段由多模态描述模型生成自然语言字幕；字幕再被切分为更细粒度的文本子块，每个子块继承父字幕对应的时间区间。
  - **Memory Manager**：用文本嵌入模型对每个子块编码，并将“时间戳 + 子块文本 + 嵌入向量”作为记忆条目存入向量数据库，记忆随视频流增量增长。
  - **QA Handler**：提问时，将问题与所有候选答案拼接成检索查询，嵌入后与记忆条目做相似度搜索，取 Top-K 条目作为上下文，交给语言模型推理器预测答案。
- **检索查询与评分**：查询形式为问题与全部答案选项的文本拼接；相似度用余弦相似度（归一化嵌入下等价于点积）；按相似度取 Top-K 记忆条目。
- **主要检索策略**：
  - **Flat Caption Retrieval**：以完整字幕为检索和提供单位，保留完整局部上下文。
  - **Subchunk Retrieval**：以细粒度子块为检索单位，并直接把子块交给推理器，匹配更精细但上下文可能碎片化。
  - **Parent Retrieval（最佳配置）**：先用子块做细粒度匹配，再把命中的子块映射回完整父字幕，去重后提供给推理器。即“检索单位细、提供单位粗”，兼顾定位精度与上下文完整性。
  - **Hybrid Retrieval**：融合稠密向量检索与 BM25 词法检索，采用 Reciprocal Rank Fusion 合并排名，融合后的子块再扩展为父字幕。
  - **Rerank 与 Parent-Time**：重排序在父字幕扩展前对候选池重排；Parent-Time 通过时间截断只检索证据时间之前的记忆，作为严格在线设定的诊断实验。
- **评价指标**：答案准确率；检索诊断指标 Temporal Hit@K（Top-K 中是否至少一个条目与标注证据区间重叠）和 Recall@K（Top-K 时间区间覆盖标注证据窗口的比例）。按定义 Hit@K ≥ Recall@K。

## 3. 实验设计

- **数据集/场景**：在 **QAEgo4D-Closed** 测试集上进行多项选择式第一视角视频问答。视频以流式方式按 **15 秒非重叠片段**处理。
- **固定记忆设置**：所有配置使用同一套由 Qwen3-VL-8B 生成的字幕文本记忆，确保差异主要来自检索设计。
- **模型与工具**：
  - 描述器：Qwen3-VL-8B；
  - 推理器：Gemini 2.5 Flash，温度设为 0，使用结构化 JSON 解码；
  - 稠密嵌入：llama-3.2-nemoretriever-300m-embed-v1；
  - 重排序器：nvidia/rerank-qa-mistral-4b；
  - 默认检索预算 K=12；Parent 类方法检索 36 个子块并保留最多 12 个唯一父字幕；Hybrid 的 RRF 参数 k0=60。
- **对比方法**：
  - 内部消融：Parent、Flat、Sub、Parent-Rerank、Sub-Rerank、Hybrid、Parent-Time 等 7 种配置；
  - 外部基线：Ground VQA、ReKV-LLaVAOneVision 0.5B/7B、Lando et al. 的 Gemini-based 全文本记忆管线；
  - 另有一条 Parent 的检索预算曲线和定性成功/失败案例分析。
- **对比指标**：答案准确率、Hit@K、Recall@K，以及查询时 token 数和记忆足迹。

## 5. 实验数量与充分性

- **充分性**：
  - 优点是对检索单元、重排、混合检索、时间截断和预算做了较清晰的隔离比较，固定底层记忆和预算，内部公平性较好。

- **公平性**：Parent 类方法检索 36 个子块但最终保留 12 个父字幕，以对齐其他方法的 K=12 上下文预算，这一设计较合理；但主配置未强制时间因果截断，严格在线部署时需依赖 Parent-Time 诊断，而该配置准确率明显下降。闭源 Gemini 推理器也降低了完全复现性。

## 6. 主要结论与发现

- **Parent 最佳**：在 K=12 时达到 **56.4%** 准确率、Hit@K 79.0%、Recall@K 70.7%，与强全记忆基线和检索基线相当，但查询时平均仅使用 **3,600 tokens**，约为全文本记忆 10,880 tokens 的 33%。
- **Flat 次优**：55.6% 准确率，检索指标略高，说明完整字幕本身已具竞争力；Parent 在精确匹配与上下文 grounding 之间更平衡。
- **检索指标与准确率不单调**：Sub-Rerank 获得最高 Hit@K（82.4%）和 Recall@K（74.3%），但准确率仅 53.4%；说明“检索到更多相关片段”不等于“推理器能选对答案”。
- **预算曲线**：增大 K 会持续提升 Hit@K 和 Recall@K，但准确率在 K=12 达到峰值后下降。更多上下文会引入重复房间、相似物体、相近动作和不确定字幕等硬干扰项。
- **定性表现**：当检索字幕明确提到目标物体及位置时成功；当字幕只提供粗粒度或模糊空间信息时失败，例如把“刀在滤网/水槽附近”误判为“在水槽里”。
- **总体启示**：第一视角文本记忆检索不应只优化时间覆盖，还应关注证据可靠性、具体性、答案判别价值和 token 效率；未来应走向保留实体、时间锚点、动作、位置和不确定性的证据感知结构化记忆。

## 7. 优点

- **问题定位清晰**：将“记忆已生成后如何检索”从记忆构建中隔离出来，研究变量明确，避免同时改变描述器和检索器导致归因困难。
- **Parent 设计简洁有效**：子块负责细粒度匹配，父字幕负责上下文推理，是一种低成本的“检索—扩展”策略。
- **诊断指标与最终指标结合**：同时报告 Hit@K、Recall@K 和答案准确率，揭示了

检索覆盖与答案正确性之间的差距，说明仅以 Hit@K/Recall@K 评价检索并不充分，必须把“检索到的证据是否足以判别答案”纳入评估。

## 8. 局限与不足

- **泛化证据有限**：结论主要来自单一数据集、单一描述器、单一推理器和单一嵌入/重排模型，尚不能证明 Parent 策略在不同领域、语言、视频时长和描述质量下同样最优。
- **统计严谨性不足**：未报告多种子运行、置信区间或显著性检验，配置间几个百分点的差异是否稳定尚不明确。
- **描述器误差会向下游传播**：记忆固定为 Qwen3-VL-8B 字幕，检索只能在其中选择；若字幕遗漏关键物体、位置或动作，检索策略无法补救。论文的失败案例也表明，粗粒度或模糊空间描述会直接导致推理错误。
- **时间边界与父字幕扩展风险**：子块继承父字幕时间区间，细粒度定位仍受父字幕切分影响；Parent 扩展虽保留上下文，也可能把父字幕中与问题无关的内容重新引入，形成新的干扰。
- **查询构造的潜在偏差**：将问题与全部候选答案拼接为检索查询，可能使检索偏向选项文本本身，而非视频证据；论文未系统分析答案选项措辞对检索排序的影响。
- **严格在线设定未成为主配置**：主实验未强制时间因果截断，Parent-Time 诊断显示准确率明显下降，说明实际流式部署时性能可能低于主结果。
- **外部比较口径不完全等价**：不同方法的记忆表示、token 统计和检索预算不同，跨方法资源效率比较只能作参考；闭源 Gemini 推理器也降低完全复现性。
- **评估维度仍偏窄**：主要关注多项选择准确率和时间检索指标，未覆盖开放式问答、多轮追问、证据引用质量、延迟、能耗和隐私等实际部署因素。

## 9. 可改进方向

- **证据感知重排**：在相似度之外引入时间一致性、实体/位置具体性、字幕置信度和答案判别力，过滤“视觉合理但时间错误”的干扰项。
- **结构化记忆**：将实体、动作、位置、时间锚点和不确定性显式存储，而非仅依赖自然语言子块，以便更可靠地检索和扩展。
- **自适应预算**：根据问题类型和候选证据分布动态选择 K，而非固定 Top-K；对简单问题减少上下文，对需要跨片段推理的问题保留更多时间窗口。
- **因果与在线约束**：在主配置中系统加入时间截断、流式到达和延迟约束，并分析其对准确率与召回的影响。
- **更严格的评测**：多数据集、多描述器、多推理器、多种子和显著性检验；同时报告答案准确率、证据精确率、token 效率与延迟。
- **查询去偏**：分别检索“问题-only”和“问题+选项”查询，分析选项文本对检索排序的贡献，避免答案措辞主导证据选择。

## 10. 总体评价

论文把“记忆已构建后如何检索”作为独立变量，提出了简洁有效的“子块检索—父字幕提供”策略，并用检索诊断指标揭示了召回提升与答案准确率下降并存的矛盾。其价值在于强调第一视角文本记忆检索应同时优化证据召回、上下文可靠性、具体性和答案判别力；主要不足是实验覆盖和统计严谨性有限，结论仍需跨数据集与跨模型验证。
