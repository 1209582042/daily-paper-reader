## 摘要
长时程机器人操作要求机器人记住超出其短暂观测窗口的任务相关信息。现有的记忆增强策略通常在执行时从历史中检索相关信息并对其进行推理，这给高层模型带来了沉重的推理负担。为解决这一挑战，我们提出 PAL（先规划、后执行），一种用于视觉-语言机器人操作的分层记忆框架。它维护短期视觉缓冲区、语义事件记忆和可执行的 subtask_list。高层视觉-语言模型（VLM）将流式视觉观测转换为 subtask_list。在执行时，VLM 从 subtask_list 中选择当前相关的子任务，并将其传递给低层视觉-语言-动作（VLA）策略。为了教会模型向记忆中写入什么以及何时更新记忆，我们引入了一个两阶段数据生成流程：首先扩展稀疏的更新监督，然后使用带有任务落地验证的自标注来生成更匹配执行过程中所遇状态分布的训练数据。我们在依赖记忆的基准和真实世界操作任务上评估了我们的方法。在 RoboMME 上，PAL 达到 56.05% 的成功率，优于最强基线 FrameSamp-Modul 的 44.51%。在涵盖四项操作任务的真实世界实验中，PAL 达到 60.83% 的总体成功率，超过 MemER（45.00%）和 FrameSamp-Modul（28.33%）。这些结果表明，主动将未来相关子任务写入分层记忆可改善长时程视觉推理和机器人控制。代码和视频可在我们的网站获取：https://qinghangliu.github.io/pal-webpage/

## Abstract
Long-horizon robot manipulation requires a robot to remember task-relevant information beyond its short observation window. Existing memory-augmented policies typically retrieve relevant information from history and reason over it at execution time, placing a heavy reasoning burden on the high-level model. To address this challenge, we propose PAL (\textbf{P}lan first, \textbf{A}ct \textbf{L}ater), a hierarchical memory framework for vision-language robot manipulation. It maintains a short-term visual buffer, a semantic-event memory, and an executable \texttt{subtask\_list}. A high-level vision-language model (VLM) converts streaming visual observations into the \texttt{subtask\_list}. At execution time, the VLM selects the currently relevant subtask from the \texttt{subtask\_list} and passes it to a low-level vision-language-action (VLA) policy. To teach the model what to write to memory and when to update it, we introduce a two-stage data generation procedure that first expands sparse update supervision and then uses self-labeling with task-grounded verification to generate training data that better match the state distribution encountered during execution. We evaluate our approach on memory-dependent benchmarks and real-world manipulation tasks. On RoboMME, PAL achieves a \textbf{56.05\%} success rate, outperforming the strongest baseline, FrameSamp-Modul, at 44.51\%. In real-world experiments across four manipulation tasks, \pal{} reaches \textbf{60.83\%} overall success, surpassing MemER (45.00\%) and FrameSamp-Modul (28.33\%). These results show that proactively writing future-relevant subtasks into hierarchical memory improves long-horizon visual reasoning and robot control. # 论文结构化总结：Plan First, Act Later (PAL)

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型在通用机器人操作上进展显著，但多数策略仍假设世界是马尔可夫或近马尔可夫的——动作可从当前观测或短窗口帧中恢复。
- **失效场景**：在依赖记忆的长时程任务中，成功行为依赖很久之前观测到的信息，例如重复操作需记住已完成进度、主动探索需在重返场景时回忆早前发现的目标位置。
- **现有方案的痛点**：记忆增强型 VLA 通常维护一个记忆库，在执行时检索相关条目并推理。这带来两个问题：
  - 高层模型必须在庞大的记忆库中搜索并推断下一子任务，推理负担重；
  - 记忆库含大量冗余信息，检索困难，导致任务失败率上升。
- **核心洞察**：**定义未来目标的证据，往往在该目标被执行之前就已出现**。例如机器人按压按钮时，高亮方块已出现，此时即可把“拿起该方块”写入子任务列表；高亮消失后直接取用即可，无需重新识别。
- **整体含义**：提出 PAL（Plan first, Act Later），将“子任务推断”与“执行时激活”在时间上解耦，用分层、流式的可执行记忆替代“执行时大海捞针式检索”，从而提升长时程记忆依赖任务的成功率与控制稳定性。

## 2. 方法论

### 2.1 三级分层记忆

- 记忆状态定义为 \(M_t = (V_t, E_t, P_t)\)：
  - **短期视觉缓冲 \(V_t\)**：保留当前观测窗口内的近期 RGB 帧；
  - **语义事件记忆 \(E_t\)**：自然语言事件的有序列表，记录环境中已发生、可能与任务相关的事件；
  - **可执行子任务列表 \(P_t\)**：自然语言子任务的有序列表，即“未来计划”的持久载体。
- 低层策略执行形式为 \(a_t = \pi_{VLA}(o_t, \ell_t, L)\)，其中 \(\ell_t\) 为高层选定的当前子任务。

### 2.2 流式记忆推理（Stream-based Memory Reasoning）

- 每隔 \(\Delta t\) 查询一次，令 \(C_t = o_{t-\Delta t:t}\) 为自上次查询以来的图像块；VLM 输入为上一时刻记忆 \(M_{t-\Delta t}\)、当前图像块 \(C_t\) 与任务指令 \(L\)。
- VLM 一次输出三个字段：新事件 \(\Delta E_t\)、新子任务 \(\Delta P_t\)、当前执行子任务 \(\ell_t\)。证据不足时输出空值，记忆保持不变。
- **更新规则（文字化算法流程）**：
  1. 将 \(C_t\) 追加进视觉缓冲；
  2. 将 \(\Delta P_t\) 追加到子任务列表；
  3. 若 \(\Delta P_t\) 非空，则清空旧事件记忆，否则保留；再追加 \(\Delta E_t\)；
  4. 若本步发生任一更新（事件或子任务），清空视觉缓冲，否则保留累积；
  5. 更新子任务列表后事件缓冲亦清空，使后续事件识别以新列表为参照。
- **设计收益**：流式更新增量压缩视觉历史，降低长时程推理所需上下文；已存子任务可直接取用，避免在大记忆库中检索推断。

### 2.3 两阶段训练（教会模型“写什么”和“何时写”）

- **Stage 1：密集更新时机监督**
  - 原始数据仅在单个时间步 \(t_i\) 有稀疏标注 \((\Delta E_i^{ref}, \Delta P_i^{ref})\)，监督点太少，且相邻查询间视觉证据变化细微，模型难以区分“更新/不更新”。
  - 在区间 \([t_{i-1}, \frac{t_i+t_{i+1}}{2})\) 内按固定间隔采样多个查询时刻，为每个时刻构造不同长度的视觉缓冲（越晚证据越多）。
  - 以 \(\frac{t_{i-1}+t_i}{2}\) 为分界：早于分界赋空标签 \(\emptyset\)，晚于分界赋参考标签。由此把单点标注扩展为一段“时机带”上的多样本监督，让模型学习更新模式与近似时机。
- **Stage 2：带任务落地验证的自标注**
  - 动机：Stage 1 数据分布与模型实际 rollout 分布不匹配，模型可能更新过早、过频或重复写入已有内容。
  - 流程：用 Stage 1 模型在训练集上 rollout，并维护模型自己生成的记忆状态；对每个预测，验证器检查其是否等于对应参考标签、是否已在记忆中：
    - 不匹配或重复 → 置为 \(\emptyset\)；另一路预测不受影响；
    - 若到截止时刻 \(\frac{t_i+t_{i+1}}{2}\) 仍未写入第 \(i\) 个参考更新，则整条轨迹判为失败；
    - 仅保留所有必需更新点均被验证器接受的轨迹，用于再次微调。
  - **验证器细节**：非坐标文本要求完全一致（拒绝改写、遗漏、多余文本）；含坐标时要求对应字段存在且预测与参考的 L2 距离严格小于 10 像素。
  - **两种模式**：仿真用 one-pass（Stage 1 已较强，首轮多数被接受）；真实世界用 cyclic（首轮 200 条仅接受 31 条，15 轮后升至 170 条）。
- **实现**：高层为 Qwen3-VL-4B-Instruct，LoRA 微调语言模型线性层（rank 16 / α 32），视觉塔与 aligner 冻结；低层 VLA 沿用 MemER 的预训练策略，动作块长度 20。

  - GPT-6-astra + VLA（以 GPT-6-astra 替换微调高层 VLM，记忆为环境语言描述）。

## 6. 主要结论与发现

- **分组表现**：Long-video 增益最大（81.60% vs 46.00%，+35.60），说明流式更新把最长视觉历史压缩为紧凑子任务列表的效果最显著；Episode-start 77.33% vs 72.96%，且比 MemER 的 65.11% 高 12.22 个百分点，直接支持“提前规划优于按需推断”。
- **训练阶段贡献**：Stage 1 Only 37.35%、Sparse Label 43.39%、PAL 56.05%，说明稀疏监督不足、单纯密集监督又会引入分布偏移，第二阶段自标注+验证是关键。
- **更新行为**：Stage 1 Only 更新过频（相对真值 +34%~+44%）；Sparse Label 严重欠更新（长视频任务甚至 0 次更新）；PAL 更新频率接近真值（−6.4%~+4.0%）且最终列表准确率显著更高（如 VideoPlaceOrder 84%）。
- **真实世界**：PAL 总体 **60.83%**，优于 MemER（45.00%）与 FrameSamp-Modul（28.33%）；在 PickXtimes（53.33% vs MemER 0.00%）与 VideoPlaceOrder（50.00% vs 46.67%）上优势明显，VideoUnmask 与 MemER 同为 100%。
- **失败模式**：PAL 在 InsertPeg（4.80%，250 次中 101 次超时）、StopCube（5.20%，需动态预判与快速反应）、RouteStick（22.40%，高低层协调

不足——高层写入的子任务与低层实际执行进度之间存在时间错位，子任务切换不够及时；将动作块长度从 16 降到 8 后成功率升至 46.0%，说明缩短单次动作执行的“盲区”能缓解该问题，但也提示 PAL 的收益部分受制于低层策略的响应粒度。

- **对结论的解读**：PAL 的优势集中在“证据先于执行出现”且“子任务可被自然语言离散化”的任务上；对于需要毫秒级反应（StopCube）或连续精细对齐（InsertPeg、RouteStick）的任务，分层解耦反而引入额外延迟与协调成本，说明“先规划后执行”并非普适解，其适用边界值得在论文中更明确地界定。

## 7. 局限性与批判性评估

**方法层面的局限**

- **对高层 VLM 与标注质量的强依赖**：Stage 1 需要带时间戳的参考更新标注 \((\Delta E^{ref}, \Delta P^{ref})\)，论文未充分说明这些标注的来源、人工成本与标注者间一致性；若参考标签本身存在粒度或措辞差异，验证器的严格匹配会放大误差。
- **记忆清空策略偏激进**：一旦写入新子任务即清空事件记忆与视觉缓冲，虽能抑制冗余、防止重复写入，但也意味着早期证据不可回溯。若某条子任务在后续执行中失败需要重新定位目标，系统缺乏“回查”机制。
- **子任务列表只增不改**：列表为单向追加结构，缺少修改、撤销与优先级重排；一旦高层写入错误子任务（如误识别目标），错误会持续传导至低层，论文未报告此类错误的恢复率。
- **缺乏子任务级失败检测与重试**：低层执行失败后，高层是否重新规划、如何重新规划，论文着墨较少；这恰是长时程任务中最常见的失效来源。
- **验证器脆弱性**：非坐标文本要求完全一致，实质上惩罚了语义等价但措辞不同的正确预测；坐标阈值固定为 10 像素，对不同分辨率/视角的泛化性存疑。真实场景 cyclic 模式首轮 200 条仅接受 31 条、需 15 轮才升至 170 条，也侧面反映自标注流程的数据效率不高。
- **超参数 \(\Delta t\) 与查询频率**：更新周期如何选取、对成功率与推理开销的敏感性如何，缺少系统性分析；真实场景高层查询频率与 10–12 Hz 的低层控制频率之间的延迟预算未被量化。

**实验层面的局限**

- **基线可比性**：多数基线数值直接引自 RoboMME 原文（3 checkpoints × 3 seeds），而 PAL 使用 5 seeds，评测预算不对等；GPT-6-astra + VLA 仅 1 个 seed，其 39.75% 的结果统计置信度弱，作为对比项说服力有限。
- **真实世界样本量小**：每任务 30 次评估、方差大（MemER 在 VideoPlaceOrder 上标准差达 ±30.55），PickXtimes 上 MemER 为 0.00% 的极端值也可能受任务难度分层影响，宜报告逐难度等级结果。
- **任务覆盖面**：16 个仿真任务与 4 个真实任务均属桌面级操作，且都满足“子任务可语言化、证据可视觉观测”的前提；对需要力/触觉反馈、不可语言化技能或多人/动态环境的任务，结论外推性未知。
- **消融的完整性**：已有 Sparse Label / Stage 1 Only / Update Gate 三档较好地分离了“写什么”与“何时写”，但缺少“固定周期全量重推理”“不清空记忆”等变体，因而无法直接量化“清空策略”与“流式增量”各自的贡献。

**写作与呈现**

- 论文对失败案例的归因（InsertPeg 超时、StopCube 反应延迟）较为诚实，但对“为何分层解耦在这些任务上反而更差”的机制解释仍偏定性，缺少如高层查询延迟、子任务切换次数的定量剖析。

## 8. 总体评价与启示

- **核心贡献清晰且具迁移价值**：“证据先于目标出现”这一观察朴素但有力，把“推断何时做”前移到“证据出现时即写入计划”，将长时程记忆问题转化为可控的流式增量写入问题，是本文最具启发性的思想。
- **工程完整度高**：三级记忆结构、流式更新算法、两阶段训练（密集时机监督 + 带验证的自标注）构成闭环，且仿真与真实机器人均有验证，算力与训练细节披露充分，可复现性较好。
- **增益显著但有条件**：Long-video 分组 +35.60 个百分点的提升表明该方法在“长视觉历史、离散子任务”场景下确有实效；但 InsertPeg、StopCube 的低成功率提示其更适合“规划主导、执行容错”的任务，而非“反应主导”的任务。
- **可延展方向**：子任务列表的可编辑/回滚机制、自适应更新周期、高层-低层联合微调以缓解时间错位、引入失败检测触发重规划，以及将记忆结构扩展至力/触觉等非视觉模态，都是自然且有价值的后续工作。
