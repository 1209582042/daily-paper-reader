## 摘要
长时程机器人操作需要随关键信息而非执行时间扩展的记忆。我们提出一种参数空间记忆框架，其中每个片段被存储为可分离对象。神经隐式表示从共享的元学习初始化出发拟合到片段视频；所得权重增量构成记忆。关键在于，无论片段跨越一百帧还是十万帧，该增量都保持固定大小。学习到的投影器将权重增量映射为 token 嵌入，用于条件化语言模型进行问答，并条件化解码器进行联合命令回归，而查询时无需检索帧。在 RoboMME 上，语言模型在所有问题类型上均超过随机水平，解码器达到平均 $R^2$ 为 0.51。将增量替换为匹配噪声会使性能下降 11.4 个点，而随机初始权重不可解码，证明元学习初始化对于嵌入片段内容至关重要。通过将个体经验表示为公共参数空间中的固定大小权重增量，该方法将记忆成本与时间跨度解耦，并为可扩展的流式记忆提供基础。

## Abstract
Long-horizon robotic operation requires memory that scales with essential information rather than execution time. We present a parameter-space memory framework where each episode is stored as a separable object. A neural implicit representation is fitted to episode video from a shared, meta-learned initialization; the resulting weight delta constitutes the memory. Crucially, this delta remains a fixed size regardless of whether the episode spans a hundred or a hundred thousand frames. A learned projector maps the weight delta into token embeddings, conditioning a language model for question answering and a decoder for joint command regression, without frame retrieval at query time. On RoboMME, the language model exceeds chance across all question types, and the decoder achieves a mean $R^2$ of 0.51. Replacing the delta with matched noise drops performance by 11.4 points, while random-origin weights are non-decodable, proving the meta-learned initialization is essential for embedding episode content. By representing individual experiences as fixed-size weight deltas in a common parameter space, this approach decouples memory cost from time horizon and provides a basis for scalable streaming memory.

# inr2action 论文详细总结

## 1. 核心问题与研究动机

- **背景问题**：长时程机器人操作本质上是非马尔可夫的——决定当前动作所需的信息（累积量、被遮挡前的属性、episode 起始时固定的参照）往往已离开视野，分布在整段历史中，而非存在于任何单帧。
- **现有方案的三类记忆载体及其缺陷**：
  - **瞬态激活**（LSTM 隐状态、Transformer KV 缓存）：信息绑定于当前前向计算，计算结束后无法独立查询。
  - **显式外部存储**（可微记忆矩阵、文档检索）：容量与模型解耦，但记忆必须先被检索才能参与推理。
  - **参数化记忆**（Titans、GradMem）：在推理时用梯度更新单个持续运行的记忆模块，主要面向语言序列，且难以把**单个经验**表示为可分离对象。
- **核心痛点**：把完整观测流喂回策略，成本随时长增长，而非随"真正需要记住的信息量"增长。
- **论文主张**：记忆应当是**固定大小、可独立寻址的参数空间对象**，把记忆成本与时间跨度解耦。

## 2. 方法论

### 2.1 核心思想
- 每个机器人 episode 被拟合为一个神经隐式表示（INR，基于 NeRV 的视频 INR）；从**共享的元学习初始化 θ** 出发拟合得到参数 φ，定义**权重增量 Δ = φ − θ** 作为该 episode 的记忆。
- Δ 的大小**与帧数无关**：无论 episode 是 100 帧还是 10 万帧，记忆体积恒定。

### 2.2 查询方式（两条读出路径）
- **问答**：`ŷ = g(f_ψ(Δ), q)`，语言模型同时以投影后的权重 token 和自然语言问题为条件。
- **动作解码**：`â = h_ω(g(f_ψ(Δ), q)) ≈ a ∈ R^d`，用回归头替换语言解码头，输出 episode 观测结束时刻的绝对关节空间指令（7 维关节角 + 1 维夹爪）。
- 查询时**不存储、不重建、不检索任何帧**。

### 2.3 关键技术细节
- **INR 编码器**：位置编码 → 三层 MLP stem → NeRV 块（3×3 卷积 + PixelShuffle + GELU）逐级上采样 → 1×1 卷积输出 RGB 帧。
- **重建损失**：`L_NeRV = λ‖x̂−x‖₁ + (1−λ)(1−SSIM(x̂,x))`，λ = 0.7；L1 保像素精度，SSIM 保局部结构。
- **元学习**：用 MAML 学习共享初始化 θ，内循环学习率为逐参数向量、与 θ 联合学习，K = 3 步（沿用 MetaSDF）；每个 episode 再以 500 步全批量 Adam 拟合。
- **权重-Token 投影器 f_ψ**：Δ 是逐层张量集合，按 Inr2Array 思路**逐张量独立线性投影**到共享隐宽 c̃ = 256（避免展平丢失层结构），每层经自适应平均池化压成 tpl = 8 个 token，7 个活跃张量拼接为 **N = 56 个 token**，最后经共享 LayerNorm + 线性层对齐到骨干隐维。
- **输出头**：问答用 TinyLlama-1.1B-Chat；动作用 Pythia-400M（取自 TinyVLA，去掉视觉塔、多模态投影器与扩散头）；回归头为三层 MLP + Huber 损失，目标按维标准化。
- **两阶段训练**（沿用 LLaVA/LLaNA）：阶段一冻结骨干、只训投影器与占位嵌入（15 epoch，lr 1e-4）；阶段二联合低学习率微调（3 epoch，lr 2e-5，余弦衰减 + 3% warmup；动作读出扩到 10 epoch）。
- **防止"token 被忽略"的对比约束**：同一批次内把 Δ 换成另一样本的 token 得到 L_swap，加入铰链惩罚 `L_contrastive = max(0, m + L_real − L_swap)`，m = 0.5，λ_c = 1.0。
- **去偏评分**：候选答案得分 = 带 Δ token 的 NLL 减去不带 Δ 的 NLL，只保留权重 token 带来的偏好变化，取最小得分者为预测。

## 3. 实验设计

- **数据集/基准**：RoboMME（基于 ManiSkill 仿真器，7-DOF Franka Panda，64×64 px 帧）。
- **任务构成**：16 类任务、4 个记忆套件——Counting（时序）、Permanence（空间）、Reference（物体）、Imitation（程序性）；每类 100 个源 episode，共 1600 个，按 70/15/15 划分。
- **数据增强式扩增**：每个 episode 采 10 个随机截断点 T_cut 分别拟合 INR，每配置共 16,000 个拟合 INR。
- **读出标签**：gripper（当帧可解）、choice action（原子动作）、subgoal（细粒度子步骤）、task goal（任务指令），以及 joint action（8 维关节指令）。
- **对比/对照设置**：
  - 阶段一 vs 阶段二（冻结 vs 微调骨干）；
  - **匹配噪声控制**：把 Δ 换成同形状高斯噪声后经同一投影器；
  - **6 种 INR "flavor" 消融**：初始化（元学习 M / 随机 R）× 监督信号（像素 P / DINO D / CLIP C / 组合）；
  - **任务内控制**：任务内重新计算 R²，排除靠指令区分任务的嫌疑；
  - 干扰项只在同任务标签词表内采样，迫使模型依赖实例级内容；
  - t-SNE 可视化元学习 vs 随机初始化的权重空间结构。
- **说明**：论文**未设置外部基线**（如直接看帧的 VLM 或其他记忆方法），也未做闭环 rollout。

  - 动作解码实验（阶段一/阶段二，bootstrap 95% 置信区间，逐维 R²、MAE、夹爪符号准确率）；

  - 6 种 flavor × 2 种子的消融表，含 Δnoise 列；

- **充分性评价**：
  - **优点**：控制变量设计较严谨——噪声替换、任务内重算、初始化消融三者结合，能较有说服力地把性能归因于 episode 内容本身；去偏评分（减先验 NLL）避免了模型先验污染。
  - **不足**：仅 **2 个训练种子**，语料规模有限，作者自己承认相邻配置 1–3 个百分点的差异不应过度解读；**缺少外部基线**，无法判断该方法相对"直接给帧的 VLM"或其它记忆方案的相对位置；全部为离线单步评估，未涉及闭环策略性能。
  - **公平性**：内部对照公平，但跨方法比较维度缺失，结论的外部效度受限。

## 6. 主要结论与发现

- **权重 token 可被语言模型"读懂"**：仅凭 56 个投影 token、无任何帧访问，TinyLlama 在所有问题类型上超过随机水平；阶段二总体 47.2% vs 池化随机 34.6%（+12.6 pp），其中 choice action +16.1、gripper +19.1、subgoal +9.5、task goal +3.5；Cohen's κ 0.31–0.45。
- **冻结骨干只能读出瞬时状态**：阶段一仅 gripper 显著超随机（+12.4 pp），说明进度类信息存在但需要微调语言模型才能被消费（与 LLaNA 一致）。
- **同一 Δ 可驱动动作**：动作解码平均 R² 从阶段一 0.48 提升到阶段二 0.51（MAE ≈ 0.15 rad），夹爪符号准确率 81.4%；16 个任务内 R² 全为正（约 0.19–0.80），说明不是靠指令区分任务。
- **元学习初始化是必要条件**：随机初始化权重**不可解码**——随机起点 flavor 在 gripper 上停在 50% 随机线；把 Δ 换成匹配噪声后，Flavor 2 总体从 47.2% 掉到 35.9%（−11.4 pp），动作 R² 从 +0.51 崩到 −0.55，且逐维为负——说明系统确实依赖 token 而非退

化到语言先验或任务标签；权重空间本身承载了可被消费的 episode 内容。

- **记忆成本与时间跨度解耦得到实证支持**：同一 Δ 的维度不随 T_cut 变化，而在不同截断点上仍能支撑 QA 与动作读出，说明"固定体积记忆 + 按需查询"在原理上可行，代价不再随时长线性增长。
- **信息类型与可解码性存在梯度**：瞬时/局部状态（gripper）最易读出，细粒度程序性信息（subgoal）次之，而全局任务语义（task goal）增益最小——提示当前 56-token 的容量与投影方式对"高层抽象"的压缩仍有损耗，Δ 更擅长保留与动作直接相关的状态轨迹。
- **元学习塑造了权重空间的可分结构**：t-SNE 显示元学习初始化的 Δ 按任务/记忆套件形成更清晰的簇，随机初始化则弥散；这与"随机起点不可解码"互为佐证，说明共享初始化不仅加速拟合，还提供了跨 episode 可比较的坐标系统，使线性投影器能找到稳定的读出方向。
- **监督信号的选择影响有限但非无关**：6 种 INR flavor 的对比显示像素监督（P）与 DINO/CLIP 特征监督在多数指标上差距不大，组合信号未带来一致增益；说明瓶颈更可能在"权重→token 的投影与语言对齐"，而非 INR 的重建目标本身。

## 7. 主要贡献与创新点

- **概念层面**：把"episode 记忆"重新表述为**参数空间中的可寻址对象**（Δ = φ − θ），提出以 INR 拟合作为"写入"、以权重 token 投影 + 语言模型作为"读出"的记忆接口，绕开了检索—重建—回放视频的常规路径。
- **方法层面**：
  - 将 Inr2Array 式的逐张量线性投影用于**视频 INR 的权重增量**，保留层结构并压到 56 个 token，使 1B 级语言模型可以直接消费；
  - 提出**交换对比铰链损失**，显式惩罚"忽略 token"的退化解，这是权重 token 类方法中容易被忽视的失效模式；
  - 提出**去偏 NLL 打分**，用"有 Δ 与无 Δ 的 NLL 之差"消除语言先验，使评测更贴近"记忆贡献"而非"常识猜测"；
  - 用**匹配噪声替换**与**任务内重算 R²**两种控制，把性能归因从"任务标签/指令"剥离到"实例内容"。
- **实证层面**：在统一基准上同时验证了同一 Δ 可服务**语言问答**与**连续动作回归**两种读出，给出了"权重即记忆"可行性的定量证据，并系统报告了失败模式（随机初始化、噪声替换）作为边界条件。

## 8. 局限与不足

- **缺少外部基线**：未与"直接把帧/视频喂给 VLM"、"检索式记忆"、"循环策略"等方法对比，无法回答"参数化记忆是否比朴素方案更划算"这一核心竞争性问题。
- **离线单步评估**：动作解码只评估 episode 结束时刻的单步绝对指令，未做闭环 rollout，无法判断 R² ≈ 0.51 是否足以支撑真实控制；MAE ≈ 0.15 rad 在精细操作中可能仍偏大。
- **规模与统计效力有限**：2 个训练种子、每任务 100 个源 episode，1–3 个百分点的差异不具判别力；Cohen's κ 0.31–0.45 属中等一致性，距离可靠部署尚有距离。
- **拟合成本未计入**：每 episode 需 500 步全批量 Adam 拟合 INR，"写入"成本随时长/分辨率增长，论文未报告该开销，也未与"直接存帧"的存储/计算做定量权衡；"成本与时长解耦"严格说只成立于**查询阶段**，写入阶段仍与帧数相关。
- **容量上限未刻画**：固定 56 token 对不同复杂度 episode 的信息瓶颈缺乏分析（如更长时长、多物体交互、需保留精确数值累积量的任务）。
- **依赖元学习初始化**：随机初始化完全失效意味着方法对元训练分布敏感，跨域/跨机器人形态的迁移性未知。
- **仿真与低分辨率**：64×64 px、ManiSkill 单一机械臂，真实场景的视觉噪声、光照与遮挡未覆盖。
- **算力信息缺失**：GPU 型号、数量、总时长均未报告，复现门槛不透明。

## 9. 启发与可延伸方向

- **记忆的"写入"成本是下一步关键**：若能用 amortized encoder 直接预测 Δ（而非每 episode 迭代拟合），或采用少步元学习，才能让"写入"也脱离时长依赖。
- **容量自适应**：可按 episode 复杂度动态分配 token 数（如重要性加权的张量选择），或用层次化 token（层内/层间）替代固定 8 token/层。
- **与闭环策略结合**：把 Δ 作为策略的额外条件输入，检验其是否能替代历史帧堆叠，从而在长时程任务上降低推理成本——这是该工作最有价值但尚未验证的应用假设。
- **读出接口的通用化**：权重 token 与 VLM 的对齐流程可迁移到其它"以拟合参数为记忆"的场景（如场景重建、用户偏好、多轮对话状态）。
- **评测协议贡献**：噪声替换、去偏打分、任务内 R² 这三项设计本身值得被后续记忆类工作借鉴，用以区分"真用记忆"与"靠先验猜"。

## 10. 一句话总结

论文提出把每个机器人 episode 拟合为 INR 并以权重增量 Δ 作为固定大小的参数化记忆，通过逐张量投影成 56 个 token 供语言模型直接问答与驱动动作回归，在 RoboMME 上以噪声替换、任务内重算与初始化消融等严格内部对照证明了"权重可被读懂、记忆可被寻址"，但其缺少外部基线与闭环验证、写入成本未计入、统计效力有限，因而更像是一个**概念验证型的记忆接口范式**，而非已证实的实用方案。
