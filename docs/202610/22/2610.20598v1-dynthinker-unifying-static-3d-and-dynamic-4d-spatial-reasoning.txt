ABSTRACT 

Achieving general spatial intelligence requires a unified understanding of both static 3D and dynamic 4D. However, we find that existing models struggle to excel at both: 3D post-training can weaken dynamic understanding, while 4D-specialized models often lack strong static 3D reasoning. Our analysis reveals that this spatial–dynamic interference is highly non-uniform across parameter groups, with the balance between static and dynamic capabilities particularly sensitive to changes in late-layer MLPs. To address this interference, we propose DynThinker, a unified framework for jointly strengthening static and dynamic spatial reasoning. Decoupled Exponential Moving Average (D-EMA) applies configurable group-wise averaging to constrain drift in interference-sensitive pretrained parameters while preserving flexibility for capability enhancement. Spatial-Dynamic Fusion (SDF) complements D-EMA by selectively integrating spatial and temporal priors from a dynamic geometry encoder into intermediate VLM representations under semantic guidance. Across ten metrics spanning nine static 3D and dynamic 4D benchmarks, DynThinker achieves the highest average score among all evaluated models. 1 INTRODUCTION 

Spatial intelligence has emerged as a central capability for Multimodal Large Language Models (MLLMs), enabling them to understand and reason about both static 3D structure and dynamic 4D environments, supporting applications ranging from scene understanding (Yang et al., 2025a; Cao et al., 2026) to embodied interaction (Lin et al., 2025; Li et al., 2025b; Yang et al., 2026b). Recent post-training methods have substantially improved static 3D reasoning (Tong et al., 2024; Zhang et al., 2025a; Yin et al., 2025; Li et al., 2025a), while parallel efforts have extended spatial reasoning to dynamic 4D environments (Zhou et al., 2025b;a; Zhang et al., 2025b; Li et al., 2025d). Yet these directions remain largely specialized: 3D-oriented models often lack dynamic understanding, whereas 4D-oriented models remain limited in static 3D reasoning. This gap motivates a unified model capable of strong spatial reasoning across both static and dynamic environments. However, unified spatial reasoning is challenging, as improving one capability can come at the expense of the other. We find that 3D-focused spatial post-training can interfere with pretrained dy-namic competence: improvements in static 3D reasoning are accompanied by substantial degrada-tion on dynamic 4D benchmarks (Zhou et al., 2025b). This trade-off leads to imbalanced capability profiles shown in Figure 1, revealing spatial–dynamic interference that hinders joint capability im-provement. Existing capability-preservation strategies provide only partial remedies. Data replay re-quires auxiliary data and careful mixing, regularization can limit adaptation, and parameter-efficient methods such as LoRA (Hu et al., 2022) may restrict update capacity. The central challenge is therefore to preserve existing dynamic competence while allowing sufficient flexibility to strengthen static 3D reasoning, without relying on replay data or additional regularization objectives. To better understand this interference, we analyze 3D-specialized VLMs through checkpoint inter-polation and parameter-group restoration. We find that the interference is highly non-uniform across parameter groups, with the balance between static and dynamic capabilities particularly sensitive to changes in late-layer MLPs, as shown in Figure 2. Restoring these parameters to their pretrained values substantially recovers dynamic performance, while partially reversing the gains in static 3D reasoning. This opposing response indicates that the tension between static 3D enhancement and dynamic capability preservation is particularly pronounced in late-layer MLPs. Motivated by these observations, we propose DynThinker, a unified spatial reasoning framework that addresses spatial–dynamic interference through complementary designs. First, Decoupled Ex-ponential Moving Average (D-EMA) mitigates interference through configurable group-wise tem-poral averaging, allowing stronger consolidation for interference-sensitive parameters while pre-serving flexibility for capability enhancement. The decay is adjusted according to the number of EMA updates, ensuring consistency across training schedules. Second, Spatial-Dynamic Fusion (SDF) complements parameter preservation with joint spatial–dynamic perception by selectively integrating spatial and temporal priors from a dynamic geometry encoder into intermediate VLM representations. Guided by the VLM’s semantic context, SDF adaptively modulates contribution of each prior stream, enabling model to capture both static geometric structure and temporal evolution. Extensive experiments demonstrate strong and balanced performance across static 3D and dynamic 4D reasoning. Across ten metrics, DynThinker achieves the highest average score of 60.5, surpass-ing the proprietary frontier model GPT-5.6 Sol at 59.5, while also attaining state-of-the-art results among the compared open-source models on ReVSI, DSR-Bench, and DSI-Bench. Ablation studies further confirm the complementary roles of D-EMA and SDF in mitigating spatial–dynamic inter-ference while strengthening spatial reasoning, showing that spatial specialization need not come at the expense of dynamic capabilities. Our contributions can be summarized as follows: • Diagnosing Spatial–Dynamic Interference. We identify a spatial–dynamic interference in which 3D-focused post-training strengthens static reasoning while degrading dynamic competence inherited from pretraining, posing a key challenge to unified spatial reasoning. • A Unified Framework for Spatial Reasoning. To overcome this interference and bridge static 3D and dynamic 4D reasoning, we propose DynThinker, a unified framework that 2Preprint strengthens both capabilities within a single VLM. D-EMA mitigates interference during adaptation, while SDF adaptively integrates spatial and temporal priors for enhancement. • Strong and Scalable 3D–4D Performance. DynThinker achieves strong and balanced performance across ten static 3D and dynamic 4D metrics, attaining state-of-the-art results among compared open-source models on ReVSI, DSR-Bench, and DSI-Bench. 

2 RELATED WORK 

2.1 STATIC AND DYNAMIC SPATIAL INTELLIGENCE 

Progress toward real-world spatial intelligence requires vision–language models (VLMs) to reason about both static spatial structure and dynamic changes over time. Early work explores image-based spatial reasoning, with SpatialVLM learning qualitative and metric spatial relations from automati-cally generated image–question pairs (Chen et al., 2024a). Beyond individual images, benchmarks such as VSI-Bench and MindCube require models to integrate observations across multiple views and reason about 3D scene layout, spatial relationships, and metric properties (Yang et al., 2025a; Yin et al., 2025; Yang et al., 2025c). Recent work has extended spatial intelligence toward dy-namic 4D settings, with benchmarks spanning complementary data sources and reasoning targets that together motivate unified reasoning across static 3D and dynamic 4D. VLM4D combines real and synthetic videos to assess motion, viewpoint changes, and temporal continuity (Zhou et al., 2025b), while DSI-Bench focuses on disentangling observer motion from object motion (Zhang et al., 2025b). DSR-Bench instead builds on real-world videos to evaluate evolving 3D relations and multi-object interactions (Zhou et al., 2025a), and MLLM4D-Bench uses scenarios derived from stereo videos to probe spatial and temporal reasoning (Yin et al., 2026). Building on these efforts, we study how to jointly strengthen static and dynamic spatial capabilities during post-training. 2.2 GEOMETRY INTEGRATION IN VISION –L ANGUAGE MODELS 

To equip VLMs with stronger 3D and 4D reasoning, methods augment semantic visual features with explicit geometric cues (Wang et al., 2026a). Geometry encoders include VGGT, which recovers 3D scene structure from multiple views (Wang et al., 2025a), and V-DPM, which extends geometric re-construction to dynamic scenes with 3D motion estimation (Sucar et al., 2026). Existing methods incorporate geometric knowledge into VLMs through input-level feature fusion (Zheng et al., 2025), distillation (Li et al., 2025b), and intermediate-layer integration (Li et al., 2026). For static and dy-namic spatial reasoning, DSR-GSM uses π3 (Wang et al., 2026b) to capture both scene geometry and motion, together with stacked Q-Formers to select question-relevant features for VLM integra-tion (Zhou et al., 2025a). GeoSR improves geometric evidence use through geometry-unleashing masking and geometry-guided fusion, while employing separate models for static and dynamic rea-soning (Zhang et al., 2026a). Building on GeoThinker’s semantic-guided intermediate-layer inte-gration (Li et al., 2026), we introduce Spatial-Dynamic Fusion (SDF) to fuse complementary spatial and dynamic priors within a single VLM, adaptively balancing their contributions. 2.3 CAPABILITY PRESERVATION DURING POST -T RAINING 

Specialized post-training can improve target performance while degrading previously acquired ca-pabilities, a phenomenon observed in language models and other adaptation settings, including em-bodied models (Kotha et al., 2024; Hancock et al., 2026). Weight averaging provides one approach to balancing adaptation and capability retention: WiSE-FT interpolates pretrained and fine-tuned checkpoints to improve robustness (Wortsman et al., 2022), while SWA (Izmailov et al., 2018) and EMA (Morales-Brotons et al., 2024) aggregate parameter states within a training run to improve generalization. Prior work has examined how EMA hyperparameters should adapt to training scale, such as batch size (Busbridge et al., 2023). In spatial post-training, however, we find that capabil-ity interference is unevenly distributed across parameter groups, calling for more targeted control over the balance between static and dynamic capabilities. Motivated by this observation, D-EMA applies configurable group-wise averaging horizons, normalized by training duration, to mitigate interference while retaining sufficient flexibility for capability enhancement across training scales.

4 METHOD 

DynThinker unifies static 3D and dynamic 4D reasoning through two complementary components: Spatial-Dynamic Fusion (SDF) for joint capability enhancement and Decoupled Exponential Mov-ing Average (D-EMA) for interference-aware capability preservation. As illustrated in Figure 3, SDF integrates complementary spatial and temporal features from a dynamic geometry encoder into intermediate VLM representations, adaptively modulated by the VLM’s semantic context. During post-training, D-EMA applies group-specific temporal averaging to pretrained parameters, balanc-ing capability preservation with sufficient flexibility for adaptation. The model architecture, SDF, and D-EMA are detailed in Sections 4.1, 4.2, and 4.3, respectively. 4.1 MODEL ARCHITECTURE

Since the priors are injected directly into existing visual representations, SDF introduces no additional tokens to the LLM sequence. 4.3 DECOUPLED EXPONENTIAL MOVING AVERAGE 

D-EMA consolidates the post-training trajectory through group-wise temporal averaging without constraining online optimization. It decouples the consolidation of pretrained parameters from fu-sion module adaptation by averaging the former while retaining learned weights of the latter. Mo-tivated by the parameter-group sensitivity identified in Section 3, it assigns configurable averaging horizons to pretrained parameter groups according to their sensitivity to spatial specialization.

5 EXPERIMENT 

In this section, we first introduce the implementation details and training datasets, followed by evaluations on spatial and dynamic reasoning benchmarks in Section 5.1. We then present ablation studies and scaling behavior in Section 5.2. Additional controlled experiments and downstream evaluations are presented in the Appendix F.1, I.1 and G.1. 

Implementation Details. We train DynThinker with a batch size of 64 and a learning rate of 1 ×

10 −5, using 32 input frames per scene and m = 8 decoded frames in VDPM. The fusion ratio is set to rfusion = 0 .5, and the D-EMA layer boundary is b = 4 . To accommodate broader adaptation during scaled training, we use a D-EMA decay of 0.999834 for pretrained parameters, while newly introduced modules are excluded from averaging. D-EMA starts after 150 optimization steps and updates every 10 steps. Training uses 16 PPU-ZW810E accelerators with 96GB memory each. 

Training Data. Our training mixture contains approximately 2.68M samples, extending Geo-Thinker’s scaled data recipe (Li et al., 2026). It includes sampled SPAR-7M (Zhang et al., 2025a) and the LLaVA-Hound split of LLaVA-Video-178K (Zhang et al., 2024), spatial instruction data from VLM-3R (Fan et al., 2025), VSI-590K (Yang et al., 2025b), and MindCube (Yin et al., 2025), and 430k general video samples from (Yang et al., 2025b). The mixture also includes 13K DSR (Zhou et al., 2025a) samples associated with 2,000 videos, covering 26% of its official training data, and 1M MLLM4D samples from (Yin et al., 2026), covering 50% of its training set. 5.1 EVALUATION RESULTS 

We conduct evaluation across multiple benchmarks, including (1) Spatial statics: ReVSI (Zhang et al., 2026b), VSI-Bench (Yang et al., 2025a), MMSI-Bench (Yang et al., 2025c), MindCube-Tiny (Yin et al., 2025), ViewSpatial (Li et al., 2025a), SITE (Wang et al., 2025c), CV-Bench (Tong et al., 2024) and (2) Temporal dynamics: VLM4D (Zhou et al., 2025b), DSR-Bench (Zhou et al., 2025a), DSI-Bench (Zhang et al., 2025b) with sample-wise and group-wise protocol.

Component Ablations and Model Scaling. Table 3(a) incrementally builds DynThinker upon Geo-Thinker under the same data recipe and training schedule with the Qwen3-VL-4B backbone. Adding D-EMA to GeoThinker improves VSI-Bench from 51.31 to 53.14 and VLM4D from 45.20 to 53.57, recovering much of the dynamic performance lost during specialization while also improving static spatial reasoning. This substantial dynamic recovery shows that D-EMA effectively mitigates the interference introduced during 3D-specialized post-training. Replacing the geometry encoder with VDPM provides additional gains, while incorporating encoder-side spatial priors and decoder-side temporal priors further strengthens both capabilities, with the full 4B model reaching 56.56 on VSI-Bench and 59.74 on VLM4D. Scaling the complete model to an 8B backbone further improves these scores to 58.16 and 61.78. Overall, the ablation results highlight the complementary roles of D-EMA for capability preservation and SDF for enhancing static and dynamic reasoning.

Performance then remains stable be-tween 62.51 and 63.17 from 1M to 2M samples. On the full VLM4D benchmark, our 1.5M-sample model achieves 66.74, compared with 61.0 for MLLM-4D RFT. These results show that DynThinker remains effective under dedicated 4D specialization, achieving strong dynamic reasoning with fewer SFT samples and outperforming MLLM-4D RFT on the full VLM4D benchmark. 

6 CONCLUSION 

We presented DynThinker, a unified framework for static 3D and dynamic 4D spatial reasoning. Our analysis reveals spatial–dynamic interference during post-training, with the balance between the two capabilities particularly sensitive to changes in late-layer MLPs. To mitigate this interference, D-EMA preserves pretrained capabilities through group-wise temporal averaging, while SDF enhances 9Preprint spatial–dynamic reasoning by integrating complementary spatial and temporal priors into VLM rep-resentations under semantic guidance. Across diverse benchmarks, DynThinker achieves strong and balanced 3D and 4D performance. Ablation and scaling studies further validate the effectiveness of parameter consolidation and dual-stream feature integration, while showing that DynThinker re-mains effective under dedicated 4D specialization. B IMPLEMENTATION DETAILS 

B.1 MODEL CONFIGURATIONS 

Frame Sampling and Dynamic Decoding. Following GeoThinker (Li et al., 2026), we train with 32 input frames per sequence for scaled regime in the main paper. The VDPM encoder processes all 32 frames, while the sequential decoder processes features from 8 uniformly sampled frames during both training and inference. The resulting decoder features are linear interpolated along the temporal axis to construct representations for all 32 input frames. Both feature streams are subsequently resampled to the VLM’s visual token grid before fusion. 

Visual Token Compression. Following GeoThinker (Li et al., 2026), we employ a larger spatial merge size, increasing it from 2 to 4 for inputs containing more than 8 frames. For inputs with at most 8 frames, we retain the backbone’s native merge size of 2. Thus, the input-dependent merge size is

4, n > 8. (9) This configuration reduces the visual token sequence length for longer inputs while retaining a finer spatial grid for shorter inputs. The compression threshold depends on the original input frame count 

n. Consequently, our 32-frame training configuration uses spatial merge size s = 4 , with 8 frames selected for decoder processing. B.2 DATA CURATION 

For the scaled regime training of our model, we curated a large-scale multimodal dataset totaling 2.68M samples. The data composition is as follows: 

Spatial Reasoning: Cambrian-S VSI-Bench instruction (590k), SPAR (234k), VLM-3R VSI-Bench instruction (205k), VLM-3R VSTI-bench instruction (132k), MindCube training set (10k). 17 Preprint

H ADDITIONAL RESULTS (SENSITIVITY ANALYSIS )

H.1 SELECTION OF THE MLP L AYER BOUNDARY 

Figure 9 examines how the MLP restoration boundary affects dynamic and spatial performance. VLM4D accuracy remains near 51% across the earliest boundaries, close to the performance ob-tained by restoring all MLP layers. As the boundary moves deeper, dynamic accuracy declines substantially and eventually approaches the specialized model’s performance. Meanwhile, VSI-Bench accuracy rises sharply at later boundaries, indicating that retaining more specialized MLP layers favors spatial reasoning at the expense of dynamic recovery. We select b = 4 within the early plateau: restoring layers j > 4 recovers nearly the same dynamic performance as restoring all MLPs, with little change in spatial accuracy. This suggests that reverting the first four layers provides limited additional benefit for dynamic recovery. Accordingly, we define MLP layers j > 4 as the interference-sensitive group in D-EMA, allowing stronger consolidation to be assigned to these layers when differentiated averaging horizons are used.
