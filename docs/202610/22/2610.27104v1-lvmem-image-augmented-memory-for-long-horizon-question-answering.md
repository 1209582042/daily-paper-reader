## 摘要
可靠的语言引导感知对具身智能体至关重要，因为它们需要基于长观测历史回答关于物体、事件及其位置的问题。与传统视觉问答不同，现实机器人场景需要跨更长时序范围进行推理，并具备持久场景记忆。我们基于视图记忆范式，提出一种用于长时程时空问答的高效框架。现有基于视图的系统通常存储文本描述或视觉嵌入，而我们扩展 ReMEmbR 风格记忆，加入图像路径，将每条存储描述链接到其原始视觉内容。为使存储标注信息更丰富，我们在记忆构建过程中用基于光流的帧选择策略（PSFR）替代均匀采样，并存储以对象为中心的描述性场景表示，而非简单文本描述。我们进一步为基于 VLM 的智能体配备自适应检索工具，该工具返回与最相关描述关联的图像，使智能体能够决定何时需要视觉检查。在 OC-NaVQA 基准上，LVMem 在两种骨干网络下于二元和位置指标上均优于 ReMEmbR，并在二元准确率上达到或超过 4D 场景图 DAAAM 基线，同时运行于无需显式图构建的轻量级视图记忆之上。

## Abstract
Reliable language-guided perception is essential for embodied agents, where questions about objects, events, and their locations must be answered from long observation histories. Unlike conventional visual question answering, realistic robotic settings require reasoning over extended temporal horizons and persistent scene memory. We build upon the view-based memory paradigm and propose an efficient framework for long-horizon spatio-temporal question answering. While existing view-based systems typically store either text captions or visual embeddings, we extend the ReMEmbR-style memory with image paths that link each stored description to its original visual content. To make the stored annotations more informative, we replace uniform sampling during memory construction with an optical-flow-based frame selection strategy (PSFR) and store an object-centric descriptive scene representation instead of plain captions. We further equip a VLM-based agent with an adaptive retrieval tool that returns the image associated with the most relevant caption, allowing the agent to decide when visual inspection is needed. On the OC-NaVQA benchmark, LVMem outperforms ReMEmbR on binary and positional metrics with both backbones and matches or exceeds a 4D scene graph DAAAM baseline on binary accuracy, while operating on a lightweight view-based memory that requires no explicit graph construction.

## 1. 核心问题与研究背景

- **应用背景**：具身智能体（如仓储机器人）在数小时到数天的运行中会累积海量视觉流，用户会提出诸如“哪個货架上有破损的箱子”“经过装卸区时它是什么样子”这类需要回忆“看到了什么、在哪里、何时看到”的问题。
- **问题形式化**：给定连续 RGB 观测流（含位姿与时间戳）和关于物体/事件/状态的自然语言查询，需构建记忆表示，并在视觉外观、空间位置、时序顺序上联合推理后给出答案。
- **现有方法的瓶颈**：
  - 多模态大模型在长视频、持久场景记忆、大规模历史检索上仍显不足。
  - **结构化路线**（4D 场景图，如 DAAAM、HOV-SG、ConceptGraphs、Clio、Khronos）可解释、支持长时程，但依赖显式几何重建与逐物体描述生成，构建与维护成本高。
  - **视图式记忆路线**（ReMEmbR）把 VLM 生成的字幕存入向量库，支持文本/位置/时间检索，成本低，但**仅以文本进行检索与推理**，无法核查视觉细节（如颜色、招牌文字）或消歧。
- **核心论点**：文本记忆高效但会丢失视觉证据；多模态记忆信息更丰富但必须被“选择性检索”。LVMem 在保留 ReMEmbR 轻量表示的前提下，把每条描述链接回源图像，并研究“视觉证据何时真正有用”。

## 2. 方法论

### 2.1 总体思想
在 ReMEmbR 的视图式记忆上做三点增强，**不重建 3D/4D 结构、无需训练**：
1. 用光流选帧（PSFR）替代段内均匀采样；
2. 用“以对象为中心的描述性场景表示”替代普通字幕，并为每条记忆附加图像路径；
3. 为 VLM 智能体增加**自适应图像检索工具**，由智能体自行决定何时看图。

### 2.2 记忆构建
- **分段**：视频流 S 切为固定时长 T 的段 $\{s_1,\dots,s_L\}$；段 $s_i$ 含 $m_i$ 帧。
- **PSFR 选帧**：均匀采样按等间隔取 K 帧；PSFR（Patchwise Sparse-Flow Retention，源自 FocusGraph）用稀疏光流识别结构性变化强的帧，同样输出**恰好 K 帧**，从而在相同帧预算下隔离“选帧准则”的影响，剔除静止/冗余内容。
- **结构化生成、散文式存储**：VLM $\phi_\theta$ 在结构化提示 $\pi$ 下把所选帧映射为四元组
  $d_i=\phi_\theta(F_i;\pi)=(\sigma_i,O_i,H_i,X_i)$
  - $\sigma_i$：场景类型（室外含天气）；$O_i$：可见物体；$H_i$：人物及其活动与衣着；$X_i$：可读文字（逐字引用）。
  - 物体字段表示为带属性实体集合 $O_i=\{(w_j,c_j,n_j)\}_j$，$w_j\notin G$（排除 object/item/device 等泛化名词），$c_j\in C\cup\{\bot\}$（固定颜色表），$n_j\in N$（计数）。因此表示是**枚举性、属性绑定、具体化、正向表述**的。
  - **不做否定**：如“没有 ATM”在嵌入空间中与“ATM”查询距离很近，会被检索到却无答案，故空字段直接省略。
  - 生成时用字段标签，存储前**剥离标签、丢弃空字段**，合成散文 $\tau_i$——避免标签 token 在每条记录中重复而稀释嵌入。
- **记忆记录**：$r_i=(E(\tau_i),\tau_i,p_i,t_i,u_i)$，其中 $E$ 为 mxbai-embed-large-v1，$p_i$ 位姿、$t_i$ 时间戳、$u_i$ 为所选 K 帧中**第一帧**的路径（因 PSFR 已剔除静态帧，首帧可作确定性视觉锚点，无需额外排序）。存路径而非 base64，保持索引紧凑、图像留在磁盘。

### 2.3 带视觉增强的检索
- 沿用 ReMEmbR 的工具调用智能体（文本/位置/时间检索），文本检索本质是对嵌入做 top-k L2 最近邻：
  $R_k(q)=\arg\text{top-}k_{i}\, \|E(q)-e_i\|_2$，$\text{TextRetrieve}(q)=\{\tau_i\}_{i\in R_k(q)}$。
- **新增图像检索工具**：$\text{ImageRetrieve}(q)=\{u_i\}_{i\in R_M(q)}$，M 可配置；智能体可迭代调用（步数可配）。文本足够时直接作答，需要细粒度细节（读招牌、区分相似物体）时才取图。

### 2.4 视觉增强的答案生成
- 汇总所有子查询返回的图像路径集合 $U=\bigcup_{q\in Q}\text{ImageRetrieve}(q)$；若检索阶段调用过图像工具，则加载图像并附加到提示，否则退化为纯文本模式。
- 图像预处理：长边缩放到 ≤768 px、JPEG 质量 80、base64 编码、detail 级别设为 low，以降低 token 与载荷。
- 输出与 ReMEmbR 对齐的结构化 JSON（text / binary / position / time / duration）；若 API 报上下文长度错误，返回空响应而非崩溃。

- **图像检索的“适度”规律（核心负结果）**：图像并非越多越好。随着 M 从 0 增至 1~3，二元/文本准确率上升、位置误差下降；继续增至 5 时收益饱和甚至回退，推测原因是冗余图像稀释了关键证据、并抬高了上下文长度与干扰项。文本检索深度 k 亦呈类似规律：k=20 相比 k=5 带来更多召回但也引入更多噪声，需与 M 配合调参。
- **供图模式差异**：由智能体自主调用工具（tool 模式）通常优于“无条件附上 top-M 图像”（top-M 模式），说明**让模型自行判断“何时需要看”**比强制供图更有效——这与论文的核心论点（视觉证据应被选择性检索）自洽，也侧面说明 LVMem 的增益并非单纯来自“多模态输入”，而来自检索决策。
- **描述生成与提示的作用**：将字幕器从 VILA1.5-3b + 原提示替换为 Qwen3.5-9B + 结构化提示后，各图像数配置下均有提升，且在 M=0（纯文本）时提升已存在——表明“以对象为中心、属性绑定、去标签、不做否定”的表示设计本身即改善了文本检索的可检索性，视觉增强是在此基础上的**增量**而非替代。

## 7. 方法与工程层面的可取之处

- **极简而有效的设计哲学**：不训练、不重建、不引入新几何表示，仅在既有视图式记忆上增加“选帧—结构化描述—图像锚点—按需取图”四个轻量环节，复现门槛低、易迁移到其他具身/长视频问答栈。
- **成本可控**：以“存路径而非 base64”“长边 768 px + JPEG 80 + detail=low”等方式显式控制存储与 token 开销，并在 API 上下文超限时返回空响应而非崩溃，体现出对真实部署鲁棒性的考虑。
- **公平性意识**：PSFR 与均匀采样严格对齐帧预算；消融中固定嵌入模型、智能体与 k 值；以“是否超过运行间标准差”判断结论稳健性；主动报告负结果。这些做法在同类工作中相对少见。

## 8. 边界条件与可延展的改进方向

- **“首帧即视觉锚点”是启发式**：PSFR 虽剔除静态帧，但首帧未必是段内信息量最大或最清晰的一帧；可探索按清晰度/信息熵/与查询相关性动态选锚点，或为每条记忆保留少量候选帧并做二次筛选。
- **检索粒度与记忆粒度耦合**：当前以“段”为检索单元，段长 T 与帧数 K 共同决定时间分辨率；对于“持续时长”类问题，段级聚合可能天然存在量化误差，可考虑层次化记忆（段—事件—物体）或多尺度索引。
- **图像工具缺少“读图后写回”机制**：智能体看图所得结论未被回写进记忆或缓存，重复查询会重复取图；引入证据缓存/摘要回填可能进一步降低延迟。
- **评估层面**：单基准、小样本、小模型裁判，以及对闭源骨干版本的依赖，是当前结论外推的主要风险；跨数据集（FindingDory、HourVideo 等）与人工/多裁判一致性校验是必要的后续工作。

## 9. 对后续研究的启示

- **“文本检索 + 视觉核验”是一种务实的折中范式**：它以接近纯文本记忆的成本，获得了接近结构化 3D 记忆的部分可核查性，为长时程具身记忆提供了一条低门槛路线。
- **“何时看图”本身值得作为学习/优化对象**：论文的经验性结论（M=1~3 最优、tool 优于 top-M）提示，视觉证据的调用策略（预算分配、触发条件、迭代次数）可作为独立的建模问题，而非超参数微调。
- **表示设计对检索的影响被低估**：结构化、具体化、正向表述、去标签的散文式描述，在纯文本设置下即带来增益，说明“怎么写记忆”与“怎么检索记忆”同等重要。

## 10. 总体评价

LVMem 是一篇问题定位清晰、方法克制、实验设计较规范的增量式工作：它准确指出了视图式文本记忆“丢失视觉证据”的痛点，并以最小改动（选帧 + 结构化描述 + 图像锚点 + 自适应取图）给出了可用的解法，同时诚实地报告了“图像越多不一定越好”的边界。其主要不足在于评估规模与裁判可靠性有限、部分启发式（首帧锚点、段级粒度）缺少消融，以及跨方法与跨数据集的泛化证据不足。作为“轻量多模态记忆”方向的一个实证性参照，其结论（选择性视觉检索优于无条件多模态输入）具有较好的可复用价值。
