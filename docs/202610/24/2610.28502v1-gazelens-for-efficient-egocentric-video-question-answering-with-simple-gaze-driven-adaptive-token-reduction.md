## 摘要
智能眼镜可帮助用户理解自身活动与周围环境，但小型视觉-语言模型必须在有限计算量内保留有用证据。这并不容易，因为冗余帧会消耗视觉预算，而激进的空间压缩可能丢弃相关细节。尽管注视能够标识佩戴者的关注点，但问题可能需要来自周围场景的证据。为应对这些约束，我们提出 GazeLens，将帧选择与注视及问题引导的令牌缩减相结合。首先，在视觉编码之前，利用 HOG 变化与图像清晰度进行帧选择。随后，对每个选定帧，高斯池化形成注视聚焦摘要与互补摘要。由于二者的相关性取决于问题，一个轻量级门控将其融合为一个主令牌。结合一个全局场景令牌，从而在每帧两个令牌内同时保留聚焦摘要与上下文摘要。在 StreamGaze 上，GazeLens 相比所评估的全网格基线和令牌缩减基线取得更高的宏平均与微平均准确率，且输入前向 FLOPs 低于共享骨干的令牌缩减基线。

## Abstract
Smart glasses can help users understand their activities and surroundings, but small vision-language models must preserve useful evidence within limited computation. This is difficult because redundant frames consume the visual budget, while aggressive spatial compression can discard relevant details. Although gaze identifies the wearer's focus, the question may require evidence from the surrounding scene. To address these constraints, we propose GazeLens, which combines frame selection with gaze- and question-guided token reduction. First, HOG transitions and image sharpness select frames before visual encoding. For each selected frame, Gaussian pooling then forms gaze-focused and complementary summaries. Because their relevance depends on the question, a lightweight gate blends them into a primary token. Together with a global scene token, this retains both focused and contextual summaries within two tokens per frame. On StreamGaze, GazeLens achieves higher macro and micro accuracy than the evaluated full-grid and token-reduction baselines, with lower input-forward FLOPs than the shared-backbone token-reduction baselines.

- **现有方案的三个失效模式**：
  1. **缩减发生得太晚**：FastV、PyramidDrop 在语言模型内部剪枝，视觉编码与部分 LM 计算已经发生；LLaMA-VID 虽把每帧压到 2 token，但仍需编码所有采样帧；LongVU 依赖编码前计算的 DINOv2 特征。
  2. **帧选择过密或过疏**：固定帧数导致单一的全局折中，无法按内容自适应。
  3. **注视使用不当**：GazeLLM 直接以注视点硬裁剪，丢弃周边证据且对传感器抖动脆弱；Voila-A 用 Perceiver 在编码后做注视条件化，增加了注意力开销且未减少编码器输入；GazeVLM 保留全局/局部视图但 token 分配是预设的，不随问题变化。
- **关键洞察**：注视点标识佩戴者“在看什么”，但**问题所需的证据未必在注视处**（例如“用户从未注视过哪个物体”这类问题需要周边/全局信息）。因此紧凑表示必须同时保留“聚焦”与“上下文”两类摘要，且二者权重应由问题语义决定。
- **论文定位**：提出 GazeLens，把“编码前的自适应帧选择”与“注视+问题引导的空间 token 压缩”结合，在**每帧仅 2 个视觉 token**的严格预算下同时兼顾聚焦与场景上下文。

## 二、方法论

### 2.1 核心思想
三个模块分别对应一个具体失效模式：用**参数无关的图像统计量**在编码前削减时间冗余；用**软高斯池化**替代硬裁剪以保留周边证据；用**问题条件标量门控**按样本调节聚焦与互补信息的混合比例，并额外保留一个与注视无关的全局 token。

### 2.2 模块一：动态帧选择（Dynamic Frame Selection）
- 目标：帧数不固定，取 `t_min ≤ T ≤ t_max`，只把预算花在“内容真正变化”且“不模糊”的帧上。
- **HOG 转移线索**：相邻帧缩放到固定 HOG 窗口并转灰度，计算描述子 L2 距离
  `δ_i = ||φ(I_i) − φ(I_{i−1})||₂`，对光照/自动曝光变化较鲁棒。
- **清晰度线索**：3×3 Laplacian 方差 `ℓ_i = Var(Lap₃ₓ₃(I_i))`，运动模糊会使其趋近 0，无需标定。
- **融合与筛选**：对每个线索在 clip 内做 z-score 归一化 `c̃_i = (c_i − μ_c)/σ_c`，加权求和 `S_i = Σ_c w_c·c̃_i`；保留 `S_i > z_thresh` 的候选并按分数排序，超过 `t_max` 则截断。
- **去模糊修正**：每个保留索引替换为窗口 `|j−i| ≤ τ` 内清晰度最大的帧（因为变化线索常在模糊的过渡帧上取峰值）。
- **下限保障**：若不足 `t_min`（如近乎静止的片段），补入均匀间隔帧以维持最低时间信息量。
- 该模块完全无参数、在视觉编码之前运行，选帧结果可跨同一视频的多个问题缓存复用。

### 2.3 模块二：聚焦感知的注视聚合（Focus-Aware Gaze Aggregation）
- 对每个选中帧编码得到空间 patch 特征 `F_t ∈ R^{H×W×D}`，注视点为归一化坐标 `(x_t, y_t)`。
- **不用硬裁剪**（几像素抖动会选中完全不同的 patch，且丢失周边），改为在特征网格上构造各向同性高斯权重：
  `ê^t_{ij} = exp(−[(i − y_t(H−1))² + (j − x_t(W−1))²] / (2ρ²))`，`ρ = max(max(H,W)/4, 0.5)`。
- 归一化后得到两支：
  - Focus 分支 `h_t = ê / Σê` → 池化得 `g_t`（注视聚焦证据）；
  - Unfocus/Complement 分支 `h̄_t = (1−ê) / Σ(1−ê)` → 池化得 `c_t`（周边互补证据）。
- 另计算**全局 token** `m_t`（特征网格均值），提供与注视无关的场景摘要；当注视坐标缺失或抖动时可作为无偏回退。

### 2.4 模块三：问题条件语义门控（Question-Conditioned Semantic Gating）
- 问题 `u` 经 VLM 文本编码器 `E` 编码，**均值池化 + L2 归一化**得 `t`（无额外参数，消除长短问题尺度差异）。
- 两层 MLP + Sigmoid 输出**标量门** `s = σ(φ_θ(t)) ∈ [0,1]`，在 clip 内所有帧共享。
- 主 token 融合：`p_t = s·g_t + (1−s)·c_t`。`s→1` 偏向注视区域，`s→0` 偏向互补视觉证据。

### 2.5 令牌装配与训练目标
- 线性投影：`a^ctx_t = W_ctx·p_t`，`a^vis_t = W_vis·m_t`，每帧按 `[a^ctx_t, a^vis_t]` 排列作为视觉前缀，**LM 侧视觉预算严格为 2T**。
- 任务形式：四选一多项选择问答（MCQA），骨干权重冻结，仅训练 LoRA 适配器（注意力层）、线性投影和语义门。
- 损失：带标签平滑（α=0.1）的交叉熵，作用于 A/B/C/D 四个答案 token 的最终位置概率。

## 三、实验设计

### 3.1 数据集与 Benchmark
- **主评测：StreamGaze**（Lee et al., 2025），第一人称视频 QA 基准，含 **Past / Present / Proactive** 三类任务、共 10 个子任务，数据来自 EGTEA Gaze+、EgoExo、HoloAssist。
  - 官方划分：训练 5,766 QA 对，测试 1,399 题；把 proactive 题展开为带时间戳的探针后得 **2,418 个评估样本**。
- **迁移评测：EgoGazeVQA**，在 EGTEA 源上训练 4 epoch，在留出的 **Ego4D + EgoExo（1,265 例）** 上测试。
- **指标**：Macro accuracy（Past/Present/Proactive 等权平均）与 Micro accuracy（全样本汇总），外加 **每输入前向 TFLOPs**。

### 3.2 对比方法
- **无缩减 / 无注视调优的全网格基线**：SmolVLM2-256M、SmolVLM2-500M（本文骨干）、FastVLM、Mobile-VideoGPT。
- **共享骨干（SmolVLM2-500M）上的 token 缩减方法**：GazeLLM（注视点固定裁剪）、LLaMA-VID（每帧 2 token，文本条件注意力，无注视先验）、Voila-A（注视热图 + Perceiver 重采样）。
- 选择这三个基线是因为它们代表三种不同的缩减机制，便于控制变量比较。
