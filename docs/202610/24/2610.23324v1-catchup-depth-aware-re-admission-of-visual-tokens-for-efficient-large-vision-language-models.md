## 摘要
大型视觉语言模型（LVLM）在解码器各层中反复处理数百个视觉词元，带来显著的计算和内存开销。现有的推理时视觉词元剪枝方法通常会不可逆地移除低排名词元，尽管获得高查询条件注意力的视觉词元集合会随解码器深度而变化。可恢复路由会保留被跳过的词元以便后续重新考虑，但在绕过中间变换后，会以过时表示重新接纳它们。我们进一步发现，用全词元参考轨迹中当前深度的 oracle 状态替换过时的重新接纳状态，可显著提升定位性能。因此，我们提出 CatchUp，一个无需训练的深度感知视觉词元重新接纳框架。CatchUp 反复重新评估查询条件视觉相关性，在每个解码器区间仅处理选中的视觉词元，并保留延迟词元以供后续重新接纳。在重新接纳时，CatchUp 利用来自语义和空间相关视觉词元的参考到当前转移信号，近似缺失的表示演化。在三个指代表达定位数据集和六个多模态基准上，CatchUp 在 64、128 和 192 词元预算下于两组基准中均取得最高的平均相对保留率。在 64 词元预算且活跃视觉词元减少 88.9% 的情况下，CatchUp 在六个多模态基准上平均保留完整模型 92.17% 的性能，同时将端到端延迟降低 8.0%。代码见 https://github.com/pej0918/CatchUp

## Abstract
Large Vision-Language Models (LVLMs) repeatedly process hundreds of visual tokens across decoder layers, incurring substantial computation and memory costs. Existing inference-time visual token pruning methods often irreversibly remove low-ranked tokens, although the set of visual tokens receiving high query-conditioned attention can change across decoder depth. Recoverable routing preserves skipped tokens for later reconsideration, but re-admits them with stale representations after bypassing intermediate transformations. We further find that replacing stale re-admitted states with their current-depth oracle states from a full-token reference trajectory substantially improves grounding performance. We therefore propose CatchUp, a training-free framework for depth-aware visual-token re-admission. CatchUp repeatedly re-evaluates query-conditioned visual relevance, processes only selected visual tokens through each decoder interval, and preserves deferred tokens for later re-admission. Upon re-admission, CatchUp approximates missed representation evolution using reference-to-current transition signals from semantically and spatially related visual tokens. Across three referring-expression grounding datasets and six multimodal benchmarks, CatchUp achieves the highest average relative retention in both benchmark groups at 64-, 128-, and 192-token budgets. At a 64-token budget with 88.9% fewer active visual tokens, CatchUp retains 92.17% of the full model's performance on average across six multimodal benchmarks while reducing end-to-end latency by 8.0%.
