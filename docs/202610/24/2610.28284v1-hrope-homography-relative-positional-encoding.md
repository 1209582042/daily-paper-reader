## 摘要
几何相对位置编码已成为向多视图Transformer注入空间归纳偏置的主要机制。现有设计将注意力条件化于相机级视锥或光线步进深度，通过传感器几何关联跨视图token。然而，这种以传感器为中心的表述仅描述token从何处被观测到，而忽略了该token所描绘场景区域丰富的表面几何。本文倡导转向表面感知的位置编码，显式地将patch token锚定到物理表面的几何上。我们提出HRoPE，遵循经典多视图立体的倾斜支撑窗假设，将每个patch的局部几何表示为倾斜的3D平面。我们将token级、由平面诱导的单应性作为相对变换注入注意力。这为Transformer提供了几何先验，用于校正透视畸变并在不同视角间对齐patch特征。我们的编码无需真值几何：平面参数可仅在视图合成目标下端到端预测，或从基础模型导出。在RealEstate10K、CO3Dv2和DL3DV上的大量实验表明，我们最佳的HRoPE变体在新视图合成中始终优于所评估的几何位置编码。大量消融和分析证明了所提编码的有效性。请访问我们的项目页面：https://gaohchen.github.io/HRoPE

## Abstract
Geometric Relative Positional Encoding has become the primary mechanism for injecting spatial inductive biases into multi-view transformers. Existing designs condition attention on camera-level frustums or ray-marched depth, associating cross-view tokens through the sensor geometry. Such sensor-centric formulations, however, describe only where a token is observed from, leaving the rich surface geometry of the scene region depicted by the token. In this paper, we advocate a shift toward surface-aware positional encoding that explicitly grounds patch tokens in the geometry of physical surfaces. We introduce HRoPE, which represents the local geometry of each patch as a slanted 3D plane, following the slanted support-window assumption of classical multi-view stereo. We inject token-level, plane-induced homographies into attention as relative transformations. This equips the transformer with a geometric prior for rectifying perspective distortions and aligning patch features across viewpoints. Our encoding requires no ground-truth geometry: the plane parameters can be predicted end-to-end under a view-synthesis objective alone, or derived from foundation models. Extensive experiments on RealEstate10K, CO3Dv2, and DL3DV show that our best variant of HRoPE consistently outperforms the evaluated geometric positional encodings for novel view synthesis. Extensive ablations and analysis show the effectiveness of the proposed encoding. Please refer to our project page at: https://gaohchen.github.io/HRoPE

# HRoPE: Homography Relative Positional Encoding 论文总结

## 1. 核心问题与研究动机

- **背景**：多视图 Transformer 已成为前馈式 3D 视觉（如新视角合成）的主流架构，但注意力机制本身对相机位姿、极线约束等几何信息是“置换等变”且无感知的，必须显式注入几何先验。
- **现有方案的共同缺陷**：从 2D RoPE → GTA/CaPE（相对外参）→ PRoPE（完整投影矩阵）→ RayRoPE/URoPE（逐 token 深度），几何位置编码的精度在提升，但**始终以传感器为中心**——只描述“token 从何处被观测到”，不描述 token 所描绘的**物理表面本身**。
- **根本矛盾**：多视图匹配本质上是比较**局部邻域**，其外观跨视图形变由表面几何决定。现有 PE 只给出 patch 的零阶位置（深度），却缺少一阶局部朝向（法向），隐含强加了“正面平行（fronto-parallel）”假设，迫使大模型用数据与容量去补偿这一偏差，牺牲效率与泛化性。
- **核心主张**：表面朝向是“缺失的自由度”。作者提出**表面感知位置编码（surface-aware positional encoding）**，将 patch 锚定到物理表面几何上。

## 2. 方法论

### 2.1 核心思想
- 受经典多视图立体中 **PatchMatch Stereo 的倾斜支撑窗（slanted support window）** 启发，将每个 patch 的局部表面近似为一个**倾斜的 3D 平面**（单位法向 n、有符号距离 d）。
- 平面诱导的单应变换天然描述了局部邻域在跨视图间的透视形变，将其作为**相对变换**注入注意力，相当于“先把两个邻域矫正到同一共享切平面再比较”。

### 2.2 关键公式与流程
- **平面诱导单应**：设平面 n^⊤X = d，则投影为
  - H_i = K_i (R_i + t_i n^⊤ / d)
  - 两视图间：x̃_i ∼ H_i H_j^{-1} x̃_j（严格对应同一物理平面上的点）
- **逐 patch 变换**：为每个 patch (i,u) 赋予独立变换
  - H_{i,u} = K_i (R_{i,u} + κ_{i,u} t_{i,u} n_{i,u}^⊤)，其中 κ = 1/d
  - 每 patch 预测 **13 个标量**：t∈R³、由 6D 连续表示经 Gram–Schmidt 得到的 R∈SO(3)、归一化法向 n、逆平面距离 κ。
- **注意力调制**：对 query 乘 H_{i,u}^⊤，对 key 乘 H_{j,v}^{-1}，则 logit 为
  - (H_{i,u}^⊤ q)^⊤ (H_{j,v}^{-1} k) = q^⊤ (H_{i,u} H_{j,v}^{-1}) k
  - 即注意力只依赖 token 对之间的**相对单应**；与 PRoPE 不同，该相对因子逐 token 对变化。
- **块对角结构**：每头特征维度 D 被划分为 D/2（几何块，含 D/6 份 3×3 的 H 复制）、D/4（x 方向 2D RoPE）、D/4（y 方向 2D RoPE）。目标视图 token 无预测平面，退化为 H = K_i（A = I）。
- **闭式求逆（Sherman–Morrison）**：
  - A = R + κ t n^⊤，A^{-1} = R^⊤ − κ(R^⊤t)(n^⊤R^⊤)/(1 + κ n^⊤R^⊤t)
  - 避免显式矩阵求逆；分母即 det A，相机中心落在预测平面上时为零，故对 t、κ、分母做 clamp（[−0.5,0.5] 与 0.1），并保证 det A ≥ 0.57。
- **两种实例化**：
  - **Predicted**：轻量回归头从 patch 特征（可学习、DINOv2、VGGT 等）端到端预测参数，仅用视图合成目标训练。
  - **Calibrated**：已知相机标定时，保留 PRoPE 的投影 P_i，仅预测逐 patch 局部坐标系 F_{i,u}，H^cal = P_i F_{i,u}；当所有 patch 共享同一坐标系时退化为 PRoPE。
- **理论性质**：当预测法向与视线方向一致时，诱导变换退化为 fronto-parallel 情形，因此 HRoPE **严格推广**了基于点和射线的 PE。

## 3. 实验设计

- **任务与指标**：前馈式新视角合成（NVS），指标为 PSNR↑、SSIM↑、LPIPS↓。
- **数据集**：

  - **DL3DV**（场景）——按 RayZer 协议测试 2/4/8 视图的扩展性。
  - **Aria Synthetic Environments (ASE)**——提供 GT 深度/法向/相机，用于 oracle 几何实验。
  - **ScanNet / VSI-Bench**——用于 MLLM 空间推理迁移实验。
- **Benchmark 与骨干**：在 **LVSM**（decoder-only，约 25M 参数；DL3DV 上用约 53M）框架内替换位置编码，其余结构不变。
- **对比方法**：LVSM（无几何 PE）、GTA、PRoPE、RayRoPE、URoPE（部分数据集），以及多种消融变体。
- **消融与迁移**：
  - 变换参数化：Depth、SO(3)、P·F、SE(3)、HRoPE、无约束 4×4（Full），并对比对应的 768 维**加性**位置编码（APE）。
  - 参数来源：从零学习、DINOv2、DINOv2†、DA3、VGGT、VGGT-Ω。
  - 分布外泛化：目标焦距缩放 1×–5×、目标视图外推 +50%、输入视图间距从 [25,100] 变为 [75,150]。
  - 跨架构迁移：**EscherNet**（约 800M 参数的多视图扩散模型，替换其原生 CaPE）与 **LLaVA-Video-7B**（VSI-Bench 空间推理，作用于视觉 token 的 L−10 至 L−2 层）。

## 6. 主要结论与发现

- VGGT 版 HRoPE 在 CO3Dv2 / RealEstate10K / Objaverse 上全面领先，相对 PRoPE 分别提升 **0.53 / 1.27 / 1.03 dB** PSNR，SSIM 更高、LPIPS 更低。
- 在 DL3DV 的 2/4/8 视图设置下均优于 PRoPE，且**两视图（稀疏）时增益最大**，说明表面先验在稀疏观测下价值更高。
- 在 RealEstate10K 上**无需 GT 相机位姿**即超过 PRoPE，说明逐 patch 单应比视图级投影是

……更有效的几何表示（PRoPE 需要显式相机位姿，而 HRoPE 可从 patch 特征端到端推断局部几何）。

- **参数化消融**：在同等条件下，HRoPE（法向 + 逆深度 + 相对旋转/平移）优于 Depth、SO(3)、SE(3)、P·F 以及无约束 4×4（Full）等变体；无约束 Full 版本并未因自由度更高而更好，说明**几何结构化的归纳偏置**（平面诱导单应、可逆闭式形式）比单纯增加参数量更重要。对应的 768 维加性 APE 版本普遍劣于乘性（注意力调制）版本，排除了“仅靠更多参数或更强特征”的解释。
- **参数来源消融**：性能排序大致为 VGGT > DA3 > DINOv2†/DINOv2 > 从零学习，即更强的特征能带来更准的局部平面估计；但即使**从零学习**的 HRoPE 也已超过 PRoPE，说明增益主要来自编码结构而非外部特征。DINOv2†（带额外适配）与 DINOv2 的差异较小，表明特征质量的影响是渐进的而非决定性的。
- **校准变体（P·F）**：在已知相机位姿时，仅预测逐 patch 局部坐标系即可超过 PRoPE，且当所有 patch 共享同一坐标系时严格退化为 PRoPE，构成一个干净的“局部几何贡献”隔离实验；这也验证了 HRoPE 是 PRoPE 的严格推广。
- **Oracle 几何实验（ASE）**：用 GT 深度/法向/相机替换预测参数后性能进一步提升，形成“几何越准 → 渲染越好”的闭环证据，说明预测头确实是当前性能的一个瓶颈，而非几何先验本身无效。
- **分布外泛化**：在目标焦距缩放（1×–5×）、目标视图外推（+50%）、输入视图间距改变（[25,100] → [75,150]）三类设定下，HRoPE 的性能下降幅度小于 PRoPE 等基线，说明表面感知编码带来的增益不是对训练分布的过拟合，而是更接近真实的几何不变性。
- **跨架构迁移**：在 EscherNet（约 800M 参数的多视图扩散模型）中以 HRoPE 替换原生 CaPE 后生成质量提升；在 LLaVA-Video-7B 上对视觉 token 的 L−10 至 L−2 层注入 HRoPE 后，VSI-Bench 空间推理得分提升。这两项结果表明该编码并非只适配 LVSM 这类 decoder-only 前馈 NVS 架构，而具有一定的**架构无关性**，并可迁移到需要空间推理的多模态大模型。
- **稀疏视图优势**：DL3DV 上 2 视图增益最大、随视图数增加增益收窄，与“表面先验在观测稀疏时最能补偿信息缺失”的直觉一致。

## 7. 局限与讨论

- **平面假设的适用范围**：将 patch 局部表面近似为单个 3D 平面，对薄结构（树叶、栏杆）、高曲率或强纹理混叠区域会失效；patch 越大，平面近似误差越明显，论文未系统分析 patch 尺寸与平面误差的关系。
- **训练成本上升**：逐 patch 参数预测显著增加训练开销（VGGT 版约 76 GPU-hours，对比原始 LVSM 约 33 GPU-hours），推理时也需为每个 patch 计算 H 及其逆；虽然用 Sherman–Morrison 闭式求逆避免了显式矩阵求逆，但逐 token 对的相对单应仍比 PRoPE 的视图级变换更昂贵，论文对推理时延/显存的量化对比不够充分。
- **数值稳定性依赖人工约束**：需要对 t、κ 及 det A 分母做 clamp 才能避免相机中心落在预测平面上导致的奇异，这些超参数（[−0.5,0.5]、0.1、det A ≥ 0.57）的敏感性未做消融。
- **监督信号单一**：Predicted 变体仅用视图合成目标端到端训练，没有显式的深度/法向监督，学到的平面未必具有物理意义（可能只是对渲染有利的“有效几何”），论文虽用 ASE oracle 实验间接佐证，但缺少对预测法向/深度与 GT 的直接误差评估。
- **实验覆盖的边界**：主实验以 2 参考视图为主，DL3DV 最多到 8 视图；未涉及视频级长序列、动态场景、大分辨率（>336×336）或极端宽基线情形。部分基线（如 URoPE 在 CO3Dv2）结果缺失，跨方法比较并非完全对齐；各方法所用特征来源不完全一致，需要结合消融表谨慎解读。
- **资源描述的小瑕疵**：文中将 RTX 4090 标为 48 GB（常见为 24 GB），且扩散模型与 MLLM 迁移实验的算力未单独列出，复现细节略有欠缺。

## 8. 总结与启示

- **一句话概括**：HRoPE 指出多视图位置编码长期缺失的“表面朝向”自由度，用 patch 级倾斜平面诱导的单应变换作为相对位置编码注入注意力，把“传感器中心的观测描述”升级为“表面中心的几何描述”，在 NVS、分布外泛化与跨架构迁移上均取得一致增益。
- **方法论启示**：把经典多视图立体（PatchMatch 倾斜支撑窗）的几何直觉翻译成 Transformer 注意力的乘性调制，是一条低成本、可解释、可退化为已有方法的先验注入路径；“相对单应逐 token 对变化”是它与 PRoPE 的本质区别。
- **实践价值**：对稀疏视图、位姿不精确或缺失位姿的场景尤其有吸引力（RealEstate10K 上无需 GT 位姿即超过 PRoPE）；对多模态大模型的空间推理也有正向迁移。
- **未来方向**：更一般的局部表面表示（二次曲面、多平面/分层平面）、显式几何监督、自适应 patch 尺寸、以及在大规模视频与动态场景上的扩展，都是自然的后续工作。
