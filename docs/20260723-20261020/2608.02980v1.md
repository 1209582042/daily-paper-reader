## 摘要
大型多模态模型（LMM）在图像和短视频上已取得显著成功，但将其扩展到长视频仍面临挑战，原因在于以帧为中心的标记化方式和有限的上下文窗口。3D几何为视觉流提供了一种自然的压缩机制：深度和相机位姿使来自多个视角和时间步的观测能够融合为一种持久的、与世界对齐的表示。尽管近期的3D LMM利用几何感知表示来提升空间推理能力，但它们在定位和分割任务上仍落后于专用的3D感知系统。我们认为一个关键局限在于几何感知解码：现有方法通过语言标记、候选框选择或轻量级定位查询来传递3D预测，从而在语言推理与稠密几何预测之间形成了瓶颈。基于这些认识，我们提出Qwen-3D，一种几何感知的LMM，它在Qwen主干网络内利用多视角几何线索压缩视觉信息，从而实现对静态场景的高效长时程视觉推理。Qwen-3D为视觉标记引入了3D旋转位置嵌入，使注意力能够直接在3D场景空间中运作，而非跨越独立的图像帧，从而促进可扩展的跨视角与时间推理。为连接语言与几何，Qwen-3D引入了一个基于查询的分割解码器，将语言直接定位到底层3D场景表示中，统一了图像和视频上的指代定位、实例分割与视觉问答。在多种基准测试上，Qwen-3D超越了现有的3D LMM，并优于若干大型专有2D模型。值得注意的是，Qwen-3D通过在2D和3D数据上联合训练，在实现这些改进的同时，仍在标准2D视觉语言基准上保持了强劲性能。

## Abstract
Large Multimodal Models (LMMs) have achieved remarkable success on images and short videos, yet scaling them to long videos remains challenging due to frame-centric tokenization and limited context windows. 3D geometry provides a natural compression mechanism for visual streams: depth and camera pose enable observations from multiple views and time steps to be fused into a persistent, world-aligned representation. While recent 3D LMMs leverage geometry-aware representations to improve spatial reasoning, they continue to lag behind specialist 3D perception systems on grounding and segmentation tasks. We argue that a key limitation is geometry-aware decoding: existing methods communicate 3D predictions through language tokens, proposal selection, or lightweight grounding queries, creating a bottleneck between language reasoning and dense geometric prediction. Building on these insights, we introduce Qwen-3D, a geometry-aware LMM that compresses visual information within the Qwen backbone using multi-view geometric cues, enabling efficient long-horizon visual reasoning over static scenes. Qwen-3D augments visual tokens with 3D Rotary Positional Embeddings, allowing attention to operate directly in 3D scene space rather than across independent image frames and thereby facilitating scalable cross-view and temporal reasoning. To bridge language and geometry, Qwen-3D incorporates a query-based segmentation decoder that grounds language directly in the underlying 3D scene representation, unifying referential grounding, instance segmentation, and visual question answering across both images and videos. Across a diverse set of benchmarks, Qwen-3D surpasses existing 3D LMMs and outperforms several large proprietary 2D models. Notably, Qwen-3D achieves these improvements while maintaining strong performance on standard 2D vision-language benchmarks by jointly training on 2D and 3D data.

# Qwen-3D 论文结构化总结

## 1. 核心问题与整体含义

- **背景**：大型多模态模型（LMM）在图像与短视频上表现优异，但扩展到长视频时受制于两个瓶颈：以帧为中心的 tokenization 导致 token 数量爆炸，以及有限上下文窗口难以支撑跨帧长程时空推理。
- **3D 几何作为压缩机制**：深度图与相机位姿可将多视角、多时刻的观测融合进一个持久的、世界对齐的 3D 表示，从而把长多视角视频流压缩为紧凑的场景表示——时间上相距很远的帧若对应相近的 3D 位置即可被合并。
- **核心痛点（论文的核心论点）**：现有 3D LMM 在定位（grounding）与分割任务上明显落后于专用 3D 感知系统，甚至多数 3D LMM 根本不尝试 ScanNet 上的目标检测。作者认为关键瓶颈不在"几何感知表示"，而在**几何感知解码**：现有方法通过语言 token（如 3D-LLM）、候选框选择（如 Video-3D-LLM、LEO、ChatScene）或单个特殊 `<REF>` token（如 LLaVA-3D、Grounded-3D-LLM）来传递 3D 预测，在语言推理与稠密几何预测之间形成了严重的信息瓶颈。
- **根本矛盾**：LLM 擅长离散 token 推理，而稠密 3D 定位需要在连续世界坐标系中输出空间精确结果；且 3D 场景没有像图像像素那样的规范参考系，自回归解码 3D 框/坐标/掩码是"不自然的接口"。
- **整体含义**：论文提出 Qwen-3D，试图回答"大型多模态模型应如何与 3D 定位系统对接"这一开放问题，主张**几何感知表示 + 几何感知解码**二者缺一不可。

## 2. 方法论

### 2.1 核心思想
在 Qwen2.5-VL 主干上做三件事：(a) 用 3D 几何压缩多视角视觉 token；(b) 用 3D 旋转位置编码让注意力直接在 world space 运作；(c) 用查询式掩码解码器直接消费主干的全量上下文视觉-语言特征，实现稠密 2D/3D 定位。

### 2.2 几何感知场景表示
- 用 Qwen2.5-VL 视觉编码器提取多视角图像特征，结合深度、相机内参与位姿反投影到世界坐标，得到特征-坐标对集合 `FC = {(f_i, p_i)}`。
- **体素化 token 合并**（voxel size = 5cm）：对落在同一体素内的特征与坐标做均值池化，得到紧凑、无序的几何对齐 token 集合 `FC'`（M' ≤ M）。该步骤是参数无关的，直接由 3D 空间布局引导。
- 该压缩是长序列可扩展性的关键：不做体素池化时，即使大幅减少输入帧也会 OOM。

### 2.3 几何感知视觉-语言注意力
- 将 Qwen 的 Multimodal RoPE 从 1D/2D 网格扩展为 3D 世界坐标编码，位置编码分解为四个分量：`PE3D(p) = [PE(t); PE(x); PE(y); PE(z)]`。
- 文本 token 的时间 ID 顺序递增（退化为标准 1D RoPE）；点云 token 共享常数时间 ID，空间 ID 用其世界坐标。
- 注意力前对 query/key 施加旋转：`q̃ = R(p_q)q`，`k̃ = R(p_k)k`。
- **注意力掩码改造**：由于点云具有置换不变性，将 Qwen2.5-VL 的因果掩码替换为视觉 token 上的全注意力（仅在答案 token 上保留因果掩码），提升 3D 性能且不损害主干原有能力。
- 频率分配细节：作者为每个维度初始化相同范围的频率，使高低频通道在四个分量上均匀分布；而"朴素 3D MRoPE"沿用 Qwen 原有的通道划分，导致高频集中在时间轴、低频集中在 z 轴，反而损害 3D 定位。

### 2.4 几何感知解码
- 取主干输出的上下文视觉 token `V` 与语言 token `T`，实例化 N 个可学习 object query `Q`，送入 Mask2Former 风格解码器；每层在"对视觉与语言 token 的交叉注意力"和"query 间自注意力"之间交替。
- 最后一层后，每个 query 通过**与视觉 token 的点积**预测分割掩码，通过与**语言 token 的点积**预测语言定位分数。
- 与 `<REF>` token 方案的本质区别：语言推理与几何预测共享稠密视觉表示，而非仅通过单个 token 通信；这与现代多目标检测/分割架构更自然地对齐。
- 问答与描述仍由原始 Qwen2.5-VL 语言头做 next-token prediction。

### 2.5 训练目标
总损失为三项加权和：`L = α_mask·L_mask + α_textground·L_textground + α_gen·L_gen`
- **掩码损失**：匈牙利匹配后对匹配掩码用 BCE + Dice（遵循 Mask2Former）。
- **文本片段定位损失**：对匹配的文本片段用 BCE，未匹配 query 被监督为对所有文本 token 输出低概率。
- **文本生成损失**：问答/描述任务上的 token 级交叉熵。

### 2.6 2D-3D 联合训练
- 2D 与 3D 共享全部参数；2D token 用规则网格 + 2D 位置编码，3D 输入为无序点 token + 3D 编码。
- 训练时以概率 p 用 MoGE 等重建模型把 2D 数据"提升"为 3D，以改善 2D/3D 表示对齐。
- 检测任务通过拼接类别名构造 prompt（如 "find chair. table. sofa."）。

## 6. 主要结论与发现

- **3D LMM 新 SOTA**：ScanRefer 上 7B 版达 62.8 Acc@25 / 54.7 Acc@50，较 LLaVA-3D 提升约 12% Acc@25，较两阶段 Video-3D-LLM 提升约 4%，较 3D-LLM 提升 30%+。
- **逼近专家模型**：ScanRefer 上接近 UniVLG（62.8 vs 63.5），显著优于 ODIN、3D-VisTA、PQ3D 等。
- **域外泛化突出**：Locate-3D/ScanNet++ 上 3B 版 55.7/43.4，远超 UniVLG（32.3/24.6）与 Video-3D-LLM（33.2/27.6）；3EED 户外在 Drone/Quad 划分上超过 UniVLG。作者归因于直接由 VLM 特征解码、不依赖现成检测器。
- **分割**：ScanNet200 上 25.3 mAP / 41.5 mAP25，超 Grounded-3D-LLM 13% mAP / 25% mAP25，接近语言提示式专家模型。
- **VQA**：7B 版在 ScanQA 与 SQA3D 上全面超过所有基线（ScanQA EM@1 31.5、CIDEr 99.0；SQA3D EM@1 59.6）。
- **2D 能力基本保持**：RefCOCO 88.1 vs 基座 89.1，RealWorldQA 60.4 vs 62.6，有小幅下降但未灾难性遗忘。
- **消融结论**：全 token 接口（53.5）远胜 `<REF>`（39.7）；对齐 3D RoPE（53.5）> 2D（53.2）> 朴素 3D（49.9）；全注意力（53.5）远胜因果掩码（36.4）；微调主干（53.5）远胜冻结（37.0）。
- **鲁棒性**：对深度噪声几乎不敏感，对位姿噪声优雅退化，极端错位下仍优于 UniVLG；输入帧从 400 降到 15 仍保持约 56% 定位性能。
- **总体论断**：仅靠几何感知表示不足以实现高质量 3D 感知，必须配套几何感知解码。

## 7. 优点

- **问题诊断精准且有实验支撑**：把"3D LMM 落后于专家系统"归因于解码接口而非表示，并用 `<REF>` token 对照消融直接验证，论证链条清晰。
- **架构简洁高效**：仅约 50M 可训练参数、冻结 ViT + LoRA，3 天 8 卡即可训练，工程可复现性强（代码与 checkpoint 公开）。
- **体素池化是真正的可扩展性关键**：参数无关、3D 感知的压缩，避免 token merging 必须先处理全分辨率点云（约 33K 点）导致 OOM 的问题，将点数降至约 14K。
- **统一架构覆盖多任务**：同一套参数同时支持 2D/3D 指代定位、实例分割、VQA，且 2D 与 3D 共享解码器，避免多模块拼接。
- **评测维度丰富且诚实**：域内 + 域外 + 户外零样本 + 噪声压力测试 + 帧数消融 + 时延分析 + 失败案例可视化；主动报告 2D 性能的小幅下降。
- **工程细节有价值**：将视觉编码器的 O(N²) 跨图注意力改为逐图批处理降至 O(N)，对长多视角输入的内存可行性至关重要。

## 8. 不足与局限

**作者自述的局限**：
- **静态场景假设**：共享 3D 坐标系假定场景基本静止，无法处理非刚性运动、物体交互与拓扑变化；扩展到动态 4D 表示是未来工作。
- **单步定位**：多数任务只涉及一次定位，缺乏对多实体组合推理（空间比较、关系推理、长程指令跟随）的支持。
- **依赖外部几何**：深度与位姿来自外部估计，重建误差最终限制定位上限；端到端联合优化几何与语言理解尚未实现。

**额外的观察与风险**：
- **评测协议不统一**：大量基线数字引自原文，检测框/GT 设置混杂；消融样本量小（50 场景）、单一数据集、单一模型规模，未报告方差或显著性。
- **3B/7B 反常**：SR3D 上 3B 优于 7B，缺乏解释，可能暗示训练不稳定或过拟合。
- **"通用"声称的边界**：所谓 generalist 主要覆盖静态室内 ScanNet 系场景；户外仅 3EED 零样本小规模验证，且 Vehicle 划分上反而低于 UniVLG（22.9 vs 28.6），说明跨域优势并非普遍成立。
- **对比基线选择**：与 GPT-4o、Qwen2-VL-72B 等 2D 模型的比较存在"降维打击"意味；与 LLaVA-3D 的比较受其未开源权重限制，只能引用其报告数字。
- **数据泄漏风险未讨论**：2D 共训数据（RefCOCO、COCO、LLaVA-Instruct）均在 Qwen2.5-VL 预训练分布内，2D 指标"保持"可能部分源于记忆而非真正的能力保留；3D 训练集与评测集同源（ScanNet 系），域内成绩的泛化含义有限。
- **应用限制**：需要 posed RGB-D 输入与 SLAM 重建，部署门槛高于纯 RGB 的 2D VLM；2 秒/场景的推理在实时机器人场景中仍偏慢；体素尺寸 5cm 为固定超参，对尺度差异大的场景（户外、大空间）可能不适配。
- **缺失的分析**：未

- **缺失的分析**：未报告多次运行的方差或置信区间；未分析体素尺寸、query 数量 N、LoRA rank 等关键超参的敏感性；未给出失败案例的定量分类统计（仅定性可视化）；未讨论训练数据中 2D/3D 混合比例、3D 提升概率 p 的取值依据与影响；未评估模型在未见过的传感器类型（如 LiDAR 与 RGB-D 混合）或极端光照/低纹理条件下的表现。
- **方法层面的潜在问题**：体素均值池化在物体边界处会混合不同实例的特征，可能损害小物体与薄结构（如椅子腿、显示器边缘）的分割精度，论文未针对此做边界感知的改进或分析；全注意力掩码虽提升 3D 性能，但随视觉 token 数增长呈 O(N²) 复杂度，长序列下的内存与延迟上界未充分讨论；3D RoPE 依赖位姿精度，位姿噪声消融虽显示"优雅退化"，但退化曲线在何种噪声水平下崩溃未给出阈值。
- **与相关工作的定位**：论文将自身与"两阶段 LMM"（先用检测器再交给 LLM）和"单阶段 `<REF>` token LMM"区分，但对近期同样采用查询式解码或 3D 位置编码的并行工作（如 Chat-Scene 的后续版本、SpatialLM 类方法）缺少直接实验对比，新颖性边界需读者自行判断。
- **可复现性细节**：虽公开代码与 checkpoint，但训练数据的精确采样配比、2D 提升所用 MoGE 的具体版本与参数、匈牙利匹配的成本矩阵设计、文本片段定位中"文本片段"的切分规则等关键实现细节在正文中描述较简，复现者可能需依赖代码阅读。

## 9. 启发与展望

- **"表示 vs 解码"的二分是有价值的分析框架**：论文把 3D LMM 的瓶颈从"如何压缩场景"转向"如何输出几何"，这一视角可迁移到其他连续输出任务（如轨迹预测、可操作区域预测、物理参数估计），提示未来 LMM 设计应把"输出接口"作为一等公民。
- **查询式解码 + 稠密特征共享**可能成为 LMM 与专用感知系统对接的通用范式：语言头负责语义推理，查询解码器负责几何输出，二者共享同一视觉上下文，避免信息瓶颈。
- **体素化作为参数无关压缩**的思路简单有效，但其固定分辨率假设与动态场景、大尺度户外场景存在张力；未来可探索自适应体素、层次化 3D token 或与 4D 动态表示结合。
- **动态场景与多步组合推理**是明确的下一步：作者自述的静态假设与单步定位局限，指向时序 4D 表示、关系推理与长程指令跟随等开放问题。
- **端到端几何-语言联合优化**：当前依赖外部深度/位姿估计，若能将几何估计纳入训练回路（如可微 SLAM 或自监督深度），有望突破重建误差设定的性能上限。

## 10. 一句话总结

Qwen-3D 通过"3D 体素化 token 压缩 + 3D 旋转位置编码 + 查询式掩码解码器"三件套，论证了 3D 大型多模态模型的瓶颈在于几何感知解码而非几何感知表示，以仅约 50M 可训练参数在多项 3D 定位/分割/VQA 基准上刷新 LMM 纪录并逼近专家系统，但其静态场景假设、评测协议统一性与跨域普适性仍留有讨论空间。
