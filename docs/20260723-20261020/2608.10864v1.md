## 摘要
视觉语言模型（VLM）已在图像和视频理解方面取得强大性能，但其视觉-空间表征在几何上仍然脆弱，导致在具身智能、机器人和自动驾驶所需的空间推理中出现失败。以往的几何基础方法要么在空间问答上微调 VLM，这可能固化虚假的视觉表征；要么融合来自大型几何基础视觉模型的特征，这在推理时大幅增加模型规模。来自几何基础视觉模型的知识蒸馏提供了另一种选择，但直接匹配多视图教师特征可能破坏视觉与文本表征之间预训练的对齐，降低物体和语言语义能力。我们提出多视图关系蒸馏（MVRD），它蒸馏跨视图的逐块余弦相似度，而非教师特征本身。这些关系编码了足以支持空间理解的几何对应关系，同时使学生表征保持欠定，从而使其接近预训练的视觉-语言空间。在代表性 VLM 上，MVRD 提升了视觉-空间推理，优于监督微调和特征蒸馏，并以显著更少的附加参数和更低延迟接近特征融合方法。我们表明，MVRD 使视觉表征更具几何性，同时保留语言对齐，并可泛化到 3D 场景理解任务，如物体定位、密集描述和问答。

## Abstract
Vision-language models (VLMs) have achieved strong image and video understanding, yet their visual-spatial representations remain geometrically fragile, leading to failures in spatial reasoning needed for embodied AI, robotics, and autonomous driving. Prior approaches to geometry grounding either fine-tune VLMs on spatial question answering, which can perpetuate spurious visual representations, or fuse features from large geometry-grounded vision models, which substantially increases model size at inference. Knowledge distillation from geometry-grounded vision models offers an alternative, but directly matching multi-view teacher features can disrupt the pretrained alignment between visual and textual representations, degrading object- and language-semantic capabilities. We propose multi-view relational distillation (MVRD), which distills patch-wise cosine similarities across views instead of the teacher features themselves. These relations encode geometric correspondences adequate for spatial understanding, while leaving the student representation underdetermined, allowing it to remain close to its pretrained vision- language space. Across representative VLMs, MVRD improves visual-spatial reasoning, outperforming supervised fine-tuning and feature distillation while approaching feature fusion methods with considerably fewer added parameters and lower latency. We show that MVRD makes visual representations more geometric while retaining language alignment, and generalizes to 3D scene understanding tasks such as object grounding, dense captioning, and question answering.

## 1. 核心问题与整体含义

- **背景**：视觉语言模型（VLM）在图像/视频理解上表现强劲，但其视觉-空间表征在几何上"脆弱"（fractured），在相对距离、视角变换等基础空间推理上频繁失败，限制了具身智能、机器人、自动驾驶等应用。
- **现有路线及其缺陷**：
  - **监督微调（SFT）**：用空间问答数据微调，但不直接修正虚假视觉表征，增益有限。
  - **特征融合**：把大型几何基础模型（如 VGGT、CUT3R）的多视图特征注入 VLM 视觉通路，效果好但推理时需额外独立模型，显著增大模型规模与延迟。
  - **特征蒸馏**（如 3DRS）：训练时对齐几何教师特征、推理时丢弃教师，可避免开销；但论文指出其**未被诊断的失败模式**——直接匹配教师特征会把学生视觉表征拉离预训练视觉-语言空间，破坏视觉-文本对齐，导致物体定位、外观顺序追踪等语言语义任务显著退化。
- **核心问题**：如何在不牺牲视觉-语言对齐的前提下，把几何知识蒸馏进 VLM？
- **整体含义**：论文主张"蒸馏关系而非特征"，在几何性与语言对齐之间取得更好平衡，并以极小的推理开销接近特征融合方法的性能。

## 2. 方法论（MVRD）

- **核心思想**：不蒸馏教师的多视图特征本身，而蒸馏**跨视图 patch 间的余弦相似度关系矩阵**。关系编码了几何对应信息（足以支持空间理解），但学生特征本身保持"欠定"（underdetermined）——任何共享旋转与独立缩放变换后的特征都同样最优，因此学生可选取靠近预训练视觉-语言空间的解。
- **关键技术细节**：
  - **关系表示**：对特征序列 $h$ 定义 $R(h)[i,j] = r(h[i], h[j])$，$N = T \times H_p \times W_p$（视图数 × patch 网格）。
  - **蒸馏损失**：$L_{RD} = \ell_{RD}\big(R(f(v^l_{1:T})),\, R(\mathrm{sg}(\bar g_{1:T}))\big)$，其中 $f$ 为逐位置 MLP 投影，$\mathrm{sg}$ 为停止梯度；总损失为 $L_{SFT} + \gamma L_{RD}$。
  - **相似度选择**：采用余弦相似度（对特征幅值与全局朝向不变），优于欧氏距离（后者强制匹配尺度）。
  - **矩阵损失**：采用**逐行 Pearson 相关**（对相似度分数尺度不变、更稳健），优于 MSE；并按 VLM 因果注意力做因果掩码、对角线置零以去除平凡自相似。
  - **Dual Pathway（双通路）**：在若干中间层把 LoRA 适配器拆为"几何适配器"（受复合损失监督）与"语义适配器"（仅受 SFT 监督），输出相加后进入后续层，进一步减少对语言相关子空间的扰动。
  - **其他**：使用 LoRA（rank 128, α 256）降低漂移；训练时采用分层帧采样增强（每段等长区间随机偏移取一帧），避免学生记忆固定帧索引关系。
- **理论直觉**：论文用二维示意说明特征蒸馏把视觉 token 拉向几何 token 而偏离语言 token；关系蒸馏因不唯一确定特征，可保留对齐。

## 3. 实验设计

- **数据集 / 场景**：
  - **空间推理**：训练于 VLM-3R 发布的空间推理数据集（>20 万 QA，源自 ScanNet、ScanNet++、ARKitScenes）；评测于 **VSI-Bench**（约 5000 QA，8 项任务），每场景采样 32 帧。
  - **3D 场景理解**（迁移验证）：ScanRefer、Multi3DRefer、Scan2Cap、ScanQA、SQA3D 五个标准数据集，遵循 3DRS 协议。
- **Benchmark 与指标**：VSI-Bench 平均准确率（分几何中心任务与语言接地任务两组）；3D 任务用 Acc@0.25/0.5、F1@0.25/0.5、CIDEr、BLEU-4、EM。
- **对比方法**：
  - 专有 VLM：GPT-4o、Gemini-2.5-Pro；
  - 开源通用 VLM：Qwen2.5-VL、LLaVA-OneVision、LLaVA-Video、InternVL3（含 72B/78B）；
  - 空间推理 VLM：VG-LLM、VLM-3R、3DRS、SFT 版 LLaVA-Video；
  - 3D 场景理解：Grounded 3D-LLM、PQ3D、Chat-Scene、Inst3D-LMM、3D-LLaVA、LLaVA-3D、Video-3D LLM、Ross3D、3DRS。

## 6. 主要结论与发现

- **特征蒸馏的失败模式**：3DRS 式特征蒸馏虽提升几何任务，但使语言接地任务（尤其 Appearance Order 从 38.5 降至 19.6）大幅退化；表征层面文本-视觉对齐明显受损（检测精度约 0.08 vs SFT）。
- **MVRD 效果**：VSI-Bench 平均 59.9%（超 SFT 57.7、3DRS* 57.0、VG-LLM-8B 58.2）；加 Dual Pathway 达 60.4%，距同数据训练的 SOTA 特征融合 VLM-3R（60.9）仅 0.5 点，且推理时无需几何编码器。
- **语言对齐保持**：MVRD 在全部语言接地任务上优于 3DRS，Dual Pathway 下 Obj. Size、Appr. Order 接近甚至略超 SFT。
- **效率**：Dual Pathway 仅增 0.19B 参数（约为 CUT3R 的 25%、VGGT 的 15%），延迟开销为 CUT3R 的 16%、VGGT 的 5%。
- **设计选择有效**：余弦关系 + 逐行 Pearson 损失为最优组合（59.9），最差组合（欧氏 + MSE，48.6）甚至低于 SFT，说明两项设计均为"承重"。
- **层位置**：中后期层（第 20 层）蒸馏最佳，早期层蒸馏反而低于 SFT。
- **迁移性**：在 3D 场景理解上全面超过 3DRS，物体定位（ScanRefer 63.3/56.4）为同类最佳。

## 7. 优点

- **问题诊断有新意**：首次系统指出几何特征蒸馏会破坏 VLM 预训练视觉-语言对齐，并用玩具示例、定性相似度图与定量探针三重证据支撑。
- **方法简洁且有理论直觉**：关系蒸馏的"欠定性"论证清晰，设计选择（余弦、Pearson、因果掩码）均有动机与消融支撑。
- **效率-性能权衡出色**：以极小参数/延迟代价逼近特征融合，契合具身应用对推理开销的敏感需求。
- **实验设计较严谨**：控制训练数据一致、复现基线、多骨干验证、独立任务族迁移、区分几何中心与语言接地任务分组分析。
- **工程细节周到**：帧采样增强、LoRA、双通路分离等均针对"减少漂移"这一核心目标。

## 8. 不足与局限

- **规模有限**：作者自述训练规模中等，仍存在一定几何-语义权衡（如 Dual Pathway 在部分几何任务上略降）。
- **探针偏差风险**：文本接地检测精度仅覆盖 Object Size 任务、42 个问题，且样本按"SFT 优于蒸馏"筛选，可能放大差异；阈值 0.9·s_max 与 50% 覆盖判定带有经验性。
- **教师依赖**：方法依赖 VGGT 作为冻结教师，教师质量与帧索引对齐假设仍是隐性约束；帧采样增强只是缓解而非消除。
- **评测范围**：主评测集中于室内场景（ScanNet 系）与 VSI-Bench，未覆盖户外/自动驾驶、动态场景或真实机器人闭环；3D 场景理解实验为独立训练协议，非零样本迁移。
- **对比完整性**：未与 3DThinker、VaLR 等近期表征对齐方法直接同条件对比；部分基线（如 VG-LLM）骨干不同，跨方法比较需谨慎。
- **应用限制**：Dual Pathway 增加适配器与层间分离，部署时仍需一定工程改造；对超长视频/多视图的 N×N 关系矩阵计算存在二次复杂度隐忧（文中未讨论）。
