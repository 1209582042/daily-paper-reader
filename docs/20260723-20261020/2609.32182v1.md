## 摘要
视觉语言模型正越来越多地用于理解长视频和连续视频流。然而，密集的视觉 token 会随视频时长不断累积，使长上下文推理的成本高得难以承受。现有的免训练视觉 token 选择方法通过保留信息量大的 token 来降低这一成本，但可能丢失连贯的事件证据，也无法区分近期细节观测与长程历史。我们提出 KeyRec，一个用于构建有界视觉记忆的免训练框架。在与查询无关的写入阶段，KeyRec 将细粒度的近期观测保存在视觉缓存中，并将历史证据组织为结构化事件库。候选事件根据其相对于已存储事件的新颖性被提出，并通过在线“添加—合并—淘汰”更新加以维护。当问题到来时，一个纯文本路由器在近期记忆与事件记忆之间自适应地分配固定的读取预算，而无需重新处理历史帧。KeyRec 作用于面向模型的视觉嵌入，同时支持模块化编码器—投影器 VLM 以及无编码器和投影器的 NEO-ov 架构。在四个流式与长视频基准和三个 VLM 主干上，KeyRec 仅使用 10% 的面向解码器的密集视觉 token 预算，就在 15 个设置中的 13 个取得最佳压缩性能。在实时问题上，它比最强的压缩基线高出 2.21–18.37 分；在六个长视频设置中的五个取得最佳压缩结果；并在所有 NEO-ov 2B 设置中表现最佳。

## Abstract
Vision-language models are increasingly used to understand long videos and continuous streams. However, dense visual tokens accumulate with video duration, making long-context inference prohibitively expensive. Existing training-free visual-token selection methods reduce this cost by retaining informative tokens, but may lose coherent event evidence and fail to distinguish detailed recent observations from long-range history. We propose \textbf{KeyRec}, a training-free framework for constructing bounded visual memory. During query-agnostic writing, KeyRec preserves fine-grained recent observations in a visual cache and organizes historical evidence into a structured event bank. Candidate events are proposed according to their novelty relative to previously stored events and maintained through an online add--merge--evict update. When a question arrives, a text-only router adaptively allocates a fixed readout budget between recent and event memory, without reprocessing historical frames. KeyRec operates on model-facing visual embeddings and supports both modular encoder--projector VLMs and the encoder- and projector-free NEO-ov architecture. Across four streaming and long-video benchmarks and three VLM backbones, KeyRec achieves the best compressed performance in 13 of 15 settings using only 10\% of the dense decoder-facing visual-token budget. It outperforms the strongest compressed baseline by 2.21--18.37 points on real-time questions, achieves the best compressed result in five of six long-video settings, and performs best in every NEO-ov 2B setting.

# KeyRec 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）被越来越多地用于长视频与连续视频流理解。但每帧通常被编码为数十到数百个视觉 token，视觉序列随帧数线性增长，而预填充阶段的自注意力计算随序列长度呈二次增长，长上下文推理成本极高。
- **流式场景更棘手**：视频时长未知、查询可在任意时刻到达；长视频场景下密集视觉上下文可能超出显存或上下文预算，且多轮提问会反复处理同一视频。
- **现有免训练 token 选择方法的三大局限**：
  1. **新颖性度量缺乏事件组织**：新颖性通常只对比最近帧、粗粒度锚点或全局语义表示，未将历史显式组织为时间局部化的事件，导致演化中的事件被更新切碎，视觉相似但时间上不同的事件被混为一谈。
  2. **独立选 token 破坏事件连贯性**：孤立地挑选重要 token 会丢弃连接“主体—动作—物体—场景”的支撑性上下文，损失连贯的事件证据。
  3. **统一保留策略不分层**：近期细节观测与长程历史证据在同一策略下竞争，均匀稀疏的记忆可能保留语义却丢失“此刻正在发生什么”所需的细粒度证据。
- **核心主张**：压缩不应只被视为 token 选择，而应被视为**有界视觉记忆的组织问题**——将查询无关的记忆构建与查询自适应的固定预算读取解耦。

## 2. 方法论

### 2.1 问题形式化

- 视频流 $V=\{x_1,x_2,\dots\}$，视觉嵌入机制 $\Phi$ 将每帧映射为 $n$ 个 token $H_t$。
- 目标形式化为：记忆更新 $M_t=\text{Update}(M_{t-1},H_t)$，满足 $|M_t|\le S$（持久存储预算）；读取 $Z_q=\text{Read}(M_\tau,q)$，满足 $|Z_q|\le B$（每查询读取预算）；答案 $\hat y=\text{VLM}(Z_q,q)$，不重访视频。
- 记忆结构 $M_t=(C_t,E_t)$：$C_t$ 为近期缓存（至多 $N_C$ 个 token），$E_t$ 为有界关键事件库（至多 $K$ 个事件、每事件至多 $m$ 个 token），总存储 $N_C+Km\le S$。

### 2.2 查询无关的记忆写入

- **近期视觉缓存**：按序追加新帧 token，仅保留最新 $N_C$ 个（`Tail` 截断），旧 token 逐渐被挤出。
- **事件表示**：每个事件 $e_k=(r_k,P_k,\tau_k,u_k)$，分别为紧凑路由嵌入、存储的视觉 token、时间戳、事件效用值。
- **候选事件构造**：
  - 新颖性定义为 $\nu_{t,i}=1-\max_{e_k}\cos(h_{t,i},r_k)$，即 token 相对历史事件路由的“未被表示程度”，而非帧内显著性；事件库为空时取 1。
  - 取帧内最新颖的 $m$ 个 token，用归一化新颖性分数加权求和得到候选路由 $r_t$；这些 token 构成候选事件 token $P_t$；候选效用为平均新颖性。
- **有界事件库更新（增—并—汰）**：
  - **合并判定**：先找最相似路由 $k^\star=\arg\max\cos(r_t,r_k)$；再要求时间相邻——时间间隔 $g_{t,k^\star}=\min(\tau_t)-\max(\tau_{k^\star})\ge 0$；仅当相似度 $\ge\gamma$ 且间隔 $\le\delta$ 时允许合并。该双重约束防止时间上遥远的重复观测被错误折叠为同一事件。
  - **插入**：不满足合并条件则作为新事件追加；超出容量 $K$ 时触发淘汰。
  - **合并**：路由用归一化滑动平均更新（权重 $\beta$）；token 与时间戳先按时间排序，再用 `Uniform_m` 均匀下采样至至多 $m$ 个，以保留事件的时间跨度；效用取 $\max(u_k,u_t)$，避免短暂但独特的变化被冗余相邻观测稀释。
  - **容量淘汰**：保留分数 $S_{\text{ret}}(e_k)=u_k+\lambda d^{\text{temp}}_k$，其中 $d^{\text{temp}}_k$ 为到最近事件中心的时间距离；兼顾视觉效用与时间覆盖，淘汰分数最低者。

### 2.3 查询自适应的固定预算读取

- 用**同一个冻结 VLM 的纯文本路由器**，仅看问题和两种记忆的文本描述，输出五种读取状态之一：AllRecent、HeavyRecent、Balanced、HeavyEvent、AllEvent。
- 状态决定事件记忆占比 $\pi_q\in[0,1]$，进而由 $k_q=\min(K,\text{round}(\pi_q B/m))$、$r_q=B-k_q m$ 确定选取事件数与近期 token 数。
- **事件选择策略**：HeavyRecent/Balanced 采用相关性检索（事件路由与问题平均池化嵌入的余弦相似度）；HeavyEvent/AllEvent 采用时间覆盖（按事件中心时间排序后均匀选取）；AllRecent 不取历史事件。
- 近期贡献为 $C_q=\text{Tail}_{r_q}(C_\tau)$，与选中事件 token 组成固定预算读取 $Z_q$，按时间顺序恢复后送入解码。
- **分段式记忆呈现**：以中性编号标签序列化各记忆段，保留边界但不赋予语义事件类型（附录 A.1 显示优于“朴素拼接”和“带语义标签的详细模板”）。

### 2.4 原生单视觉模型适配（NEO-ov）

- KeyRec 直接作用于面向模型的视觉嵌入，因此记忆构建与读取算法不变。
- 唯一适配是**保留位置元数据** $\xi_i=(h_i,\tau_i,p^h_i,p^w_i)$（源帧与原始空间位置），元数据随同一选择/下采样索引同步；读取时按源时间排序并恢复到原生时空位置，插入 `<IMG_CONTEXT>` 位置。无需重建密集视觉网格。

## 6. 主要结论与发现

- **流式理解收益显著**：9 个流式设置中 8 个取得最佳压缩性能；在 OVO-Bench Realtime 与 StreamingBench 上比最强压缩基线高 2.21–18.37 分；9 个设置全部持平或超过 Vanilla（最高 +10.01 分）。作者指出 Vanilla 并非理论上界——冗余的流式前缀会稀释决定性的近期证据。
- **长视频为“强但非无损”的权衡**：6 个长视频设置中 5 个最佳，LongVideoBench 上稳定优于其他压缩方法，但比 Vanilla 低 0.30–3.37 分，说明 10% 固定读取保留了大部分能力但未保留全部细粒度证据。
- **跨架构有效**：NEO-ov 2B 的全部设置均为最佳压缩结果；在 32–512 帧范围内保持稳定（512 帧仍 >44%，两个基线 <25%），表明现有 token 选择策略难以直接迁移到原生单视觉模型，保留模型原生时空结构很重要。
- **预算缩放**：KeyRec 在小预算下快速提升、约 5% 读取时达峰后缓降；峰值配置超过 Vanilla，说明超过足够证据预算后，冗余或弱相关观测会稀释证据。
- **查询自适应分配必要**：最优固定分配随任务剧烈变化（Backward 偏好事件记忆，Realtime 强烈偏好近期细节，LongVideoBench 偏好混合），无单一固定策略全面最优；路由器在 Backward 上匹配事件专用策略，在 Realtime 与长视频上超过所有固定策略。
- **序列化方式影响性能**：保留记忆边界但使用中性标签的默认模板最优；带“key event”等语义标签会引入偏置，扁平拼接则丢失结构。
- **事件粒度**：中等粒度（$m=16$）在证据完整性与时间覆盖之间取得最佳平衡。

## 7. 优点

- **问题重构有洞察力**：把 token 压缩重新表述为“有界视觉记忆的组织与读取”，明确区分查询无关写入与查询自适应读取，切中现有方法丢失事件连贯性与不分层保留的痛点。
- **事件维护机制设计精巧**：新颖性相对“历史事件路由”而非帧内显著性定义；合并同时要求语义相似与时间相邻，避免远距离重复被误并；`Uniform_m` 下采样保留事件时间跨度；淘汰分数兼顾效用与时间覆盖。
- **读取机制轻量且有效**：仅用文本路由器、不重处理历史帧，开销近似与帧数无关，随视频增长被摊薄（相对开销 19%→10%）。
- **架构通用性好**：作用于模型面向的嵌入，仅需位置元数据簿记即可适配无编码器/投影器的 NEO-ov，是较早探索该架构下视觉压缩的工作。
- **实验对照严谨**：预算匹配对照、分配消融、阈值敏感性、序列化消融等设计有效排除了多种替代解释；同时报告延迟与显存，工程可信度较高。
- **诚实的局限性陈述**：明确承认长视频非无损、未降低 ViT 编码延迟、事件表示不含物体身份/轨迹。

## 8. 不足与局限

- **作者自述局限**：
  - 免训练但依赖固定的新颖性、合并、保留规则；从 token 级监督或下游 QA 信号学习这些策略可能进一步提升。
  - Gemma 实现中 KeyRec 在视觉编码器之后运行，降低了视觉记忆与语言模型成本，但**未降低 ViT 编码延迟**；初步的中间层 token 削减因破坏优化后的编码器路径而未改善实际耗时，编码器侧剪枝与编码后记忆的高效集成仍是开放的系统问题。
  - 事件记忆只存选中的视觉 patch，**不显式建模物体身份、轨迹或状态转移**，限制了对时长、顺序、跨帧演化的精确推理。
- **实验覆盖与偏差风险**：
  - 主实验流式前缀截断 32 帧，可能低估 KeyRec 在长流上的优势；全前缀 1-FPS 实验仅对比单一基线。
  - 长视频与 Video-MME-v2 上相对 Vanilla 仍有明显差距，压缩并非无损；部分子任务（如 StreamingBench 的 Cnt 计数类）表现较弱。
  - 路由器为提示词分类器，跨骨干行为分布差异较大，存在骨干依赖与提示词敏感性风险；论文未系统评估路由器误判的代价。
  - 超参数按“流式/长视频”两个 profile 设定（$\lambda$ 分别为 0.2/0.0），虽声明未逐基准调参，但 profile 划分本身隐含场景先验。
- **应用限制**：需要访问模型面向的视觉嵌入与位置元数据，对黑盒 API 模型不适用；事件库容量与读取预算需按帧率/token 数手工配置；对需要精确时序计数或物体级追踪的问题能力有限。
