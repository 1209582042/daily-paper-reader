## 摘要
流式视频理解要求模型在未来问题未知之前持续保留有用的视觉证据。现有方法主要根据token重要性、时间冗余或片段级相关性来管理不断增长的视觉上下文，但很少围绕随时间持续存在并演化的对象来组织证据。因此，本文提出ObjectStream，一个无需训练的框架，将潜在对象视为流式视频理解的记忆锚点。ObjectStream直接从冻结的Video-LLM表示中诱导出空间连贯的潜在对象，跨帧将它们链接为持久锚点，并在有界内存预算下维护其历史，无需外部对象检测器或分割模型。基于这些锚点，ObjectStream保留三种互补形式的证据：持久对象历史、瞬态对象变化和近期视觉上下文。该设计使现有视频大语言模型（Video-LLM）能够对对象身份、交互和状态变化进行推理，同时保持底层模型不变。在在线流式和离线长视频基准上的大量实验证明了其有效性和高效性。在在线流式评估中，ObjectStream在OVO-Bench实时视觉感知上使Qwen2.5-VL-7B提升10.0分，同时将峰值GPU内存和TTFT降低约50%。在离线长视频基准上，它在丢弃82.5%视觉token的情况下超越了全token基线。这些结果凸显了潜在对象作为一种实用且有效的紧凑流式视频记忆组织原则。

## Abstract
Streaming video understanding requires models to continuously retain useful visual evidence before future questions are known. Existing approaches primarily manage the growing visual context according to token importance, temporal redundancy, or segment-level relevance, but rarely organize evidence around objects that persist and evolve over time. Thus, in this paper, we introduce ObjectStream, a training-free framework that treats latent objects as memory anchors for streaming video understanding. ObjectStream induces spatially coherent latent objects directly from frozen Video-LLM representations, links them across frames into persistent anchors, and maintains their histories under a bounded memory budget, without requiring external object detectors or segmentation models. Built on these anchors, ObjectStream preserves three complementary forms of evidence: persistent object histories, transient object changes, and recent visual context. This design enables existing Video Large Language Models (Video-LLMs) to reason over object identities, interactions, and state changes while leaving the underlying model unchanged. Extensive experiments on online streaming and offline long-video benchmarks demonstrate both effectiveness and efficiency. In online streaming evaluation, ObjectStream improves Qwen2.5-VL-7B by 10.0 points on OVO-Bench Real-Time Visual Perception, while reducing peak GPU mem-ory and TTFT by approximately 50%. On offline long-video benchmarks, it surpasses the full-token baseline while discarding 82.5% of visual tokens. These results highlight latent objects as a practical and effective organizing principle for compact streaming video memory.

## 1. 核心问题与研究动机

- **背景**：流式视频理解要求模型在视觉输入持续到达、且未来问题未知的情况下，边看边决定保留哪些信息，并满足严格的内存与延迟约束。这与离线视频理解（可先看完整视频再回答）有本质区别。
- **现有方法的局限**：主流免训练方案通过帧选择、视觉 token 剪枝、KV-cache 压缩、时序/片段级记忆组织来控制不断增长的上下文。这些方法擅长保留粗粒度上下文与时序语义，但**很少围绕“随时间持续存在并演化”的对象来组织证据**。
- **由此带来的问题**：当问题涉及对象身份追踪、对象间交互、对象状态变化时（如“之前倒水用的是哪个容器”），细粒度对象级证据在跨时间维度上缺乏显式组织，容易被背景或全局语义淹没，导致回答错误（论文图 1 的示例：基线答“蓝色杯子”，正确应为“橙色带柄马克杯”）。
- **核心主张**：流式记忆不仅要决定“保留什么”，还要决定“如何组织”。论文提出以**潜在对象（latent objects）作为记忆锚点**来组织流式视觉记忆。

## 2. 方法论

### 2.1 核心思想
- 提出 **ObjectStream**：一个**免训练、即插即用**的视觉记忆框架，不改动底层 Video-LLM 架构与参数。
- 直接从**冻结的 Video-LLM 视觉表示**中诱导出空间连贯的“潜在对象”，跨帧关联为持久锚点，并在有界预算下维护其历史；**无需外部检测器或分割模型**。
- 总记忆由三部分并集构成：持久对象历史（LOAM）、瞬态对象变化（OCTR）、近期视觉上下文（RVGW）。

### 2.2 关键技术细节

**模块一：Latent Object-Anchored Memory（LOAM，潜在对象锚定记忆）**，分四阶段：

- **S1 查询无关的 token 显著性估计**：对每帧视觉 token 做 ℓ2 归一化后求均值得到帧级上下文向量 c_t；用 token 与 c_t 的余弦不相似度作为显著性分数 s_t,j = 1 − cos(x̂_t,j, c_t)；按帧内分位数阈值（q 分位）选出活跃 token 集合 A_t。偏离全局表征越远的 token 越可能对应有信息量的对象/人物/区域。
- **S2 空间聚类发现对象锚点**：在 patch 二维网格上，对活跃 token 构建 4-邻接无向图，取连通分量得到帧级对象候选 C_t；用显著性加权平均并归一化得到候选对象特征 μ = f(C_t,m)。这一步把零散显著 patch 聚成粗粒度对象单元。
- **S3 跨帧关联与有界对象集维护**：维护动态对象集 O，每个轨迹 O_i 存储对象特征 μ_i、最近观测时间戳 τ_i、时序一致性 ρ_i、对象显著性 a_i、历史 token 池 T_i。对每个候选，找余弦相似度最高的轨迹 i*；若相似度 ≥ 阈值 θ 则匹配，并用 EMA（系数 β）更新对象特征；否则新建轨迹。当轨迹数超过预算 M 时，按（τ_i, a_i, ρ_i）字典序排名做 Top-M 淘汰，优先保留近期、显著、时序一致的锚点。
- **S4 对象中心证据保留**：对象淘汰与 token 保留在不同粒度上进行。对每个保留轨迹，在其**对象专属历史 token 池**内按显著性取 Top-k_i 个 token，而非全局选 top token（避免被少数高显著区域/帧主导），汇总得到 R_object。

**模块二：Object-Conditioned Temporal Residuals（OCTR，对象条件时序残差）**
- 动机：EMA 平滑会抑制短时但重要的变化（运动、动作切换、出现/消失、状态变化、交互变化）。
- 做法：对每条轨迹的匹配观测序列计算相邻观测特征变化 Δ_i,l = 1 − cos(z_i,l, z_i,l−1)，用该对象自身历史变化的均值+标准差作为自适应阈值 γ_i,l，超过阈值即记为时序事件 B_τ；在每个事件时间戳附近的局部时间窗 W(t, r) 内，按显著性取 Top-k_b 个原始 token，得到 R_temporal，保留原始视觉证据。

**模块三：Recent Visual Grounding Window（RVGW，近期视觉接地窗口）**
- 直接保留最近 L 帧的原始视觉 token（R_rvgw），为“当前正在发生什么”类实时问题提供高保真局部证据。

**推理**：最终答案由 LLM 以问题 Q 与合并记忆 R_τ = R_object ∪ R_temporal ∪ R_rvgw 为条件生成。

### 2.3 实现超参（论文给出）
- 在线：1 fps 采样，最大 256 帧；RVGW 8 帧；最多 64 个对象、每对象 8 token；时序残差最多 32 个事件、半径 1、每选中帧额外 2 token。

## 6. 主要结论与发现

- **在线效果显著**：Qwen2.5-VL-7B 在 OVO-Bench 实时视觉感知从 63.3 → 73.3（+10.0），Backward Tracing 44.6 → 49.5；StreamingBench 平均 73.9 → 76.8。3B 骨干上 StreamingBench 68.0 → 72.4，OVO-Bench 平均 60.0 → 68.6。
- **优于同类免训练方法**：OVO-Bench 总均分上，7B 从 FluxMem 的 60.4 提升到 65.4，3B 从 54.0 提升到 60.2。
- **离线同样有效**：7B 上 VideoMME-Long 51.3 → 54.0、EgoSchema 58.5 → 60.8；3B 上 49.3 → 52.9、54.9 → 57.7。且在丢弃 82.5% 视觉 token 的情况下**超过全 token 基线**。
- **效率优势**：峰值显存与 TTFT 相比全 token 基线降约 50%；相比 DINOv2 聚类、SAM+DINOv2 等引入外部特征的方案，精度接近或更优但延迟与显存显著更低（SAM+DINOv2 精度 73.8 但 TTFT 19.06 s、显存 26.78 GB）。
- **消融结论**：RVGW 主要提升 StreamingBench（近期观测）；LOAM 主要提升 OVO-Bench（结构化对象记忆）；二者组合全面提升；加入 OCTR 后取得最佳整体表现（54.0 / 60.8 / 65.4 / 76.8）。
- **定性发现**：SAM+DINOv2 掩码更精细，但面向像素级分割、缺乏可复用的时序记忆状态；ObjectStream 区域较粗但定位足够，且在尺度、姿态、视角变化下保持任务相关对象的跨帧一致性。
- **总体结论**：潜在对象是一种实用且有效的紧凑流式视频记忆组织原则，可在不改动底层模型的前提下兼顾效果与效率。

## 7. 优点

- **问题切入有新意**：把“记忆组织方式”而非仅“记忆压缩比例”作为核心变量，用对象作为语义索引，直击身份追踪、交互与状态变化类问题。
- **完全免训练、即插即用**：不依赖外部检测器/分割器，不修改模型参数与架构，落地成本低，可迁移到不同 Video-LLM。
- **三级互补记忆设计合理**：持久对象历史（长期语义）+ 时序残差（短时突变）+ 近期窗口（实时接地），覆盖了流式问答的三类典型需求，且消融验证了各自分工。
- **有界预算与淘汰机制清晰**：对象级 Top-M 淘汰 + 对象内 Top-k token 保留的双粒度设计，避免了全局 top-k 被少数高显著区域主导的偏差。
- **效率与精度同时报告**：在流式场景中，TTFT 与峰值显存是关键指标，论文将其与精度并列呈现，并与其他对象构建方案横向对比，说服力较强。
- **自适应阈值**：时序事件检测用对象自身历史变化的均值+标准差作为阈值，比固定阈值更能适应不同对象的动态特性。
