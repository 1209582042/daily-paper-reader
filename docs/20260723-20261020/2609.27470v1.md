## 摘要
近期的视频-语言模型越来越多地采用混合架构，将线性注意力层与全注意力层交错排列，以实现高效的长上下文处理。线性注意力的循环状态大小固定，而全注意力的 KV 缓存则随视频流持续增长，因此在有限内存预算下必须进行驱逐。流式场景的关键挑战在于驱逐必须发生在问题到来之前，因此保留什么必须在没有问题的情况下决定。现有驱逐方法从 KV 缓存本身推导 token 分数，利用位置、注意力或键值表示，而基于注意力的分数还需要代理查询或额外计算。混合骨干网络提供了另一种信号来源。在门控 delta 线性注意力中，循环状态由每个输入与已可从状态中检索到的内容之间的残差来更新，因此其在一段帧上的变化反映了该段带来的新信息量。我们提出 DeltaS，一种与查询无关、无需训练的方法，保留引起更大归一化状态变化（即状态漂移）的视频片段。在预算与保留策略保持固定的受控比较中，状态漂移优于基于位置、注意力和键值的信号。仅以占前向传播 1.9% 成本的信号，DeltaS 在六个长视频基准上平均超越最强的与查询无关的有界内存基线 2.1 分，在最长基准上超越 5.6 分。这些结果表明混合架构的两种记忆可以协同工作。代码见 https://github.com/MaumAI-Company/DeltaS。

## Abstract
Recent video-language models increasingly adopt hybrid architectures that interleave linear and full attention layers for efficient long-context processing. While the recurrent state of linear attention remains fixed in size, the KV cache of full attention continues to grow with the video stream, making eviction necessary under a bounded memory budget. The key challenge in streaming is that eviction must occur before the question arrives, so what to retain has to be decided without the question. Existing eviction methods derive token scores from the KV cache itself, using position, attention, or key-value representations, and attention-based scores further require proxy queries or extra computation. Hybrid backbones offer another source of signal. In gated-delta linear attention, the recurrent state is updated by the residual between each input and what can already be retrieved from the state, so its change over a chunk of frames reflects how much new information the chunk brings. We propose DeltaS, a query-agnostic, training-free method that retains video chunks inducing larger normalized state change, or state drift. In a controlled comparison with the budget and retention policy held fixed, state drift outperforms position-, attention-, and key-value-based signals. With a signal costing only 1.9% of the forward pass, DeltaS surpasses the strongest query-agnostic bounded-memory baseline by 2.1 points on average across six long-video benchmarks and by 5.6 points on the longest benchmark. These results suggest that the two memories of hybrid architectures can work cooperatively. Code is available at https://github.com/MaumAI-Company/DeltaS.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视频-语言模型为处理长上下文，越来越多采用**混合架构**（线性注意力层 + 全注意力层交错）。线性注意力的循环状态大小固定，但全注意力的 KV 缓存随视频流线性增长。
- **具体数据**：在本文使用的 3:1 混合骨干（Qwen3.5-9B）中，线性注意力循环状态固定为 48 MiB，而全注意力 KV 缓存一小时视频后超过 10 GiB，因此必须做 KV 驱逐。
- **核心挑战**：流式场景下**驱逐必须发生在问题到来之前**，保留信号必须**与查询无关（query-agnostic）**。
- **现有方法局限**：现有驱逐方法从 KV 缓存自身推导分数（位置、注意力、键值表示）；基于注意力的方法还需代理查询或额外计算。
- **论文切入点**：混合骨干的线性注意力循环状态是"已在计算中产生"的固定大小上下文摘要，可作为新的保留信号来源。门控 delta 规则只把"输入与状态已能检索内容之间的残差"写入状态，因此状态变化量反映新信息量。

## 2. 方法论

### 核心思想
- 用**视频块处理前后循环状态的归一化变化量（state drift，状态漂移）**作为该块的保留分数，优先保留高漂移（带来更多新信息）的块，用于全注意力层的 KV 缓存保留。

### 关键技术细节
- **门控 delta 更新规则**（式 1、2）：
  - \(S_t = \alpha_t S_{t-1} + \beta_t (v_t - \alpha_t S_{t-1} k_t) k_t^\top\)
  - 更新量取决于"预测残差"（新值减去从衰减状态检索的值）与写入门控 \(\beta_t\) 的乘积。
- **状态漂移定义**（式 3）：
  - \(\Delta S = \frac{1}{L}\sum_{i=1}^{L} \frac{\|S_i^{after} - S_i^{before}\|_F}{\|S_i^{before}\|_F}\)
  - 对 L 个线性注意力层做 Frobenius 范数归一化后取平均，得到每个视频块的单一分数，所有全注意力层共享该排序。
- **保留策略**：
  - 固定保留前 \(n_s=4\) 个 sink token 与最近 \(n_w=1024\) 个 token 的局部窗口；
  - 剩余预算 \(M-n_s-n_w\) 按**时间分桶**（N=4 个等时长跨度）均分，桶内按 \(\Delta S\) 取 top-k，避免全局排序偏向视频早期；
  - 分桶基于原始到达时间而非缓存索引，每次驱逐重新计算，无需预知视频总长。
- **位置处理**：保留 token 维持原始位置索引，不重排，避免 key 重新旋转。
- **问答隔离**：回答问题前保存状态，回答后恢复流式状态并丢弃问答产生的 KV，保证后续驱逐仍与查询无关。
- **开销**：仅需保存上一状态副本并计算范数，无需额外前向或注意力计算；信号开销为前向时间的 1.9%（2.07 ms / 107 ms）。

## 6. 主要结论与发现

- **主结果**：M=8,192 时 DeltaS 在全部 6 个基准上最优，平均超最强基线 StreamMem **2.1 分**；M=16,384 时 6 个中 5 个最优，平均超 **1.7 分**。
- **长视频优势更明显**：LVBench 上分别超最强基线 **5.6 / 4.3 分**；M=8,192 的 DeltaS（58.7）几乎追平 M=16,384 的 StreamMem（58.8），即用一半预算达到同等水平。
- **保留率越低增益越大**：增益随保留比例下降而扩大（LVBench 保留率仅 1.8%）；Video-MME v2 例外，两预算下均约 +0.5 分。
- **信号对比**：状态类信号（DeltaS、\(\beta\|e\|\)）优于位置、注意力、键值类信号；DeltaS 超最强缓存内部信号 VaN **0.7–2.1 分**，超 \(\beta\|e\|\) **0.5–1.2 分**。
- **时间分桶有效**：无分桶时保留 token 明显偏向视频早期；N=4 时平均增益最大，N=8 反而下降。
- **效率**：每次驱逐额外总开销 6.4 ms，为所有计算保留信号的方法中最低（InfiniPot-V 15.4 ms；StreamMem/HERMES 超过一次块前向时间；\(\beta\|e\|\) 达 206.1 ms）。
- **流式基准的警示发现**：在 StreamingBench / OVO-Bench 上，仅看最近帧的无记忆基线反而超过 Full KV；HLD 任务上所有处理完整视频的方法都低于随机猜测（27.6%），说明这些基准的聚合分数不能可靠反映长时记忆能力。排除 HLD 后，DeltaS 在 OVO-Bench Backward 上取得最高分（66.7，Full KV 为 64.5）。
