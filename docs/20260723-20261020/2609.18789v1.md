## 摘要
视觉语言导航需要在对时间保持空间理解的同时，将语言与视觉观测对齐。几何基础模型（GFM）在其层级结构中暴露中间表示，但导航策略应如何使用这些特征并保留历史几何证据仍未解决。我们提出 AdaGeoVLN，一个流式视觉语言导航框架，在表示深度与导航时间两个维度上回答上述问题。分层 GFM–VLM 融合将 GFM 的早期、中期和后期表示与连续策略阶段耦合，而非重复注入终端特征。导航感知的 GFM 记忆依据指令相关性、几何置信度和转移新颖性，在每层有界预算下保留历史 VGGT 全局注意力 KV 状态。保留的状态在与策略融合之前为后续观测提供几何上下文。在 R2R-CE 和 RxR-CE 上，AdaGeoVLN 仅使用单一 RGB 流且无需额外导航专用外部数据即取得强劲性能。受控消融实验表明，在相同融合位置下，多深度耦合显著优于重复的终端特征注入。有界导航感知保留在保持导航性能的同时，相对于更大记忆的时间保留显著降低了 GFM-KV 内存。这些发现支持联合考察暴露给策略的几何表示以及为未来推理保留的历史证据。代码将在录用后发布于 https://humanoid-research.github.io/adageovln/。

## Abstract
Vision-language navigation requires aligning language with visual observations while maintaining spatial understanding over time. Geometry foundation models (GFMs) expose intermediate representations throughout their hierarchy, but how navigation policies should use these features and retain historical geometric evidence remains unresolved. We introduce \method{}, a streaming VLN framework that addresses these questions across \textbf{representation depth} and \textbf{navigation time}. Hierarchical GFM--VLM fusion couples earlier, intermediate, and later GFM representations to successive policy stages instead of repeatedly injecting a terminal feature. Navigation-aware GFM memory retains historical VGGT global-attention KV states according to instruction relevance, geometric confidence, and transition novelty under a bounded per-layer budget. Retained states provide geometric context for subsequent observations before fusion with the policy. Across R2R-CE and RxR-CE, \method{} achieves strong performance using a single RGB stream without additional navigation-specific external data. Controlled ablations show that multi-depth coupling substantially outperforms repeated terminal-feature injection at matched fusion locations. Bounded navigation-aware retention preserves navigation performance while considerably reducing GFM-KV memory relative to larger-memory temporal retention. These findings support jointly examining the geometric representations exposed to the policy and the historical evidence retained for future inference. Code will be released upon acceptance at https://humanoid-research.github.io/adageovln/.

# AdaGeoVLN 论文结构化总结

## 1. 核心问题与整体含义

- **背景**：视觉语言导航（VLN）要求智能体在连续视觉流中同时完成语言对齐与空间理解，需要推理空间关系、视角变化、路线几何以及观测间的时间关联。仅靠物体识别或语言—外观匹配不足以在未见环境中导航。
- **几何基础模型（GFM）的潜力与未解问题**：以 VGGT 为代表的 GFM 能从大规模视觉数据中学习几何表示，部署时无需深度或位姿输入。但导航策略应如何与这些几何表示交互仍不清楚。
- **问题一（表示深度）**：常见做法只把 GFM 的**末端表示**暴露给策略，而中间层状态可能含有互补信息。论文追问：是否应让多个几何深度的表示与策略推理的连续阶段交互？关键区分在于**表示多样性**，而非注入频率——重复注入末端特征只增加交互次数，并不暴露早期 GFM 状态。
- **问题二（导航时间）**：历史几何状态能保留跨视角的空间上下文，但无限制保留会使内存随轨迹长度增长；基于新近度的保留把“观测年龄”当作效用代理，对指令条件化导航可能不足——早期观测可能因捕捉到指令地标、几何可靠或代表独特轨迹转移而仍然有用。
- **整体含义**：论文主张应**联合设计**“暴露给策略的几何表示深度”与“为未来推理保留的历史证据”，二者共同决定流式 VLN 的效果。

## 2. 方法论

### 2.1 问题形式化

- 在导航步 $t$，智能体观测 RGB 图像 $I_t$ 与指令 $L$，预测动作 $a_t \sim \pi_\theta(a_t \mid L, I_{1:t}, M_t)$，其中 $M_t$ 为保留的几何侧记忆。
- 框架由两个机制组成：**分层 GFM–VLM 融合**（深度维度）与**导航感知 GFM 记忆**（时间维度）。

### 2.2 分层几何融合（跨表示深度）

- 沿用 SpatialStack 的多深度接口，从 VGGT 提取深度 $m \in \{11, 17, 23\}$ 的表示，分别耦合到 Qwen3.5-4B 解码器的前三个层 $k \in \{0,1,2\}$。
- 不预设各深度的语义角色，而将其视为经验假设：不同几何处理阶段的隐状态可能提供互补信息。
- **空间对齐与投影**：对每个深度做 RMSNorm，再以 $2\times2$ 分组把 2048 维特征合并为 8192 维 token；深度特定适配器 $\Phi_m: \mathbb{R}^{8192} \to \mathbb{R}^{4096} \to \mathbb{R}^{2560}$ 映射到语言隐空间；token 级门控网络 $\Gamma_m$ 输出标量门控 logit。
- **几何更新**：$\Delta_t^m = s_m [\sigma(\Gamma_m(Z_t^m))\,\Phi_m(Z_t^m)]$，$s_m$ 为可学习标量，控制该深度的贡献。
- **注入方式**：在对应解码层之后对**图像 token 位置**做残差相加，不直接覆盖文本 token 状态；后续解码层继续传播几何增强的视觉上下文。
- **对照设计**：为区分“表示多样性”与“注入频率”，设置匹配对照——在同样三个位置重复注入 $G^{23}$（Deep ×3）。

### 2.3 导航感知 GFM KV 保留（跨导航时间）

- 将 GFM 记忆形式化为**固定容量下的导航条件化 token 选择**，作用于 VGGT 全局注意力 KV 缓存（与 Qwen/VLM 缓存、CPU 端帧对齐特征缓冲相互独立）。
- 候选记忆 $C_t^g = M_{t-1}^g \cup (K_t^g, V_t^g)$；选择在当前 VGGT 前向之后进行，因此保留状态影响的是 $t+1$ 时刻的几何上下文，不改变当前帧表示。
- **三个保留准则**：
  - **指令条件相关性**：按标点、序列标记（“then”“next”“after that”）及引导导航动词的连词切分指令（保留“next to”等短语）；对帧内视觉 token 与指令段嵌入分别做中心化，相关性 $r_{f,p} = 1 + \max_j \cos(\bar{u}_{f,p}, \bar{e}_j)^2$，即每个 token 关联最相关的子目标段；单段指令时省略文本侧中心化。
  - **几何置信度**：将 VGGT 深度与点图置信场平均池化到对齐 token 网格，映射 $\tilde{c} \mapsto 1 - 1/\tilde{c}$，取两者**最小值** $c_{f,p} = \min(c^{\text{depth}}_{f,p}, c^{\text{point}}_{f,p})$，要求两类预测都高置信。
  - **转移新颖性**：用均匀池化并 L2 归一化的浅层 token 描述每帧，相对最近邻其他帧计算 $\nu_{f|t} = 1 - \max_{f' \neq f} \cos(d_f, d_{f'})^2$；描述符在 KV 驱逐后仍保留，新颖性每步刷新；同帧所有 patch 共享该分数。
- **联合保留分数**：$S_{t,g}(f,p) = \lambda_r z(r_{f,p}) + \lambda_c z(c_{f,p}) + \lambda_\nu z(\nu_{f,p|t})$，其中 $z$ 为层与步特定的 z-score 标准化（排除特殊 token）；**权重等值固定、未调优**。
- **预算分配与选择**：总容量按离线推导的层比例 $\rho_g$（依据 GHOST 的逐层输入—输出余弦相似度）分配到 24 个全局注意力层，$B_g = \lfloor \rho_g B_{\text{total}} \rfloor$；各层独立执行 TopK 选择 $M_t^g = \text{TopK}(C_t^g, S_{t,g}, B_g)$。文中“900K”指 24 层合计的层—token 容量，而非唯一场景 token 数。

## 3. 实验设计

- **数据集 / Benchmark**：R2R-CE 与 RxR-CE 的 Val-Unseen 划分，分别含 1,839 与 3,669 个导航回合。
- **指标**：成功率（SR）、按路径长度加权的成功率（SPL）、导航误差（NE，单位米）、oracle 成功率（OS）、归一化动态时间规整（nDTW）；除 NE 外均乘 100。
- **观测设定**：仅单路 RGB 流，无全景、无里程计、无深度输入；除 R2R/RxR 外不使用额外导航训练数据。
- **对比方法**：
  - 主表对比 HPN+DN、Sim2Sim、VLN⟳BERT、Ego2-Map、DreamWalker、AO-Planner、g3D-LF、Seq2Seq、NaVid-4D、NavMorph、NaVid、Sim2Real、StreamVLN、Uni-NaVid、NaVILA、JanusVLN 等，并按观测需求（全景/里程计/深度/单 RGB）与外部数据量分组。
  - 消融对比：无几何（Qwen3.5 SFT）、单深度末端注入（$G^{23}\to L_2$）、Deep ×3（同位置重复注入末端特征）、分层融合。
  - 记忆策略对比：Hybrid Inc.（8+24）、Hybrid Inc.（8+48）、GHOST、InfiniteVGGT，以及本文导航感知保留在 600K/800K/900K 预算下的配置。
- **真实部署**：在 Unitree G1 人形机器人 + ZED X Mini 相机上部署，Jetson AGX Orin 预处理图像、远程 NVIDIA RTX A6000 工作站推理；两次室内试验涉及地标条件转向、按指令侧绕过植物、忽略无关门口、在指定目标附近停止。

## 5. 实验数量与充分性

- **实验组数概览**：
  - 2 个 benchmark 的主结果对比（各约 15–16 个基线）。
  - 1 组几何融合消融（4 种配置：无几何、单深度、Deep ×3、分层）。

  - **局限**：所有消融仅在 R2R-CE Val-Unseen 上进行，未在 RxR-CE 上重复消融；保留分数权重固定为等值，未做权重调优或学习，因此信号消融只能说明“组合有效”，不能说明“权重最优”；真实部署仅 2 次试验，属演示性质，缺乏定量统计；跨方法比较受各基线观测假设与外部数据量差异影响（作者亦明确提示需谨慎解读）。

## 6. 主要结论与发现

- **主结果**：R2R-CE 上 SR 55.7%、SPL 51.4%，较 JanusVLN* 提升 2.9/2.2 个百分点，OS 从 58.0% 升至 60.7%，NE 相近（5.27 vs. 5.17 m）。RxR-CE 上 SR 54.1%、SPL 44.7%、nDTW 61.8、NE 5.64 m，相对 JanusVLN* 分别提升 2.7、0.4、2.7 个百分点，NE 降低 0.82 m。均在单 RGB、无额外导航数据条件下取得。
- **多深度优于末端注入**：分层融合较无几何策略提升 SR/SPL 9.2/9.1 个百分点，较单深度提升 6.8/7.3 个百分点；相对匹配的 Deep ×3 提升最大，达 13.6/14.5 个百分点——说明**重复注入末端特征无法复现多深度访问的收益**。
- **导航感知保留更省内存且更准**：Nav. 900K 相对 Hybrid Inc.（8+24）SR/SPL 提升 0.6/1.1 个百分点，同时 GFM-KV 内存少 3.33%、总分配 GPU 内存少 9.35%；相对 Hybrid Inc.（8+48）提升 0.4/1.4 个百分点，KV 与总分配内存分别降低 39.73% 与 20.22%。时间基线在 OS 与 NE 上更优。
- **预算敏感性**：600K→800K→900K 时 SR 由 53.1%→54.2%→55.7%，SPL 由 49.2%→50.2%→51.4%，呈现明确的准确率—内存权衡。
- **三信号均有效**：去掉置信度导致最大 SR 下降（2.1 个百分点），其次为指令相关性（1.5）与转移重要性（1.4）；完整分数在近似恒定内存下优于所有两信号变体。
- **定性/部署**：在需下楼梯、多次转向并精确停止的 R2R-CE 回合中，AdaGeoVLN 到达目标而 Qwen3.5 SFT 与 JanusVLN 失败；Unitree G1 上完成地标条件转向等室内任务，验证了物理执行可行性。

## 7. 优点

- **问题拆解清晰**：把“几何如何被策略使用”拆成表示深度与导航时间两个正交轴，分别设计机制并分别消融，叙事结构严谨。
- **对照设计严谨**：Deep ×3 在融合位置与次数匹配下隔离表示多样性；留一信号消融在固定内存预算下进行，避免“内存换精度”的混杂解释。
- **记忆选择有导航语义**：以指令相关性、几何置信度、转移新颖性替代单纯新近度，且选择作用于 VGGT 全局注意力 KV、在融合前影响后续几何推断，形成“选择塑造未来上下文”的闭环。
- **工程细节完整**：给出空间对齐（2×2 分组）、适配器维度、门控与可学习缩放、层间预算按 GHOST 相似度分配等可复现细节；明确区分 GFM-KV 与总 GPU 内存，报告口径透明。
- **实用性强**：单 RGB、无额外导航数据、VGGT 冻结，训练与部署成本相对可控，并已在人形机器人上演示。
