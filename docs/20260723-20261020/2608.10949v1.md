## 摘要
流式视频理解要求多模态大语言模型（MLLMs）在严格因果性和有界记忆约束下，从持续演化的视频流中保留相关证据。然而现有范式仍存在局限：基于模型的方法需要侵入式地更新骨干网络，而基于记忆的方法则会在时间冗余内容上消耗大量视觉编码计算，并依赖对视觉历史的刚性访问。为解决这些局限，我们提出 StreamFlow，一种高效的视觉记忆框架，能够实现对历史视觉信息的动态、按需访问。StreamFlow 将轻量级、动态感知的中期记忆与潜在长期记忆相结合：前者在视觉编码前过滤时间冗余，后者将历史视频内容整合为可供后续推理访问的视觉潜在表示。在生成过程中，当模型对视觉证据的依赖减弱时，注意力引导的检索机制会注入相关的视觉潜在表示。StreamFlow 实现了最先进的流式视频理解性能，在 StreamingBench 上达到 67.73% 的总体准确率，同时在离线长视频基准上也表现强劲。相对于原始设置，它将视觉注意力分数（VAS）提升了 59.1%，同时将端到端延迟和峰值内存分别降低 50.4% 和 21.1%，从而实现更具视觉依据且更高效的推理。

## Abstract
Streaming video understanding requires multimodal large language models (MLLMs) to preserve relevant evidence from continuously evolving streams under strict causality and bounded memory. Yet existing paradigms remain limited: model-based methods require intrusive backbone updates, while memory-based methods expend substantial visual-encoding computation on temporally redundant content and rely on rigid access to visual history. To address these limitations, we introduce StreamFlow, an efficient visual memory framework that enables dynamic, on-demand access to historical visual information. StreamFlow combines a lightweight, dynamics-aware mid-term memory that filters temporal redundancy before visual encoding with a latent long-term memory that consolidates historical video content into visual latents accessible to subsequent reasoning. During generation, an attention-guided retrieval mechanism injects relevant visual latents when the model's reliance on visual evidence weakens. StreamFlow achieves state-of-the-art streaming video understanding performance, reaching 67.73% overall accuracy on StreamingBench, while also delivering strong performance on offline long-video benchmarks. Relative to the vanilla setting, it improves the visual attention score (VAS) by 59.1% while reducing end-to-end latency and peak memory by 50.4% and 21.1%, respectively, enabling more visually grounded and efficient reasoning.

# StreamFlow 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：自动驾驶、具身机器人、计算机使用代理等新兴场景要求 MLLM 对持续演化的视频流进行实时理解，研究重心正从离线视频理解转向**流式视频理解**。该任务的核心约束是：严格因果性（不能看未来帧）、有界内存、低延迟。
- **现有两大范式的局限**：
  - **基于模型的方法**（如 VideoLLM-Online、Dispider、StreamForest）：需微调 MLLM 骨干以具备在线感知能力，训练成本高昂，且存在灾难性遗忘风险。
  - **基于记忆的方法**（如 LiveVLM、StreamMem、InfiniPot-V、StreamingTOM）：冻结骨干 + 外部记忆，模块化且易集成，但存在两个细粒度管理缺陷：
    1. **冗余视觉编码**：对每一帧密集编码后才构建记忆，在静态或可预测区域浪费大量计算；
    2. **刚性记忆访问**：历史证据被固定为视觉前缀，造成持续上下文开销，且生成过程中视觉注意力持续衰减（attention drift），增加幻觉风险。
- **核心研究问题**：如何设计一种流式记忆，决定"编码哪些视觉信息"以及"何时在生成中重新激活历史证据"？

## 2. 方法论

**核心思想**：构建一条连续的"记忆流"——视觉信息被选择性编码（中期记忆）、随时间整合压缩（长期记忆）、并在生成中按需动态重新激活（注意力引导注入）。

### 2.1 动态感知中期记忆（Dynamics-aware Mid-Term Memory）

- **参考锚定分组**：将视频流按 GOP 组织，每个 GOP 含 1 个 I 帧（参考帧）+ T−1 个 P 帧，帧先暂存于缓冲区，攒满 T 帧后成组。
- **块级残差打分**：在原始像素空间直接计算每个 P 帧相对 I 帧的残差场 R_f(u) = X_f(u) − X_0(u)；对每个视觉 patch 内的残差幅值取均值，得到时间残差分数 s_{f,i}，作为动态先验。
- **稀疏块选择**：I 帧全部 N 个 patch 保留作为空间参考；每个 P 帧仅保留残差分数最高的 ⌈ρN⌉ 个 patch（即在该预算约束下最大化残差分数总和）。保留的 patch 按时间顺序组成稀疏 GOP，进入中期记忆。**关键点：过滤发生在视觉编码之前**，从而直接节省 ViT 计算。

### 2.2 潜在长期记忆（Latent Long-Term Memory）

- **视觉潜在编码**：当稀疏 GOP 被挤出中期记忆时，用冻结的视觉编码器 E_v 在原时空坐标上编码保留的 patch，得到与查询无关的视觉潜在表示 H_g。
- **有界记忆管理**：长期记忆容量固定为 C 个 GOP，按时间从旧到新排序。未满时直接追加；满时**不做 FIFO 淘汰**，而是计算相邻 GOP 的 I 帧逐 token 余弦相似度均值，选出最相似的一对，用合并算子 F_merge 合并：以较早 I 帧为锚，保留较晚 I 帧中 ⌈ρN⌉ 个最不相似 token 作为稀疏 P 帧，再将合并后的 2T 帧均匀下采样至 T 帧。合并释放一个槽位给新 GOP，从而在固定预算下保留长程信息。

### 2.3 注意力引导记忆注入（Attention-Guided Memory Injection）

- **视觉注意力分数（VAS）**：对第 t 个生成 token，将各层各头对全部可访问视觉 token（视觉前缀 + 已注入的记忆潜在）的归一化注意力权重求和，再对层与头取平均，得到 VAS_t ∈ [0,1]。VAS 低说明语言上下文主导、视觉依赖减弱。
- **触发与检索**：当 VAS_t < τ（默认 0.1）时触发检索。用冻结视觉投影器 P_v 将视觉 token 映射到文本嵌入空间，构造池化查询 q_t 与帧级键 k_{j,f}；每个 GOP 以其最相关帧的余弦相似度打分，取 top-K（K=4）个 GOP 并按时间顺序重排。
- **压缩注入**：神经压缩器 C_φ（LoRA 适配的 Qwen3.5-9B）联合处理按时间拼接的 GOP、查询 token 与 L 个可学习查询，仅保留 L 个可学习查询的输出作为固定长度视觉瓶颈（L=32），插入当前解码前缀之后。设有最大注入次数 5 次、最小注入间隔 8 个解码步。

- **性能**：StreamingBench 总体 67.73%，超此前最佳 LiveVLM-7B 4.63%；RTVU 81.55%，超 HERMES-7B 2.11%，10 个任务中 7 项第一，Counting 任务 67.02%（超 TimeChat-Online 9.04%）。离线：MLVU 75.34%（+2.24%）、VideoMME 73.52%（短/中/长分别 87.78/70.67/62.11，全面领先）。控制骨干下仍超 StreamingTOM 1.17%、超 ReKV 1.63%（VideoMME）。
- **视觉 grounding**：平均 VAS 从 0.066 提升至 0.105（+59.1%），缓解生成过程中的注意力漂移；matched 记忆相对 shuffled 使正确答案对数几率平均提升 0.27。
- **效率**：Pre-ViT patch 数减少 37.3%，视觉前端延迟降低 50.0%；上下文长度与 KV cache 各减少 37.8%，自注意力延迟降低 63.4%；端到端延迟降低 50.4%，峰值内存降低 21.1%。
- **机制发现**：残差选择在 50% 预算下保留 61.08% 局部运动、71.96% 外观变化，同时拒绝 95.28% 静态 patch；保留比例 ρ 从 0.25→0.50 收益最大，之后边际递减；VAS 引导注入优于预算匹配的分隔符/随机插入。

## 7. 优点

- **问题切分精准**：把"编码什么"与"何时取用"拆成两个正交子问题，分别用像素域残差过滤与生成时注意力触发解决，动机与设计高度自洽。
- **编码前过滤**：在原始像素空间做残差打分，避免"先密集编码再压缩"的算力浪费，是相对现有记忆方法的关键差异化，且有量化的净收益（含选择开销后仍降 50% 延迟）。
- **有界且非 FIFO 的记忆整合**：相似度引导的相邻 GOP 合并兼顾时间顺序与长程保留，避免简单淘汰丢失早期证据。
- **按需注入而非全量前缀**：以 VAS 作为在线 grounding 信号，把记忆访问从"固定前缀"变为"生成中动态事件"，同时降低上下文开销。
- **机制级验证**：反事实干预 + 逐 token VAS 轨迹 + 案例研究，形成"注意力恢复→证据使用→答案正确"的证据链，超出一般仅报准确率的论文。
- **效率测量规范**：三级边界、重复测量取中位数、明确排除项，可复现性较好。
